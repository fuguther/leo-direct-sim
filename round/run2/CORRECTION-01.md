# 纠偏记录（CORRECTION-01，2026-09-11）【主控失误与整改】

> 来源：Codex 审阅实际文件（收窄文件、候选卡、权限清单）后指出的三点偏移。**三点均成立**。

---

## 偏移 1：把"文件级授权"当成"有限反馈"（**最严重**）

**我做了什么**：深化者申请补料时，我逐文件授权 —— B3 获准读**完整 HISTORY-INDEX**，C2 获准读 **ELIMINATED-REGISTER 总表**，A3/C2 获准读**整批候选（cards.json）**。

**为什么错**：这等于**把历史判断任务转交给了深化者**。文件级授权**无法保证"只读其中一条"**；深化者一旦读了全集，就会（有意或无意地）把其他历史候选的判断带进本卡论证——正是"有限反馈"要防的。

**整改**：
1. **收回**三者的历史全集、淘汰总表、整批候选授权（已执行）；
2. 由**主控完成历史核对**，产出三份**有限摘录** `round/run2/feedback/EXCERPT-<卡ID>.md`：
   只含本卡相关的匹配对象、类型、原文定位、以及"对本卡的含义"；
3. 要求深化者：若已读过全集，**在稿中如实声明已读范围**（不再声称完全隔离）；
4. **不作废候选**（Codex 明确：不因此直接作废）。

**流程教训（写入规则方向）**：补料的正确形式是**主控摘录**，不是**给文件**。

---

## 偏移 2：把待比较的线索称为"主线"

**我做了什么**：收窄文件里直接写"本轮主线 = B3 / A3 / C2"。

**为什么错**：三者是**待比较的线索**，尚未裁决；提前称"主线"会固化判断。

**整改**：
- 三份摘录均要求稿首声明"本卡是候选线索，尚未裁决"；
- 各卡的**实质性要求**：
  - **B3**：明确**旧卡身份**（= run1 旧 B3，非 run2 同名卡），并说明"吸收 A1 的审计表与归因方案"是否**真正改变了判断**——若只是多一张表，如实降级；
  - **A3**：必须说明**超出普通推理工程优化**的 RL 层面困难（时间语义 / 信用分配 / 部分可观测性）；给不出则如实降级；
  - **C2**：必须从"评估缺口"推进到**具体失败原因 + 针对性改进**；给不出则**如实降级为评估协议卡**。

## 偏移 3：把猜测写成数字或事实

**实例**：
- "混载训练可吃掉 60–80%" —— 卡中**未附依据**；
- "流量模型普遍无时间过程" —— 由**个别论文**推广。

**整改**：
- **删除所有无来源百分比**（给不出篇名+节号就删）；
- "普遍/全部/首次/无人"等主张→改为**限定表述**（"在核验的 N 篇中未见"，并列出是哪几篇）；
- 每题**只按三问裁决**：重要条件下为什么做不好 / 改动针对什么原因 / 强简单替代为何仍不足；
- **不得**用"缺少同场比较""容易实现"替代选题价值。

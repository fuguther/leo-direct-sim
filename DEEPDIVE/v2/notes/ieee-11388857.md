# 精读笔记：ieee-11388857

**论文**: ST-QoS-A*: Spatio-Temporal QoS-Aware A* Routing on Time-Expanded Graphs for LEO Satellite Constellations
**出处**: 2025 12th IFEEA, IEEE, DOI: 10.1109/IFEEA66847.2025.11388857
**作者**: Xin Lu (上海卫星工程研究所), Zhaopeng Ning, Gang Li* (同济大学)

## 七要素

1. **问题**: 大规模 LEO 星座（Starlink/OneWeb 类）星间网络拓扑高速演化，传统"周期性在 TEG 上跑 Dijkstra"存在两大瓶颈：(a) 复杂度随 TEG 规模（节点数×时间层数）多项式增长，大星座在线实时计算不可行；(b) 基于当前/历史快照的决策缺乏对未来拓扑演化的预测，传输中易次优。需在时延、拥塞、稳定性三 QoS 维度下做到时空一致路由，且保持最优性保证与高计算效率。
2. **场景假设**: N 颗卫星的 LEO 星座建模为动态多属性加权图 G(t)=(V,E(t),C(t))；链路存在性由二值邻接函数 A(t) 决定，须同时满足距离、指向角、LoS 可见性、策略约束（最小安全距离 d_safe、最大指向速率、最大可容忍多普勒频移、跨缝规避窗口）；假设 A1（轨道与姿态可预测）；极轨场景 i=97°，含跨缝与地影频繁中断；每链路有并发会话硬上限 U_max。预测窗 T 离散为时间层 ℓΔt 构成 TEG。
3. **方法**: ST-QoS-A*——TEG 上的启发式搜索 f(n)=g(n)+h(n)。三个核心机制：
   - **时间对齐代价累积**: 从 (v_i,ℓ) 扩展到 (v_j,ℓ') 时，边际代价 ω 在发送时刻 t_ℓ 处取值评估，保证与连续时间 TDSPP 的时间一致性；
   - **物理可采纳启发式**: 拥塞与稳定性代价不估计（置 0，避免高估），仅时延项取光速传播时延下界 h(n)=α·‖p_dst−p_n‖/c，保证 admissible → 最优性；
   - **极轨处理**: 保留仅时延启发式，通过剩余可见寿命筛除（残余可见时间 T_res<T_guard 的弧被剪枝或惩罚）实现极感知剪枝，不破坏最优性；
   - **事件驱动自适应**: 两类触发——拥塞/容量触发（Sess≥U_max 时移除/惩罚弧，λ∝ρ）与拓扑触发（A(t) 变化时剪弧重路由）；另讨论 80% 链路负载预警触发（带迟滞）可进一步稳定路由，但实现保留原触发设计；
   - 复合代价 w = α·(传播+协议处理时延) + β·拥塞代价（链路近似 M/M/1 队列，与利用率 ρ=L/C 相关的非线性排队时延）+ γ·稳定性代价（预警区 [d1,d2] 内归一化邻近指标 ξ 的指数惩罚 exp(ξ)−1 形式）；α,β,γ 为可调权重。
4. **实验**: AGI STK 12 + 定制 MATLAB 接口全流程仿真平台；6 个地面设施节点（FAC1–FAC6）+ 多平面星座异构网络；自动注入 8 条 FAC-FAC 业务流；1 秒分辨率记录四指标：Succeeded Tasks、Average Propagation Delay、Average Hops、Maximum Link Load。时间滑窗机制每 120 秒、±30 分钟窗口内周期扫描重规划。传统基线只考虑几何距离与容量限制；Smart 额外含拥塞平方项、时间平滑项、切换惩罚项。极轨附加实验：i=97°、跨缝 ±10° 纬度内非均匀时间分层 Δt=0.5–1 s（其余 1 s）、触发迟滞开启。
5. **结果**: 基线场景：任务成功率提升 100%–300%（如 t=0s 时 3→6，t=8640s 时 1→4，另两点 2→5）；平均传播时延降低 9.4%–21.4%（10–20% 量级，如 0.0430→0.0338 s、0.0827→0.0749 s、0.0419→0.0350 s、0.0426→0.0400 s）；最大链路负载降低 60% 以上（具体点 +72.3%、+63.8%、+70.9%、+67.1%）；平均跳数略增（如 3.67→4.67、2.50→4.50）换取多路径分流。极轨场景：所有时间窗 ST-QoS-A* 仍全面占优，任务成功率为传统法 3–4 倍（2→7/8），时延略低（如 0.06576→0.06447 s），MaxLd≈1.0 近均匀；增益绝对值有所收窄。
6. **局限与代价**: (a) 平均跳数增加（多路径分流代价）；(b) 极轨下因可见性区间短、链路 churn 高，时延与峰值负载增益收窄，需更细时间分层与触发迟滞抑制震荡重路由；(c) 80% 预警触发仅在讨论中给出，最终实现未采用；(d) 最优性保证依赖拥塞/稳定代价不进启发式（h 只含时延下界），搜索剪枝效率受限；(e) 仿真仅 6 地面站 + 8 条流、单一 STK+MATLAB 环境，无大规模星座/真实负载验证；正文无复杂度实测数据（仅理论 O(d̄·NL·log(NL))）。
7. **可复用点**: (a) TEG 上"发送时刻取值评估边际代价"的时间对齐累积机制可直接移植到任何时空路由/调度框架；(b) 光速传播时延下界作为 admissible 启发式 + "不确定分量置 0 保最优"的设计范式；(c) 剩余链路寿命 T_res<T_guard 剪枝/惩罚的极轨处理；(d) 80% 负载预警 + 迟滞触发的事件驱动适应；(e) STK12+MATLAB 1s 分辨率、120s 滑窗重规划的仿真评测协议；(f) M/M/1 拥塞代价 + 指数稳定性惩罚的复合可加代价函数。

## 与选题空间的关系

- **赛道重合**: 与 LEO 直连仿真平台同属 LEO 星座 QoS 感知路由，但其求解范式是"TEG + A* 确定性搜索"，是学习类方法（GNN/DRL）的**非学习基线/对照组**首选——本文明确以"缺乏最优性保证"批评 DRL 路线，任何 RL 路由工作都需与之对比或融合。
- **可直接借鉴的机制**: ① 发送时刻评估代价的时间对齐累积（时空一致性的干净形式化）；② 光速下界 admissible 启发式（可给 RL 提供奖励下界/可行域剪枝）；③ 剩余链路寿命守门时间剪枝；④ 80% 负载预警 + 迟滞触发（可设计为 RL 环境的事件/奖励信号）。
- **差距/机会**: 仿真规模小（6 站、8 流、无大规模消融）、复杂度仅有理论界无实测、α/β/γ 权重靠人工调——权重自适应（学习化权重选择、RL 调 ω）与更大规模动态业务是明确的选题空隙；其 STK+MATLAB 评测协议（1s 分辨率、120s 滑窗重规划、四指标）可映射到本平台 receipt 式可复现实验设计。
- **引用定位**: 相关工作中作为"TEG 确定性最优路由代表"引用；极轨鲁棒性段落（非均匀分层 + 迟滞）可作为平台极轨场景设计的支撑文献。

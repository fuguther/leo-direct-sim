## 七要素（具体到数字机制）

1. **研究问题**：LEO 巨星座中动态 LISL（激光星间链路）的调度与路由联合优化。动态 LISL 依赖闭环控制（对准误差须 <1 µrad），空闲期终端仍需保持激活，带来额外能耗；Starlink 式固定 4 LISL 配置终端利用率低、大量链路冗余。目标是在"多建动态链路降低跳数/时延"与"关闭空闲终端省能耗"之间取折中，并与路由策略耦合。
2. **场景与系统模型**：OneWeb 型 Walker 星座 85°:720/18/1，轨道高度 1,200 km，18 个轨道面、720 颗卫星，相邻面相位差 0.5°。每星链路模式 = 3 条固定 LISL（同面内 + 两侧同向邻面，构成 T 形）+ 1 条动态 LISL（可在 7 个候选对象中选择或关闭，amax=7）。链路建立条件：两端卫星同时决策建立；每终端只能建 1 条链路；(i,j)∈E ⟹ (j,i)∈E。业务：热点卫星集 Vh（北美/欧洲/亚太），每个 episode（接入点两次切换之间，仅几分钟）从中随机选 K 个源目的节点，K(K−1) 条数据流，f≈高斯分布（n 达数百用户，中心极限定理）。轨道半径 R=7,587 km。
3. **问题形式化**：路由为线性规划流约束（容量约束式(4)、中间节点流守恒式(5)、源/汇约束式(6)(7)），用平均跳数 Havg（式(8)）替代时延，并设计三种路由策略：R1 最小化平均跳数、R2 最小化最大链路负载 z（大系数 L 防环路）、R3 两者折中。调度问题（式(15)）：max −β·E[H0] −(1−β)·P0(G(Ed))，其中 P0=|Ed|（动态链路数即能耗代理），β∈[0,1] 权衡两目标；β=1 只看跳数，β=0 只看能耗。可行域 Ω 离散且巨大，整体 MDP 状态空间无限。
4. **方法（MADRL）**：将调度建模为序贯决策 MDP <S,A,P,R,γ>：每个时隙 t 根据当前链路负载状态 St（N×N 矩阵，元素为链路流量）决策下一时隙 Ed^{t+1}=π(St)。分解：每颗卫星 = 一个 agent（720 个），状态 si 为以 i 为中心 (2a+1)×(2b+1) 邻域的子矩阵（镜像卫星状态矩阵左右翻转）；动作 ai∈{0..7}；奖励按式(26)从全局奖励分解：建模式 1–6 链路得 rit=0.5β(s^{t+1}_{ij}+s^{t+1}_{ji})−2(1−β)，模式 7 的流量项乘系数 η，未建链路奖励 0（0.5 因链路双向计两次，−2 因能耗项计两次）。分解奖励之和与全局奖励的相关系数 >0.98。网络：Double DQN [37] + Dueling DQN（Q=V+A−Ā，式(31)）+ ε-greedy（式(34)：ε=1−i/500 (i≤450)，0.1 (450<i≤800)，0.01 (800<i≤1000)，0 (i>1000)）+ Adam + 每 C 个时隙同步目标网络。
5. **关键加速/降开销技术**：(a) 压缩感知：状态矩阵由 Φ0（高斯随机 D×L 矩阵）压缩 esi=Φ0·si，实测状态为 10×81 float32（D=10, L=81，因每星链路数 ≤NLISL=4 稀疏），压缩数据直接进 DNN 无需重构，计算开销降为原始输入的 20%；(b) 网络参数与经验共享（所有 agent 同一策略、全局经验池）；(c) 改良优先经验回放（式(33)）：episode k<kth 时按 |ri|^α 归一化概率采样（奖励稀疏期优先采样成功建链经验），之后退化为均匀采样。
6. **实验设置**：β=0.5 主设置；训练 1000+ episodes；对比 4 方法：Dynamic（本文）、T-shaped（仅 3 固定链路，基准，全局奖励恒 0）、Fixed（4 固定链路，Starlink 式）、Random（随机建动态链路）。部署方案：1 颗 GEO 作数据中心 + 2 颗 GEO 中继，LEO→数据中心最长往返 629 ms，可在单个时隙内完成状态上传与参数下发（参数 float16 广播 1.46 MB）；每 LEO 每时隙上传 3,245 B，每个中继 GEO 汇聚 Nrelay=240 颗 LEO 的 760.55 KB/时隙；经验样本 6,485 B，≤10^6 样本共 6.04 GB 存储；DNN <10^6 次浮点乘法，专用硬件 1 ms 内完成。附录 A/B 用 [4] 终端参数 + ITU-R 1742/1805 天线增益图验证可行性：通信距离 ≤4,000 km，俯仰角 −12°~0°，方位角间隔 17.90°（终端盲区 10°），最小角间隔 1.13° 时接收增益 <0 dBi（对准最大增益 104 dBi），动态/固定 LISL 间干扰可忽略。
7. **结果与局限**：三种路由策略下相比固定 4-LISL：能耗（LISL 数量）降约 15%，平均时延降约 2 跳；R1 下动态链路最少、R2 最多（R2 需靠更多链路分流负载）；随 β 增大跳数与链路数的边际收益递减；活跃流比例变化时性能稳定；50 时隙（5 episodes）跨 episode 测试中每 episode 首时隙跳数因沿用上一 episode 调度而抬升，但能快速收敛回稳态，链路切换峰值出现在每 episode 第 2 时隙后迅速下降。局限（作者自认）：全局问题分解为独立决策带来最优性损失；奖励分解在动态链路多时趋于高估（R2 下 agent 奖励之和与全局奖励误差最大）；路由策略与调度是交替迭代而非端到端联合学习；负载重时部分链路满载导致跳数回升。

## RL 领域块

- **适用**。方法类别：值型离散动作 DRL —— 多智能体（参数共享）Double Dueling DQN（per-agent 独立学习 + 全局经验池共享 + 改良优先经验回放），协作式 MARL，非通信式、非 CTDE 集中式 critic。
- **MDP 定义**：状态 = 卫星邻域链路负载子矩阵（CS 压缩 10×81 后展平为 810 维输入）；动作 = 本星动态 LISL 的 8 种选择（7 个候选对端 + 关闭，离散）；奖励 = 全局目标按各链路贡献分解的局部奖励（式(26)，含 β 权衡与 η 修正因子）；折扣因子 γ 数值未报告（式(28) 使用但文中未给值）。
- **训练机制数字**：ε 退火见上（1000 episodes 分四段）；经验池样本数超过阈值 Ns 才开始训练，容量 ≤10^6；目标网络每 C 时隙更新（C 值未报告）；优先回放切换阈值 kth 与 α 值未报告。

- **评估协议**：训练时假设 V0 内全部数据流活跃；测试含不同 β、不同活跃流比例、连续 50 时隙、三种路由策略各 50 episodes；消融对象为 4 种链路配置而非 RL 组件本身（未单独消融 CS/PER/参数共享）。

## 与选题空间的关系

- **直接对标工作**：本文是"LEO 星座 LISL 动态调度 + 路由 + MADRL"这一选题的 IEEE TCOMM 级标杆：三固定 + 一动态（8 选 1 离散动作）链路模式、跳数-能耗 β 权衡目标、按链路贡献分解全局奖励、CS 压缩状态，构成该方向当前最完整的参照系。若选题涉及 LISL 拓扑调度/拓扑控制的 RL 化，本文是必引基线（baseline 应含其 T-shaped / Fixed-4 / Random 三个对照配置与 β 权衡评估协议）。
- **可切入的空白**：(1) 调度与路由是交替迭代（路由用 LP 求解、调度用 DRL），非端到端联合优化——学习式路由 + 调度联合策略仍有空间；(2) 状态仅含链路负载、不含排队/时延实测，Havg 用跳数代理时延，无显式时延保证；(3) 奖励分解在高动态链路密度下系统性高估（R2 下误差最大），可研究更好的 credit assignment（如均值场、差分奖励）；(4) 未消融 CS/PER/参数共享的各自贡献；(5) 训练离线在 GEO 数据中心，策略对流量分布漂移（活跃流比例变化只做了比例测试，未做在线适应/持续学习）；(6) 单一 Walker 星座（OneWeb 型），极区/跨层（MEO/GEO 链路仅作管控面）未纳入调度决策。
- **可复用的机制**：两星同时同意才建链的动作语义（对称动作空间 + 镜像翻转状态）、能耗代理 P0=|Ed|、以 0.5 系数处理双向计数的奖励构造、以及附录 A/B 的几何可行性验证流程（距离/俯仰/方位/转率/干扰角间隔）值得移植到任何 LISL 拓扑优化工作中。

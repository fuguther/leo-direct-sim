# 深化修订草案 F1：路由状态新鲜度合同（非裁决稿）

> 合并谱系：c30b20940a3（toy/增强/ELB 时间戳资产）+ run1-A1/B1/C1/C4；T-C1 为直接前身，按 feedback §1 对账并入 H1/H2/H3【作者解释：历史登记，非价值裁决】。本稿不做新颖性宣称、不做候选排序。

## 1. 场景与问题
- 谁/何时：LEO 星座每颗卫星上的逐包路由决策者（学习 agent 或启发式），在每个包做下一跳决策的时刻。
- 何决定：选出向 ISL 下一跳（NSWE 4 邻，LOZANO/PRIMAL 同构【原文事实】）。
- 何信息：邻居队列占用，经控制信令广告获得；决策时刻该字段年龄 a = 生成到读取的间隔（刷新周期 + 逐跳传播/排队 + 缓存 TTL 截断）。拓扑分量可星历预测，需保鲜的只有队列分量【推演，继承候选卡】。
- 【代码事实】leo_sim：ControlEntry 携带 generated_at/received_at/ttl_s/hops（control.py），控制广告逐跳传播并保留传播时延、排队与带宽消耗（routing.py control_broadcast_children）；capacity 策略首跳用自观测队列、远端用缓存广告、未知队列记为 inf 不假设空闲 → 年龄在平台内天然内生、可计算（now−generated_at）。
- 【原文事实】LOZANO 深读：状态 28 字段含 16 值邻居拥塞编码，但假设每步即时可得，Q 函数从未建模其年龄；PRIMAL 深读：观测无任何年龄语义；CHOU/DONG/HAN 笔记同样记录"零龄假设"。AoI-of-state 空白在多篇独立深读中复现（受 feedback §5 约束：地面网 stale-info 与 LEO AoI 检索重跑义务未清，不写"未见先例"）。
- 哪条困难影响指标：Δ 过大→多决策者同时对陈旧拥塞信号过矫正（羊群/herding），重载下溢出丢包升、时延抖动升；Δ 过小→信令与业务争 ISL 容量，挤占到达率。两条都打到到达率或时延。
- 为何值得关心：【原文事实】PRIMAL 表 I 全部学习算法丢包 0.00%，收益只落在排队时延（17.6→4.8ms）；其合同 ISL 仅 50Mbps、缓冲 16Mbit——到达率差异空间是合同工程出来的。年龄是现役方法共同的未测量隐式常量，其敏感度从未被报告（WEIL 深读：消息每步刷新=隐式年龄旋钮，无 age↔性能实验【原文事实】）。

## 2. 原因（分层标注）
- 竞争解释集（T-C1 并入【作者解释】）：H1 瓶颈位置决定年龄价值 / H2 流量突发决定队列时间常数 / H3 信令成本投影决定 Δ 下界。
- 杀手解释①（认真对待）：ISL 传播 ms 级 ≪ 队列时间常数，年龄从不重要。【原文事实】600km 邻星单向传播约 2–10ms；PRIMAL 排队时延 4.8–17.6ms、E2E 约 60ms。【推演】一跳邻域内两者量级接近，杀手①不显然成立；但多跳广告年龄 ≈ 跳数×(刷新+传播+排队) 可超 100ms【推演/待证】，越阈位置必须测量。
- 杀手解释②（认真对待）：Gbps 级 ISL 下信令开销可忽略。【推演】LOZANO 合同（26GHz/500MHz）下队列字段信令占比极小，解释②可能成立；同一信令在 PRIMAL 合同（50Mbps）下占比放大约两个数量级——开销可忽略与否是合同依赖量，不能先验全称排除，也不能全称成立。
- 杀手解释③：到达率无差异空间。【原文事实】PRIMAL 表 I 学习算法丢包全 0.00% 而 SPF 丢包 84.8%：差异空间可以被合同造出，也可以被合同造没。【推演】造差异空间 = 缓冲×负载网格使丢包率落 (0,1) 开区间；全 0 合同只配报告时延结论。
- 事实/推理/假设分界：上引标注；H2 突发→时间常数变小→年龄价值升高目前只是【假设/待证】，无库内直接证据。tao25 flapping 实证锚——未核实：本库 notes 无此条目（仅 SONG-2014-TLR 记有"防乒乓防守机制"【原文事实】，可作同义弱锚），候选卡该锚在取证前降级为【作者解释】。

## 3. RL 改动（三层不可互替，逐层走通）
- 层①测量/相图层：不改策略、不改观测、不改训练；唯一改变=实验合同，把 a 升格为一等受控实验变量（Δ × 量化位数 × 负载 相图 + 陈旧值 vs 年龄修正预测对照 + 最优 Δ 是否随负载移动）。决策走通：固定 capacity 策略，注入年龄 {0,1,2,5} 拍重跑同一 trace，比较到达率/时延。学习更新走通：本层无学习，明确如此。信息/容量/预算：均不变。
- 层②观测/策略层：智能体=每星独立 DDQN（沿用 learning.py TensorflowDDQN，cfg 含 target_update_interval【代码事实】）；观测=现有观测 + 每邻居广告字段的年龄向量 a（=now−generated_at，代码可算【代码事实】）；动作不变；奖励不变（避免与层③混淆）；更新方式不变（DDQN + 周期 target 同步）。一次决策走通：包到达→观测向量追加 a→合法动作 mask→choose() ε-greedy 选下一跳。一次学习更新走通：(s,a,r,s′) 入 replay→采样→y=r+γ·Q_target(s′, argmax Q(s′))→SGD 一步→按 target_update_interval 同步。真正改变=观测信息增加（+每邻居 1 维）；模型容量与训练预算不变，单列说明。年龄课程/增强=训练分布变化，属预算变化，与机制变化分开计数。同等信息对照=a 字段 shuffle 或替换常数：info_ladder_tiny 已有 field_age 可见级与 fixed-age 负对照原语【代码事实】，但其模块自述"不训练 agent、不估算法效应"【代码事实】，扩展进学习管线属待做工程而非已证能力。
- 层③塑形理论层：训练目标改为年龄折扣 drift-plus-penalty，保最优策略集；适用域=重载×大 T_ctrl。独立生死门=Nie25/Hua25b 全文核读（drift 的信息假设）——未核实：两篇均不在本库，未读；本层挂起，不展开、不背书。
- 部署与额外代价：层①零部署代价；层②观测每邻居 +1 维、在线决策时延不变【推演】；层③仅改目标函数。
- 【代码事实/作者解释】ELB 信令年龄注入与 {0,1,2,5} 拍扫描是同一原语参数化（feedback §3）；SatCom-TELMA 无 LICENSE，仅内部复现、不公开衍生【原文事实：LOZANO 笔记】。

## 6. 验证设计（不含实验执行，仅设计）
- 第一核验：年龄注入×负载受控扫描 {0,1,2,5} 拍 × Δ × 量化位数 × 负载，先裁决杀手解释与差异空间前提，再谈策略层。
- 能区分关键解释的比较：
  - H1/H2/H3 三因素：瓶颈位置（ISL 50Mbps ↔ Gbps 合同互换）× 流量形态（Poisson ↔ NHPP 突发）× 信令占用计量；哪个因素扳动曲线，哪个解释得分。
  - 杀手①：广告跳数 1 vs ≥2，观察年龄跨过队列时间常数处性能是否转折；有转折则杀手①被限定域而非全称。
  - 杀手②：同一 Δ 扫描在两种 ISL 容量下画信令占用-性能包络；Gbps 平坦而 50Mbps 塌陷 ⇒ 开销解释成立且合同依赖。
  - 杀手③/差异空间：缓冲×负载网格使丢包率落 (0,1)；丢包全 0 的合同只报告时延/排队差异，不得下到达率结论。
- 结果解释纪律：不预设效果阈值；不承诺阴性结果必有论文价值；阴性（曲线平坦/被杀手解释覆盖）如实记录为该解释的证据。
- 靠文献与推导即可支持的结论：现役方法观测无年龄维度（多篇深读）；差异空间可被合同造出（PRIMAL 表 I）；年龄入状态有邻近先例但非同物（NGAT/Yates）。
- 必须以后测量的结论：年龄-性能曲线形状；最优 Δ 是否随负载移动；杀手①②转折位置；层②相对层①+调参+同等信息对照的净增量；H2 突发假设。

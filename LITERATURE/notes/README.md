# 文献笔记区（像人一样读）

> 登记与核验规则以 `../README.md` 为准。这里只放"读后的收获"，不是摘要库；笔记不是证据，引用/claim 前必须回原文核对。

## 怎么读（两遍法）

1. **第一遍只读论文自己** → 记录来源身份、Question / Claim / Mechanism / Evidence / Assumption / Boundary / Tension，不读取或填写“与本项目实验的关系”；
2. **候选形成后再对账** → 只有完成 `../README.md` 的冷启动问题生成和外部文献碰撞，才可把精读论文与本项目实验对照；
3. **第二遍分开事实和解释** → 明确标出论文原文事实、本项目实验原始观测、历史解释和新的推断，禁止把相似叙事写成同一机制；
4. **每轮读毕** → 更新 `00-READING-QUEUE.md` 与 `../KNOWLEDGE-MAP.md`。候选排序、冻结建议和未经裁决的空白点不写入长期记忆。

## 笔记怎么写（自由，不套模板）

- 第一遍写得像人：第一印象 / 它在问什么 / 声称什么 / 凭什么信 / 依赖什么 / 哪里让我不舒服；不得为了连接旧实验而强行解释论文。
- 可选透镜（科研选题方法论里的 7 项：Question / Claim / Mechanism / Evidence / Assumption / Boundary / Tension）——哪条有用用哪条，不追求逐条齐全。
- “与本项目实验的关系”只允许出现在第二遍对账，并须回答：这是原始观测冲突、边界差异、可行性约束，还是仅仅叙事相似。
- 查不到、没核实的地方显式标注（`未核实:`），宁缺毋假。
- 我的推测要标 `【我的推测】`。
- 每篇末尾一行状态：`> 状态: 摘要|全文；未核实字段: ...`

## 排版约定

- 文件名：`raw/<SOURCE_ID>.md`
- 第一行：`# <Title> (<SOURCE_ID>)`

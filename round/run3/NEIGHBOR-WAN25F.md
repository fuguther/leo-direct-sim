# 近邻核验：Wan25f（NEIGHBOR-WAN25F，主控执行，2026-09-11）

> 对应 C2-v2 §5.5 的指令："主控若推进，应先取 [Wan25f] 全文对表"。本记录为**摘要级对表**（全文核读留作论文写作前待办）。

## 条目

- **Wang & Leung, "Spatial-Temporal Reinforcement Learning for Network Routing with Non-Markovian Traffic"**, arXiv:2507.22174（2025-07-27）。
- 摘要要点（curl 取自 arXiv 摘要页，2026-09-11）：互联网流量是非马尔可夫的，过去状态影响路由性能；常见深度 RL 的函数逼近器不建模拓扑空间结构；提出 STRL（spatial-temporal RL）框架 + 非马尔可夫流量环境；训练收益 >19%、推理 7%，且跨拓扑变化保持。
- 域：**通用通信网络**（非 LEO 卫星）。

## 四要素对表（C2 vs Wan25f）

| 要素 | Wan25f | C2 |
|---|---|---|
| 条件 | 通用网络 + 非马尔可夫流量；拓扑变化 | LEO 星座 + **同均值**突发形状网格（CV/T_on/duty/ρ_ac，λ̄ 锁定） |
| 困难 | 马尔可夫假设被违反（状态缺历史） | 训练/评估共享盲区（过程形状不作自变量）+ 状态读数缺时间语义 |
| 机制 | 时空函数逼近器（改模型架构） | Bellman 更新式不变；改生成器（域随机化）+ 观测向量（Δq/EWMA）+ 评估合同 |
| 决策变化 | 策略网络结构 | 训练分布 + 状态通道 + 协议（同均值守恒校验、瞬态窗指标） |

## 判定

1. **不构成同题覆盖**：Wan25f 无同均值合同（未把均值与形状分离作控制变量）、无过程族域随机化、非 LEO。C2 的三件套（LEO RL 路由 + 同均值参数化协议 + 训练分布/状态通道）未被其覆盖。
2. **但削弱"状态时间语义"的新颖性**："为非马尔可夫流量给 RL 加时间建模"已在通用网络域发表（2025）。C2 的状态件（Δq/EWMA）应如实定位为**已知机制向 LEO 的迁移**，迁移条件（星座周期动态、τ_obs 信令周期约束、逐包逐跳分布式决策）须写明；C2 的差异锚在**协议件与同均值合同**，不在状态件。
3. **对 A3 的影响**：Wan25f 的"观测/历史影响决策"与 A3 的半马尔可夫困难（决策排队时延）相邻但不同因（Wan25f 处理的是流量过程的记忆性，A3 处理的是决策执行时延的负载相关性）。两卡的近邻清单均应列入该文。

# 深化修订草案 B3（v2）｜队列感知价值的负载带塌陷窗：体制切换时的阈值失标定

> 深化者草案，非裁决、不新增实验、不跑仿真。标注：【原文事实】/【作者解释】/【代码事实】/【推演】/【待证】/未核实。
> 继承：T-C2（拥塞感知收益边界条件，命题开放）的机制化切片；历史碰撞审查 run1-B3→② 处置意见。

## 1. 场景与问题
- 谁/何时/何决定：分布式逐包路由，包到达卫星 i 时从 4 邻居选下一跳；负载日模式爬坡或突发 surge 过程中，策略须决定"何时离开最短路绕行"。
- 何信息：本星+一跳邻居队列/负载瞬时值（【原文事实】LOZANO 状态 28 字段含 16 值 log 压缩拥塞编码；LIAQ 状态=坐标+邻居队列+目的地+韧性分）。与 F1 卡不同：不是信息旧，而是 Q 函数在训练分布外的队列区间外推。
- 哪条困难影响到达率/时延：绕行切换点隐含在 Q 值差里，其标定由训练负载合同决定；体制切换时阈值失标定→过早绕行（时延↑）或过晚绕行（丢包/到达率↓）【推演】。
- 为何值得关心：四篇证据共同暗示队列感知价值存在窄负载带，而真实负载恰是连续穿越带边界的：【原文事实】LOZANO 低载与最短路 50th 仅差 1.7ms≈无差异；HE 把 ISL 压到 50Mbps 造出 SPF 84.8% 丢包的极端合同才取得排队时延 -72.7%；LIAQ 主比较设 1Gb/s 队容"隔离排队"且摘要自认 Dijkstra 理想条件时延最低；WEIL 无带宽限制时各方法指标完全相同、带宽受限才分出差异。四者各测带内或带外，**无一测量跨体制迁移的阈值行为**——本卡增量钉死在此（F-II 增量薄死因警示，反馈义务1）。

## 2. 原因：事实 / 推理 / 假设分层
- 文献事实【原文事实】：§1 四锚（均经前轮回原文核对）；另【原文事实】LOZANO 训练默认 ℓ=1 单一负载合同（仅 8 网关实验用 ℓ=0.5）。
- 推理【推演】：单一负载训练→Q 值仅在训练负载附近的队列状态区间被采样更新→改道阈值=该区间内的隐式分界面；部署负载偏离→阈值在从未学习过的状态区间外推→失标定。
- 假设【待证】：塌陷窗在真实参数（LOZANO 合同、Starlink 级 ISL）下存在且有非零宽度——未核实，必须测量。
- 竞争替代解释（认真处理）：
  (a) T-C2-H1 瓶颈位置：塌陷窗只是接入段/GSL 瓶颈伪影，ISL 从未成为瓶颈→本卡无对象（HE 的 GSL 比 ISL 快 20 倍恰是反例参数，但真实星座量级不符【原文事实】）。
  (b) T-C2-H2 利用率临界：窗存在但位于任何运营负载都到不了的区间→窗虽真但不值得关心。
  (c) T-C2-H3 指标伪影：RL 与基线的"窗差异"可完全被指标选择解释（RL 赢在排队时延、输在交付，或反之）→按继承淘汰条件「收益可完全被指标选择解释则降级」处理。
  (d) 调好阈值的显式启发式（ELB/TLR）在体制切换时同样劣化→RL 无相对空间【推演】。
  (e) ZHOU-DTAR surge 已覆盖：其 normal/surge 无交付量化收益、仅 fault 有 pp 级收益【原文事实】——按反馈义务5 作窄带佐证而非否定；域级粒度与逐包逐跳错位，未测阈值行为本身。

## 3. RL 改动（相对 LOZANO 式 per-sat DQN 基线）
- 智能体/观测/动作：均不变（per-sat agent；28 字段观测；4 选 1 下一跳）。
- 训练合同（真正改变的部分①，机制变化）：负载课程/随机化——训练负载在 {轻,中,重,跨体制切换段} 上随机化，替代单一 ℓ=1。
- 评估协议（真正改变的部分②，非学习改动）：隐式阈值显式化——Q 差敏感度分析，提取改道阈值随负载的漂移轨迹，检验跨体制稳定性。
- 奖励/更新方式/网络容量：不变。预算变化：训练步数按负载点数近似线性增加（代价①）；课程引入课程顺序超参（代价②，需记录）。
- 与"信息增加"划界：负载数率入状态是对照臂而非本卡改法；本卡不改观测维度、不加容量。
- 一次决策走通【推演】：包到达→读 28 字段观测→Q(s,a) 四值→argmax 选下一跳；课程训练下该 Q 在多个负载区间都被更新过，切换点位于被采样过的状态区间→阈值不随体制迁移漂移。
- 一次学习更新走通【推演】：包送达/超时得终态回报→逐跳 TD 目标→DDQN 更新；课程下经验回放池含多负载转移样本，TD 误差在各负载区间均下降→Q 差分界面在多区间标定。失标定若成立，课程训练应把交付率-负载曲线的塌陷窗移走且不牺牲带内时延【待证】。

## 4. 直接近邻与简单替代
- 最可能已解决核心问题的工作=ZHOU-2026-DTAR：准确还原其条件与能力——288 星、18 域、GAT 编码链路负载+action-masked PPO、normal/surge/fault 三合同【原文事实】；能力=域级负载均衡与 fault 下成功率 +9.25pp；**不能**=逐包逐跳粒度、normal/surge 无交付量化收益、无跨体制阈值测量【原文事实】。故核心问题（阈值行为）未被其解决，但其 surge 合同是天然的迁移场景模板。
- 负载课程在 LEO 路由内的应用：未核实（LOZANO 的 FL/模型预演处理轨道时变，非负载课程）。
- 简单规则（ELB/TLR 显式阈值调参）：阈值静态、不随负载合同迁移；可覆盖带内部分收益，跨体制段预计同步劣化【推演】——其失标定形态（固定阈值 vs 学习阈值漂移）正是第二对照的判别点。
- 成熟 RL 合理调参（多负载混合训练+多 seed）：与本卡改法①同源，是"调参能解决多少"的基线臂；若它已消除塌陷窗，本卡降级为评估协议贡献【推演】。
- 原方法加同等信息（负载数率入状态）：最强对照（反馈义务3）——若该臂消除塌陷窗，说明瓶颈是信息缺位而非训练合同，本卡并入观测合同问题、按淘汰条件降级。
- "不知道能否胜过"保留：课程训练 vs 负载数率入状态，机制理由——课程修正 Q 的外推误差但不给策略"当前体制"的显式坐标，带边界附近仍可能误判；数率入状态给坐标但学的是条件映射，带内样本少时同样外推。胜负取决于体制切换段的经验密度，无法先验判定【推演】。

## 5. 研究价值与可行性（分开判断）
- 价值【推演】：把 T-C2 开放问句（收益边界条件）变成可判别实验——跨体制阈值失标定是四篇证据拼出但无人测量的具体机制；增量钉在"跨体制迁移的阈值行为从未被测量"（反馈义务1），不依赖工程容易/消融可做。风险：若窗不存在或落在运营区间外（H2），价值收缩为一条边界测量，不承诺阴性结果必有论文价值。
- 可行性：LOZANO 仿真器开源可改（SatCom-TELMA/MA-DRL_Routing_Simulator，155★活跃；**无 LICENSE，仅内部复现、衍生不可进公开仓库**——反馈义务4/【代码事实】笔记级）；leo_sim 已有负载扫描合同（E0/GLOBAL-PRESSURE-BRACKET 系列 profile 存在）【代码事实】；5 点扫描×3 方法为 2 天级【推演】。不做可行性→价值的推论。

## 6. 验证设计（能区分关键解释的比较）
- 主比较：单负载训练×5 点负载扫描×{RL, ELB, SPF} 交付率-负载曲线（反馈义务4）；第二对照臂：TLR、负载数率入状态 RL、多负载混合训练 RL。
- 判别结构：
  窗存在且 RL 与 ELB 失标定形态不同→否定 (d)，支持失标定机制；
  窗处 RL 与基线的优劣势完全随指标切换（排队时延赢/交付输）→触发 H3 淘汰条件，降级（反馈义务1）；
  窗仅出现在 ISL 瓶颈合同（HE 式 50Mbps）而在 GSL 瓶颈合同消失→支持 H1；
  负载数率入状态后窗消失而课程训练不移窗→信息缺位解释胜，本卡降级。
- 不预设效果阈值、不预设窗宽；种子数与置信区间按平台合同（paired 分析），不设"显著即成功"。
- 靠文献与推导可支持的结论：四锚边界条件存在（§1，【原文事实】）；单一负载训练合同是现役默认（【原文事实】LOZANO ℓ=1）。
- 必须以后测量的结论：塌陷窗的存在/宽度/位置；失标定方向（过早 vs 过晚绕行）；课程训练能否移窗；各竞争解释的相对占比——全部【待证】。

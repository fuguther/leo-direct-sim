# 信息阶梯 tiny 合同验证（2026-08-21）

## 这一步验证什么

这不是训练实验，也不是论文结果。它只把“算法在每一级信息裁剪下到底能看到什么”做成可执行的合同，防止低信息臂偷偷读取远端队列、拓扑或字段年龄。

四级视图按协议固定为：

1. `local_queue_direction`：本地队列和方向；
2. `link_rate_availability`：再增加链路速率和当前可用性；
3. `remote_queue_topology`：再增加远端队列和远端拓扑可用性；
4. `field_age`：再增加逐字段信息年龄。

## 可复核证据

实现位于 `CODE/leo_sim/info_ladder_tiny.py`，测试位于 `CODE/leo_sim/tests/test_info_ladder_tiny.py`。运行：

```text
python3 -m CODE.leo_sim.info_ladder_tiny
```

固定两条候选链路后，四级诊断策略的选择依次为：

```text
(0, 1) → (0, 2) → (0, 2) → (0, 1)
```

这只说明每一级确实使用了不同的可见字段。另有两类负对照：

- 打乱远端队列归属，但保持远端队列值的总体多重集合不变；
- 把所有字段年龄固定为同一个值。

测试还会修改底层隐藏字段，确认低信息视图及其选择动作不变。未知信息级别和不适用的负对照参数会直接报错。

## 边界

这个 tiny 模型没有训练、没有真实 M-Lab trace、没有测量信息价值，也没有证明算法优越性。它只能证明信息 mask 和负对照的程序合同成立。下一步必须把相同的信息合同接到真实压力窗口/不可变 trace，再比较 Q0-I、局部最优和实际学习臂；在此之前不能提出“增加某字段必然提升拥塞控制”的论文结论。

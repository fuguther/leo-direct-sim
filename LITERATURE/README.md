# 文献与论文选题区

> **CURRENT-CONTRACT**：本页同时规定文献核验和论文选题的证据防火墙。当前没有已冻结的中心问题、方法路线或创新点。调研摘要、Agent 观点、旧候选和项目实验解释不能自动成为项目指导或科研事实。

## 证据防火墙

论文选题必须依次经过以下四阶段，禁止提前揭示后续材料：

1. **冷启动问题生成**：只读取领域边界、研究对象和科研规范；提出 3 至 5 个可观察现象、未知原因和立即淘汰条件，不排序。不得读取旧中心问题、候选排序、实验解释或平台功能清单。
2. **外部文献碰撞**：优先用论文原文、作者公开版本、出版社页面和官方代码核对候选是否已经被回答。不得用本项目已有工作量或现成功能为候选加分。
3. **本地证据揭示**：候选已经形成后，才读取本项目实验。旧实验只用于反证、边界、测量可行性和成本判断；必须分开原始观测与历史解释，并回答“如果平台没有这项现成功能，问题本身是否仍值得研究”。
4. **廉价 Pilot 与裁决**：只有直接近邻已核、关键变量可测、竞争解释可区分、最小 pilot 可行且成功判据不预设结果时，才允许建议冻结。证据不足时保留候选和下一项核验，不强制推荐中心问题。

任何先接触旧实验或旧候选的执行者都必须声明暴露范围；其产出只能作为有锚定风险的候选材料，不能单独承担选题裁决。

## 文献核验

文献条目记录来源身份、可访问证据、适用范围和核验状态。`SOURCES.csv` 的 `support_level` 只表示当前可核材料完整度，不代表论文结论正确。引用前核对标题、作者、年份、venue/DOI 和原文具体位置。

逐篇笔记和知识地图均为 `SUPPORTING`。它们可以暴露主张、假设、证据、边界和张力，但不得自行推荐、冻结或否决论文中心问题；需要形成选题判断时，必须重新回到原文和上述四阶段合同。

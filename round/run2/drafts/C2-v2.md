### 0.1 与 N1 的区别（摘录 §1 #1：同族·评估合同，工具不同 → 互补关系，须写明）
N1 走**实测标定**（评估环境用真实动态标定），本卡走**过程族参数化**（同均值下把过程形状变成自变量）。互补关系落实为三条：
1. **资产分工**：N1 产真实流量的统计锚（突发强度/自相关/突发时长的实测分布）；C2 的扫描网格 (CV, T_on, ρ_ac) 的范围与先验**必须**由 N1 实测统计定标——没有 N1，网格范围无依据；没有 C2，N1 的单条真实样本路径无法回答控制变量问题。
2. **控制变量**：真实环境是均值与过程形状**捆绑**的一条样本路径，回答不了"等均值下仅改形状，交付率/时延变多少"；同均值扫描正是锁均值、变形状的单因素协议——两卡是评估合同的两个正交轴。
3. **覆盖风险如实保留**：若 N1 的实测环境已含真实突发，C2 的"真实过程验证面"可被部分覆盖；C2 收窄为"参数化扫描面 + 训练分布 + 状态通道"，且把"真实标定过程"仅作为网格外校验点、不作为主张来源。该核实点由主控保留，本稿不关闭。
口径：本稿全部使用"在核验的 N 篇中未见"式表述（见 §2），不做领域级空白声明。

## 1. 三问回答

### ① 现有方法在什么突发条件下为什么做不好？（机制，不是"没测"）

**先立机制（【推演·理论】，每条都可被 §4 实验单独证伪）**。设突发源：幅值 a×λ̄（a>1）、持续 T_on、占空比 duty、均值 λ̄ 锁定；链路服务率 μ，队列容量 B，队列观测/信令周期 τ_obs：

- **M1 瞬时超订→溢出（交付率通道）**：突发期间瞬时利用率 ρ_inst=a·λ̄/μ；只要 a·λ̄>μ，队列以 (a·λ̄−μ) 速率堆积，T_on 内堆积 (a·λ̄−μ)·T_on，超过剩余容量即溢出丢包。**交付率损失由 (a, T_on, B−q_0) 决定，与均值 λ̄ 无关**——这就是"同均值不同突发、交付率不同"的机制核。对照 CBR 同均值：ρ_inst=λ̄/μ<1 恒成立，无堆积。理论上界情形由排队论标准结果背书（M/G/1 平均等待 E[W]=λE[S²]/(2(1−ρ))：均值同、二阶矩不同，ρ→1 时时延随之变）。
- **M2 状态-动作时间错配（摘录 §2 点名的机制）**：逐跳策略读到的 q 是 τ_obs 前的样本；当 **T_on ≲ τ_obs（或 T_on 与 RTT 可比）**时，决策所依据的快照系统性滞后——把"正在恶化"的节点当可用（漏避让）、把"已恢复"的节点当拥塞（过度规避）。退化程度由 **T_on/τ_obs 比值**控制，均值不进入该比值。
- **M3 同质误 herd（振荡通道）**：同区域卫星看到相同 q 读数，突发下读数同步抬升 → 各智能体同时把流量推向同一替代方向，拥塞尖峰转移而非消除；平稳读数（CBR）下这种同步误反应弱。
- **M4 更新错配（学习侧）**：replay 样本全部来自无突发生成器，Q 学到的是"短队列=安全"的平稳关系，突发样本分布外；且 Boyan&Littman（47J2H748，Adaptation"Load level"段 MD L73 逐字）证实负载变化下适应不对称："when network traffic levels were then lowered again, adaptation was much slower"——突发结束后的过度绕行收敛慢。

**在核验的 14 篇中（清单见 §2 表 2）未见任何一篇**：①把 (a, T_on, duty, ρ_ac) 作为自变量扫描；②在状态中加入过程特征（Δq/变化率/EWMA）；③训练分布含多过程族随机化。三个"未见"各有具体载体：CMNCS52M 的负载是外生采样/填充（L89/L97/L177）；SaTE 生成器为 1s 泊松流且只扫均值（L232/L292）；Y2H4NPLU 网关平稳泊松（L44）；UKBSA7WN 单位时间定数包（L89）；42E4NAQU 两种**空间**强度模式（L123）；LZKNZA8B 为 NHPP+确定性正弦调制（L66）——**时变 ≠ 突发**：λ(t) 平滑调制下增量仍泊松、无 T_on/占空比结构，且训练评估同分布。其余 7 篇本次关键词检索未命中流量过程描述（【未命中】，不外推）。

**"没测"与"做不好"的分界（反馈单纪律）**：M1–M4 是机制推演；"现有方法在这些突发条件下**确实**做不好"是【待证】，由 §4 M0/M1 直接裁决。本卡不把"未见测量"当作"做不好"的证据，只把它当作**机制的候选解释集**与**协议的立项理由**。

### ② 拟议改动针对什么原因？（逐机制映射）

| 机制 | 改动件 | 一次具体的决策/学习更新 |
|---|---|---|
| M2 快照滞后 | **状态件**：s_i(a) 增加三维 Δq_τ(j)=q_j(t)−q_j(t−τ)、EWMA_τ(q_j)（半衰期对齐 T_on 网格中值）、（可选）到达计数 EWMA | 决策语义从"q 高→避开"变为"q 高但 Δq<0 且 EWMA 平稳→可用；q 中但 Δq 大且 EWMA 上升→规避"——把瞬时读数升级为带趋势语义的读数 |
| M4 replay 无突发 | **训练件**：域随机化——episode 采样器在 (a, T_on, duty, ρ_ac) 网格抽过程、λ̄ 锁定 | Bellman 更新式**一字不改**：Q(s,a)←Q(s,a)+α[r+γ max_{a'} Q(s',a')−Q(s,a)]，r 仍为 −单跳时延；变的只有生成器与观测向量 |
| M1 溢出核 | **协议件**：同均值突发扫描（CV×T_on×duty×λ̄ 网格，到达计数守恒校验） | 输出"交付率/时延 vs (a, T_on)"曲面 + 冻结策略跨过程退化曲线；这是 M1 的直接测量，也是给混训提供"该混什么"的坐标系 |
| M3 herd | **不在本卡改**（动作端驻留/滞回属 C1 的轴） | 扫描矩阵中作为可观测现象记录（方向切换率），供 C1 消费 |

**什么情况下不起作用（写死）**：(a) 交付率只看长时间平均且瓶颈为容量守恒——同均值下平均到达=平均服务，M1 只重排时延分布、不改平均交付率（故主判据必须是瞬态窗条件指标，平均指标只作参考）；(b) 策略反应时标 ≪ T_on 且 τ_obs ≪ T_on——M2 消失，效应归 C1；(c) 汇聚统计复用把突发平滑（骨干 ISL 趋近泊松极限）——M1/M3 分不出差异；(d) 若 M1–M4 在平台上一阶不显著（见降级条款）。

**诚实降级条款（按主控纠偏指令）**：M1 有排队论背书，但 M2/M3/M4 是否在目标平台一阶显著是【待证】。若实验显示：同均值网格内交付率/时延差异低于 §4 阈值，或差异存在但域随机化即全回收、状态通道无增量——则本卡**如实降级为评估协议卡**：主张收缩为"同均值扫描合同 + 14 篇负载模型审计表"的方法论贡献，不主张 RL 改进。降级判据与触发条件在此写死，不临场辩护。

### ③ 强简单替代为何仍不足？（条件对齐，按机制覆盖比较，不以"易实现"论价值）

| 替代方案 | 条件对齐后的机制比较 | 残余缺口 |
|---|---|---|
| 混合负载训练（含突发混训） | 对 M4 有效（replay 有突发样本）；对 M1–M3 不提供任何**归因**：混训后差异无法指认是形状还是占用率/容量漂移——混淆案（勘误表更正1）是混因素的现成教训；且混训输出不了"同均值形状曲面"，无法回答"哪个突发参数一阶致命" | 依赖本协议件告诉它"该混什么"；与本卡是上下游而非互斥 |
| 在线微调 | 对 M4 部分有效；对 M2 无效——错配在**观测端**（快照滞后），微调改的是参数不是信息通道；且 47J2H748 L73 证实负载变化下适应不对称（上调快、下调慢），突发时标短于适应时标时来不及 | 微调的迟滞本身需要本卡的瞬态窗条件指标才能被**测出** |
| 已有可获得信息（瞬时队列本身） | M1/M3 的信息"在"网络里；但 M2 的缺口是**读数缺时间语义**：同均值下"q=50% 上升中"与"q=50% 平稳"在现有状态里不可区分（42E4NAQU L123 后段与 CMNCS52M L143 的状态定义均只含瞬时 q） | 需要的恰是状态件那三个特征；这不是"另一个方法"，是同一信息通道的补全 |
| 规则路由（ECMP/CA-DRP/最短队列类） | 信息通道与逐跳 RL 同源（瞬时 q），M2/M3 盲区相同；CMNCS52M §VI.D（L225–232）显示规则协议在拥塞场景 NMB 劣于 RL（描述性事实，注意混淆边界） | 规则基线必须进扫描矩阵作对照——本卡协议同时服务 RL 与规则，不是淘汰规则的理由 |

**小结**：各替代方案覆盖的机制与本卡不同或不全（混训→M4；微调→M4 部分；瞬时 q→无 M2；规则→同盲区），且它们的效果**都需要本卡协议件提供测量与坐标系才能被评估**。淘汰线保留（本卡任务书原文）：同均值下 CBR 与 ON-OFF 策略性能无差异 → 本卡无空间，判读阈值见 §4。

## 4. 验证设计

**实验矩阵**（拓扑/容量/队列容量/状态维度全程锁死——E5 混淆纪律；阈值均为本稿提议，待主控批准后冻结）：
- 过程轴：{CBR, ON-OFF} × a ∈ {1.5, 3, 6}（幅值）× T_on ∈ {0.2, 1, 10} s × duty ∈ {0.2, 0.5}；λ̄ ∈ {0.5, 0.7, 0.9×μ}；ρ_ac 二阶段加入。T_on 网格必须横跨 τ_obs（M2 的 T_on/τ_obs 判据：覆盖 0.1×、1×、10×τ_obs）。
- 策略轴：{冻结已训策略跨过程扫描, 每过程重训, 域随机化训练} × {状态=q, 状态=q+Δq+EWMA}；规则基线（CA-DRP/ECMP 类）同矩阵跑。
- 指标：交付率、E2E 时延 mean/p99、**主判据=瞬态窗条件指标**（突发起点后 [0, 3T_on] 窗口内条件化）+ 方向切换率（M3 观测量）；时间平均指标只作参考（同均值设计下钝感）。
- seed/重复：每格 ≥5 seeds，报中位数与 IQR；同均值校验：每 run |实测均值−λ̄|/λ̄ < 1%，否则 run 作废（fail-loud，防均值轴混入）。
- **M0（半天–1 天，先行步）**：①审计表 14→20 篇补齐（字段：过程族/强度可变/是否报告 CV·自相关·突发时长/状态是否含过程特征/训练-评估过程是否分离）；②1 个已训策略同均值 CBR vs ON-OFF 冻结对照（复用 A1 线的 SatCom-TELMA Poi(5) DQN checkpoint，如主控认可跨卡复用）。
- **M1（1.5–2 天）**：ON-OFF 扫描 + 冻结 vs 重训差值（差值=过程失配可回收部分）；同时检验 M1–M4 各自的特征签名（M1：溢出率随 (a,T_on) 上升而均值不变；M2：误差率随 T_on/τ_obs 下降而上升；M3：方向切换率突增；M4：域随机化训练后残余差异缩小）。
- **M2（2 天）**：2×2 域随机化 × 状态三通道，分离"覆盖可回收"vs"信息通道可回收"。
- **判读规则写死**：同均值同占用率下全部网格格点交付率差 <2% 且 p99 时延差 <5% → 触发淘汰线（本卡无空间）；任一格超限 → 进入 M1/M2 归因；若仅域随机化全回收 → **降级为评估协议卡**（见 §1② 降级条款）。
- **负结果预案**：N1 无差异→按淘汰线终止，登记流程内证伪（边界=网格范围）；N2 差异存在但域随机化全回收→协议卡+训练分布卡收窄；N3 状态通道回收大头→与 C3（快照信息可辨识性）合并对账。

## 5. 最近邻差异（四要素：条件/困难/机制/决策变化）

1. **LZKNZA8B（Spatial-Temporal Learning-Based Distributed Routing，2026）**——库内最近的过程模型。条件：NHPP 周期调制负载的分布式路由。困难：拍周期序列建模，未问过程形状本身值多少。机制：序列网络提取时空特征。决策变化：λ(t) 是确定性平滑调制、增量仍泊松（E12）——**时变≠突发**；本卡把形状参数化为同均值自变量并冻结扫描。
2. **JLF7IEBQ（SaTE，2025）**——核验范围内唯一见到多档均值强度扫描的评估侧工作。条件：TE 求解延迟与满足需求。困难：计算时延在线化。机制：异构图 GNN+17ms 推理。决策变化：只扫均值（E8）；本卡锁均值扫形状、指标换成到达率/时延。
3. **CMNCS52M（2026）**——反面教材兼最近邻。条件：三种队列分布模型下的 MARL 路由。困难：时变空间负载下 RL 优于规则协议（描述性事实）。机制：DQN-LSNR 状态+奖励工程。决策变化：负载是外生采样/填充（E1–E3）且协议混改 5 变量（E5）；本卡是它的单因素修正案。
4. **42E4NAQU（Queue-Aware MARL，2026）**——信息通道最近邻。条件：队列感知状态（瞬时 q）+ 两种空间模式。困难：韧性指标下的路由。机制：DRL 逐跳决策。决策变化：过程轴缺失（E11）；本卡状态件是其直接升级件。
5. **外部两例（【外部线索】，Undermind 题录，未读全文，不入承重）**：[Shi03] "The Performance of Routing Algorithms under Bursty Traffic Loads"（2003，非卫星域）——"突发负载下评估路由"作为命题早已存在；[Wan25f] "Spatial-Temporal RL for Network Routing with Non-Markovian Traffic"（2025）——非马尔可夫流量×RL 路由的近邻信号。**含义**：本卡增量必须钉在"LEO RL 路由 + 同均值参数化协议 + 训练分布/状态通道"三件套；主控若推进，应先取 [Wan25f] 全文对表。

## 6. 反证与边界

- **反证 1（最强自我约束）**：CMNCS52M 五变量混淆（E5）。本卡扫描若不锁容量/占用率/状态维度，将复刻同一错误——§4 已把锁死清单写进合同。
- **反证 2（外部存在论）**：[Shi03] 等表明"突发改变网络性能"是老命题。本卡贡献**不是**发现该现象，而是把它转成 LEO RL 路由的训练/评估合同并给出可判读协议；若机制链 M2–M4 被证一阶不显著，按降级条款收缩为协议卡。
- **适用边界**：(a) 低占用区（λ̄≪μ）M1 效应小（E[W]∝1/(1−ρ)），分辨力集中在高占用区（网格 0.9 加密）；(b) 统计复用平滑：汇聚流大且独立时骨干 ISL 趋近泊松极限，M1/M3 被抹平——应保留"接入侧突发、骨干侧平滑"分层设定；(c) T_on ≫ 策略反应时标时效应归 C1（瞬态窗轴），两卡以 T_on/反应常数比分界。
- **失效条件汇总**：同均值校验失败（均值轴混入）；瞬态窗条件指标缺失（主判据钝感）；N1 实测证明真实流量在相关时标近似泊松（此时本卡降级为合同完整性论据——鲁棒性合同仍成立，科研叙事弱化）。
- **口径纪律（重申）**：全部"未见/未命中"仅指本次检索与 14 篇核验范围；B-01 只作流程事实登记（§0.2）；N1 覆盖风险核实点由主控保留（§0.1）；摘录之外的淘汰项一律未引用。

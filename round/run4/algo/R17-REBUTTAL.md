# R17 反诘与方案修订（主控亲验，2026-09-11）

> 来源：B9 批次附录 R17——**分通道惩罚 = 往奖励里塞两个 subgoal，可能被钻空子**。
> 处置：主控回原书逐字核验 + 回 TD(lambda) 理论章补读（补上 B9 自报的唯一硬缺口）→ 据此**修改设计优先级**。

## 1. 反诘的原文（Sutton & Barto，逐字，L1010）

> "It is thus critical that the rewards we set up truly indicate what we want accomplished. In particular,
> **the reward signal is not the place to impart to the agent prior knowledge about how to achieve what we want it to do.**
> For example, a chess-playing agent should be rewarded only for actually winning, not for achieving subgoals such as
> taking its opponent's pieces or gaining control of the center of the board."

L4588 另有 **deadly triad** 警告（函数近似 + bootstrapping + off-policy 三者并用必不稳定）——LEO 逐跳 RL 路由三者齐备。

**判定**：反诘**成立且致命**，直接命中 DESIGN-CAUSAL-CREDIT.md 的**级别 1/2**（把 -psi 拆成两路惩罚）。
理由：1[决策缓存溢出] 与 1[转发队列溢出] 是**达成目标的手段**（how to achieve），不是目标本身（到达率/时延）。
按原书立场，正确做法是**只报后果**，让 agent 自己学出归因；拆通道等于把我们的因果假设**灌进奖励**。

## 2. 主控补读：TD 理论章的收敛前提（6C843JTS 第 4 节，B9 自报未读）

- 4.1 逐字：收敛性证明的对象是 **"data sequences generated by absorbing Markov processes"**，即 "each next state depends only on the current state"（L200-202）。
- 4.2 逐字讨论 "optimal" 的歧义与 a priori 假设不可辩护（L338-344）。
- **推论**：TD(lambda)/TD(0) 的收敛保证建立在**马尔可夫性 + 吸收过程**之上；LEO 逐包路由的**部分可观测 + 半马尔可夫 + 非平稳**（多智能体独立学习）**同时违反这三条前提**。

**这一条同时削弱"级别 3（跨跳信用回传）"的理论支撑**：多步/资格迹类方法（GAE、TD(lambda)）的收敛论证都在马尔可夫框架内。

## 3. 据此的方案修订（不是措辞修补，是改设计）

### 修订 1：级别 1/2 降为**诊断工具**，不作贡献本体
- 两个通道标签仍**测量**（属评估口径），但**不再作为奖励项直接灌入**。
- 若要用双通道，必须走**约束式**（primal-dual，如 39NJWBI7 的 lambda_k 更新，L304 逐字："increases the multiplier if the estimated cost exceeds the threshold...thereby strengthening the penalty on costly actions"）——约束式把"不超过阈值"作为**目标**（合法），而非把"该怎么绕"作为手段（被 R17 禁止）。

### 修订 2：主张从"改奖励"移到**改观测语义**（对 R17 免疫）
- 原书禁止的是**往奖励里塞 how-to**；**没有**禁止把"可归因的信息"放进**观测**。
- 锚件里 Theta_i（转发队列）与 Omega_i（邻居决策队列）**本来就在观测里**（L204 逐字）。
- 因此：把"本包从哪个队列被丢弃"作为**观测的一部分**（而非奖励的一部分），让 agent 自己学出两个原因的不同规避行为——符合原书立场，且仍是算法改动（改的是观测语义与可辨识性，不是目标函数）。

### 修订 3：新增**失败原因作为可观测变量**的形式化（主推方向）
    o_i(t) = ( Phi_i, B_i, Theta_i, Omega_i, d_drop_i )
其中 d_drop_i 是**本星本地可得的离散标签**（0=无、1=决策缓存溢出、2=转发队列溢出），**零新增信令**。
- 奖励**保持原样**（式 14 的标量 -psi 不变）→ 不违反 R17。
- agent 要学的是**条件化的规避策略**：同样的队满读数，在不同致因历史下应有不同动作。
- **可证伪判据**：若加 d_drop 后策略行为与基线无差异（或 PDR/时延无改善），则"可辨识性"假设死，退化为纯测量贡献。

### 修订 4：把 R17 的反诘变成**方案的一个对照臂**
- 臂 A：奖励分通道（**预期被 R17 削弱**——用来实证"奖励灌 how-to 是否真被钻空子"）；
- 臂 B：观测加致因标签（本方案主推）；
- 臂 C：约束式（primal-dual，合法但有额外超参 lambda_k）。
三臂并跑，本身就构成"如何把归因信息交给学习器"的**方法学答案**。

## 4. 对其他两条主张的影响

- **C2（状态时间语义 + 训练分布）**：同样对 R17 免疫（改观测与训练分布，不改奖励）→ **相对地位上升**。
- **B3（负载课程）**：同为训练侧改动，免疫。
- **结论**：R17 把候选排序**从"改奖励最硬"翻转成"改观测/训练最稳"**——一次真正的判断变化，起因是我把"算法贡献"误等于"改奖励"。

## 5. 诚实声明

- 修订 1-4 是**主控基于原书逐字与 TD 理论章作出的**设计调整，尚未经对抗审查与实验；R17 的强度在于它来自教科书立场而非某篇论文的个别结论。
- 本文件不主张"分通道惩罚一定失败"——它主张：**该做法违背原书明确建议，若采用必须自证不被钻空子**，而 B9 实测本库 11 篇通用 RL 文献**无一篇提供此类保证**。

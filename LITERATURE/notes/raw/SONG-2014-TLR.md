# TLR: A Traffic-Light-Based Intelligent Routing Strategy for NGEO Satellite IP Networks (SONG-2014-TLR)

它在问:没有全局视野的 NGEO 星座路由器,能不能只靠眼前一两跳的队列占用(红绿灯)做出接近全局最优的实时绕行。答案是"预规划+实时微调"的折衷:数据包沿预计算路径走,途中看中间节点的灯色动态改道,配 Public Waiting Queue 摊平缓存,还专门设计了防死循环的防守机制——说明作者自己也意识到分布式贪心改道容易乒乓。证据是 NS2 仿真,指标为丢包率、流量均衡、吞吐。不舒服之处:固定阈值灯色、流量模型、对比基线公平性都只在文中提及,统计严谨性(seed 数、置信区间)不可考。与我们:它正是我们 F0 层"局部队列信息"的经典极端版——我们的双 seed 事实是加局部队列改了约 1/3 ISL 路径但交付率零差异,而 TLR 恰恰押注这种信息有用,可直接作对照基线,验证信息阶梯的边界。【我的推测】它的"多径分布+绕行"在 ISL 利用率 <3% 时不会有增益,与我们的零差异吻合。未见公开代码(未核实)。

# 对抗第 2 轮·生长汇编：实验设计要求（并入各候选卡）

> 来源：adjudication/round2.md 的 26 条收窄。概念框架不再变动；以下设计要求直接进入 A5 选题卡的"实验设计"字段。

## F-I v2 设计要求包
1. ρ 向量锚点声明为"时标类别地标"，不主张同栈嵌套；15s 重配置归分母侧（语义修正）。
2. 相图多轴声明（ρ×尺度×R_sync）或限定单轴适用域；崩塌带标"假设区"。
3. ρ 含时延异构度参数（非仅均值）。
4. 归因分解用析因设计（含交互项）；不可分离时报告"联合落差"。
5. 行为环境用连续时间事件调度，重配置注入与快照步进分离。
6. 全程记录观测状态年龄（R1 继承）。

## F-II v2 设计要求包
1. 谱检验先出数据集构建方案（24h 窗口×Nyquist 或限定可检测频带）；"轨道周期成分"锚定过境/可见期时标。
2. 天气协变量（WetLinks/2603.14008）；来源分解表 ≥4 格（15s/轨道/昼夜/地面段）。
3. 击穿语义：队列 drain→E2E 换算链；锚点带版本有效期；口径加太阳风暴/区域遮挡。
4. 资源紧张度统一化以"与实测击穿相关性"为评比准则。
5. 固定 vs 按需建链：声明单侧仿真锚定（10375570 + taes.2024.3415571）。

## F-III v2 设计要求包
1. 双锚点按坐标格分置（快照伪影 vs 接触计划记账），不并轨。
2. 连续参考系：留出验证（未标定独立实测窗）。
3. 流量分析用连续谱/小波，bin 选择鲁棒性检查。
4. 模板对照前先重校 2605.04448 基线。
5. 证据分级声明："Δt 单轴已验证，层×指标双轴待验"。

## N1 设计要求包
1. 冻结下层协议栈（CC/切换固定）隔离路由层效应。
2. 代表方法选择准则前置：性能梯队×方法族×可复现性三级 + 可得性偏置声明。
3. 流量项 = "实测统计构造"，归因与合成模型假设解耦声明。
4. 比较器集合前置冻结：解析最短路径 + 调优 OSPFv3 + 平凡固定规则 + 原文基线；结果按对比较器集合敏感度报告。
5. 保真度变化与配置变化分因子消融。

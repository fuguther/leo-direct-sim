# 文献笔记区（像人一样读）

> 登记与核验规则以 `../README.md` 为准。这里只放"读后的收获"，不是摘要库；笔记不是证据，引用/claim 前必须回原文核对。

## 怎么读（两遍法）

1. **先过摘要/书目** → 在 `00-READING-QUEUE.md` 记分级（A/B/C/D）与状态；
2. **再精读全文** → 只有筛选出的精读队列才读全文；
3. **每轮读毕** → 更新 `00-READING-QUEUE.md` 与 `../KNOWLEDGE-MAP.md`；跨会话必记的结论/决策/空白点进 `~/memory`（完整卡片不进记忆）。

## 笔记怎么写（自由，不套模板）

- 写得像人：第一印象 / 它在问什么 / 声称什么 / 凭什么信 / 依赖什么 / 哪里让我不舒服 / 和我们实验的关系。
- 可选透镜（科研选题方法论里的 7 项：Question / Claim / Mechanism / Evidence / Assumption / Boundary / Tension）——哪条有用用哪条，不追求逐条齐全。
- 查不到、没核实的地方显式标注（`未核实:`），宁缺毋假。
- 我的推测要标 `【我的推测】`。
- 每篇末尾一行状态：`> 状态: 摘要|全文；未核实字段: ...`

## 排版约定

- 文件名：`raw/<SOURCE_ID>.md`
- 第一行：`# <Title> (<SOURCE_ID>)`

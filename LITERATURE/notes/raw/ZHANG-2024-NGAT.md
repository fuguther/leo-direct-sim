# Graph Attention Reinforcement Learning for Multicast Routing and Age-Optimal Scheduling (ZHANG-2024-NGAT)

> 来源: https://arxiv.org/abs/2404.18084（2024 preprint）

它问的是组播路由（Steiner 树）与调度的联合优化如何最小化期望平均 AoI，用分层 RL 把两级决策拆开，图嵌入用带收缩映射证明的 NGAT。声称比传统组播算法最高快 9.85 倍，近似比 1.1–1.3 与 SOTA 相当，且在 AS-733 等四个数据集上泛化到未见拓扑。证据：四个数据集上的仿真。注意它的 AoI 仍是接收端数据龄，与 LUR 同类，和我们的"路由状态年龄"空白无关。真正与我们相关的是两处机制：NGAT 的归一化+收缩映射为图注意力的稳定性提供了理论抓手，值得移植进我们 GAT 臂；分层路由/调度拆解与我们的联合路由-调度方向结构相似（但它是集中式分层，我们是一体的）。非 LEO、有线 ISP 图，方法价值大于应用价值。摘要之外的分层细节与超参未核实，精读 arXiv 全文可补。

**评级**：B

## 全文深读（2026-09-03 补，ar5iv 全文）

**方法骨架**：目标=组播调度+组播树联合最小化期望平均加权 AoI，长时能量预算约束（III-E OP Eq.9），拉格朗日对偶化（Eq.10）。AoI 定义（III-C Eq.3-4）=**接收端数据龄**（包到达则更新为包龄，否则+1；平均加权 AoI Eq.5，加权峰值龄 Eq.40）。分层 RL 拆解（IV-A）：P1 调度子问题（每次选目的节点子集）+P2 树生成子问题（Steiner 树），λ 为跨层信号；调度 MDP（IV-B）：状态=图+6 维节点特征（类型 one-hot 3/AoI/加权重要性/在传包数），动作=目的节点幂集（2^|U|→Bernoulli 连续动作采样），奖励=g(λ,U′)；树生成 MDP（V-A）：虚拟时标 τ 下逐节点增量建树，借鉴贪婪 meta 算法；NGAT（V-C Eq.27）归一化图注意力，**Theorem 1 证明收缩映射**；A2C（V-D），actor AdamW lr 1e-3 / critic lr 1e-4（附录 Table IV），端到端联合训练（V-F Alg.3），λ 逐时隙更新。
**实验合同**（VI-A/B）：SteinLib I080/160/320/640（100 例/集，80 训练/20 测试，已知最优算近似比）；调度实验 |V|=80 全数据集，10% 目的节点，边代价随机 {1..10}，**仅 I080 训练、AS-733/ER/BA 只测试**（泛化设计），50 时隙/图；能量预算 C̄∈{1..20}；基线 Random/Greedy（超预算强制选空集）+ IRR（理论界 ln4+ε≈1.39）+ MST + TG-MLP；指标=平均加权 AoI、加权峰值龄；对比 9.85× 计算效率（口径未给），近似比 1.1–1.3。无 LEO 星座。
**与我们对账**：① AoI-of-state 空白——该文 AoI 仍是接收端数据龄（与 LUR 同类），非"路由状态信息年龄"；但调度状态特征**含 A_u(t) 与在传包数**，说明"把年龄放进决策状态"有先例，只是他们的年龄是优化目标而非状态新鲜度——我们的空白依旧成立，且动机可借其先例。② 结构对照——"调度(选目的)+路由(建树)"跨层拆解≈我们"holding/access+ISL 路由"联合优化的形状，且 λ 把路由成本回传给调度层，正呼应我们 holding 瓶颈：上层决策必须感知下层路由代价；但他们是集中式分层，我们一体分散。③ F0/F1——图嵌入消融 TG-MLP vs TG 对应我们的 F0/F1 阶梯，但度量是组合近似比非交付率；无交付/负载指标，无法直接对照零差异结论。
**可复用**：NGAT 归一化+收缩映射（Theorem 1）可移植我们 GAT 臂做稳定性论证；调度状态特征模板（AoI/在传包数入特征）支持"信息年龄入状态"动机；λ 跨层信号机制。**危险**：**摘要称降幅 25.6%/29.2%（avg AoI/peak age）与结论 21.1%/29.7% 不一致**——数字未对齐；9.85× 无口径无表格；近似比 1.1–1.3 为经验值与 IRR 理论界口径不同；合成图边代价随机 1..10 与 LEO 拓扑距离远；未报 seed/方差；超预算强制空集使基线比较偏向 RL。

## 卡A 队列状态的信息龄没有进入观测:陈旧邻居状态下的过矫正振荡

1) **场景与可观察现象**:卫星 n 在包到达时刻 t 选下一跳;可用的邻居队列/拥塞状态是 t−Δ 时刻的快照,Δ=传播(ISL 千至数千 km,单跳毫秒级,量级为本人估算【推演】)+对端排队+周期性状态更新间隔。LOZANO-2025-CONTINUAL 原文明确邻居拥塞向量"can be updated periodically",但从未给出周期、也未把龄期喂给代理【原文事实:arXiv 2405.12308 DRAFT版 §IV-A "The feedback needed by agents is minimal" 段;28字段状态=16拥塞+8邻居坐标+2本星坐标+2目的坐标,§III】。可观察:仿真日志对每条决策所用状态打时间戳→统计"决策时队短、执行时已满"条件概率、下游链路负载的极限环(切换频率/振幅)、age 分布对误判率的条件曲线;现象与到达率(误入满队→溢出丢弃)和时延(振荡绕行)直接挂钩。

2) **困难与原因假设**:【推演】多个上游节点看到同一"短队列"并同时转入(羊群),随后同时转出——tao25 引 Tanenbaum 描述的 flapping 在多智能体学习下被放大:陈旧观测使 TD 目标与策略梯度相对当前网络有偏,且"其他代理在学"构成非平稳;机制层面=部分可观测×多智能体非平稳的复合失败。【原文事实:tao25 §1 p.1-2:"two routers sharing two links simultaneously notice that one of the links is not congested and both attempt to use it...oscillating between the two links — flapping"】。竞争解释:①不是陈旧性而是奖励对切换不对称(进慢链被罚、退出无成本);②是 ε-greedy 探索噪声而非信息龄;③拓扑周期性本身产生周期性拥塞,与决策机制无关。三者均可在同一日志上判别。

3) **拟议改动**:改观测+训练环节:给每条邻居特征打时间戳,把 age 作为策略输入(age-conditioned policy);训练时按龄对特征加噪/衰减做数据增强。机制:策略学会对老信息降权→减少过矫正切换→少误入满队(到达率↑)、少绕行(时延↓);若 age 特征无增益,则得到"该信息价值可忽略"的否定结论,同样可发表。

4) **初步近邻**:WEIL-2024-RMP 把消息刷新速度当通信开销旋钮,从不量化陈旧损伤【原文事实:§3.1 "increased number of iterations...information to traverse the network faster but also increases the communication overhead";§5 表2:无带宽限制时所有方法与最短路完全打平 2.26/4.39/4.52】;PRIMAL 异步事件驱动,观测无龄期字段【原文事实:表I;§III 观测定义】;KM 记录 stale state AND routing 于 arXiv 检索零命中(2026-09-03)【原文事实:KNOWLEDGE-MAP 检索记录节】;Undermind 语义检索(S1)最近命中为 Bhavanasi2023 与 eligibility-traces 自适应路由(未读),无"龄期条件化策略"命中;泛 MARL 陈旧观测补偿 2605.26286 仅摘要级、非 LEO【摘要】。结论:LEO 逐包路由内的 age-conditioned 观测 未核(本轮检索范围内未见)。

5) **简单替代**:①带滞回的固定阈值规则(TLR 式红绿灯)本身能压乒乓,可解决轻中度负载下的大半【推演;SONG-2014-TLR 笔记:作者自设防死循环机制】;②给 ELB 信令加时间戳+信任衰减=给基线同等信息;③成熟 RL 慢更新+低 ε 也能压振荡。猜想:固定规则在稳态够用,负载阶跃附近的中间带是学习式的残余增益区——未证。

6) **立即淘汰条件**:现实 ISL 时延/更新间隔尺度下,age-aware 与 age-blind 策略的到达率/时延差 < 噪声;或实测 Δ/队列排空时间在全部负载合同里恒 <0.1(陈旧性物理上无关紧要)。

7) **下一项廉价核验**:两队列负载均衡小算例(M/M/1+信息龄 Δ):推导或微仿真"陈旧均衡策略"的振荡幅度随 Δ/排空时间比的增长曲线;一天内可出数,不需要新算法。

8) **来源指针**:tao25.pdf §1 p.1-2;LOZANO-2025-CONTINUAL §III/§IV-A(arXiv 2405.12308 DRAFT);WEIL-2024-RMP §3.1/§5表2;HE-2025-PRIMAL 表I;KNOWLEDGE-MAP.md 检索记录(2026-09-03);Undermind S1。

## 卡B 投递终局对中间路由器不可见:到达率与时延的信用分配断裂

1) **场景与可观察现象**:路径 i→j→k 上,决定"把包放进接近溢出的队列"的是 i(此刻 j 队列尚可),丢弃发生在 k 或 TTL 超时;逐跳代理的奖励只有本地排队/逼近信号,终局(送达/丢弃)不在其视野内。LOZANO 奖励=队列时间+斜距缩减+环路/GSL/不可达惩罚,无投递终局项【原文事实:arXiv 2405.12308 DRAFT §III eq.(5)-(8)】;CHOU 奖励=-(αD+βQ)【笔记转引:2605.02413 深读节,公式已核但本人未读全文;该本地 PDF 文件截断损坏】。可观察:丢弃位置直方图与决策位置的空间分离度;"幸存包均值时延改善而总到达率下降"的指标博弈信号;逐 OD 交付率分解。

2) **困难与原因假设**:【推演】到达率是路径级结果;奖励无终局项时,策略只优化幸存包时延,均衡趋向"热土豆"——把注定失败的包推给邻居,幸存者时延甚至更好、到达率更差(指标耦合下的 reward hacking)。tao25 的对照实验支持"投递惩罚缺失会学错":§3.2 竞争网络中,只有显式加入丢弃惩罚 d=21 后,才学出 p=1/4 的最优随机混合策略(均奖 -10.75),优于两个确定性策略(-22 与 -12)【原文事实:tao25 §3.2 p.5 及图3-4】。其全局终局奖励依赖不现实的即时全网广播,作者自注延迟广播 "does not significantly affect results"——但那只是 3-6 节点小图【原文事实:tao25 §2.1 p.3 脚注1】。竞争解释:①TTL/溢出已隐式惩罚丢弃,无需显式反馈;②瓶颈在表示/探索而非信用;③重载下丢包由缓冲/接入工程决定,路由边际贡献小。

3) **拟议改动**:改奖励+更新环节:逐包沿反向路径回传终局信号(送达:实测 E2E 时延;丢弃:原因码),路径上各节点按剩余跳数/资格迹分摊;或 tao25 式"到达广播+本地资格迹",并把 GPOMDP 视野 τalg=1/(1−β) 与路径混合时间对齐【原文事实:tao25 §2.1 p.3-4,β 的偏差-方差条件】。机制:把稀疏终局转成逐节点信号,使"接下高风险包 vs 推给别人"被正确定价→到达率不掉、时延可控。

4) **初步近邻**:Mao20 arXiv 2003.03433 研究协作 MARL 路由的全局/局部奖励设计与中间方案【摘要,本人未读正文】;Roth-Shaping 研究 MADQN 奖励塑形与收敛量化(时延+负载均衡,集中学习分散执行)【原文事实:Zotero 全文摘要节】;tao25(全局终局奖励+资格迹,2001 经典);PRIMAL 奖励主目标=送达,但其拥塞合同下所有学习方法丢包≈0.00%(SPF 84.8%),交付无差异空间,掩盖了该问题【原文事实:表I】。LEO 语料内未见"逐包反向终局反馈"实现 → 未核(本轮检索范围)。

5) **简单替代**:①成熟 RL 加逐跳溢出惩罚——可能解决大半,但会诱发把丢弃推给邻居(需验证);②D+λ·到达率的多目标加权网格搜索;③给原方法加粗糙全局信号(目的站周期广播送达率)。猜想:①在轻中度负载够用,重载边界失效——未证。

6) **立即淘汰条件**:在"投递率有差异空间"的负载合同(溢出丢包非零)里,加终局反馈后到达率提升 <1pp;或本地溢出惩罚+TTL 已足以复现 oracle 终局反馈的策略排序。

7) **下一项廉价核验**:tao25 §3.2 竞争网络的放大版(加队列动态与丢弃):对比 (a)纯本地时延奖励 (b)+本地溢出惩罚 (c)反向终局反馈 三者学到的(到达率,幸存者时延)前沿;(a)≈(c) 即卡死。

## 卡C 星历可预报性被学习代理闲置:接触窗边界的孤岛陷阱与动作安全掩码

1) **场景与可观察现象**:Walker 网格卫星在 t 时刻选下一跳;星历确定性决定 t+δ 后某方向 ISL 关闭、该侧子网分裂;基于队列的贪心把包送入将断连的子树,包困死到超时。信息条件两类且性质不同:接触窗=确定性可预报(轨道力学),队列=随机——现有学习代理只消费后者(LEO RL 论文普遍把 ISL 当永久存在:PRIMAL 动作=NSWE 4条ISL、无等待/无GSL 动作【笔记转引:2510.27506 深读节】;GRLR 用 4 条稳定 ISL【笔记转引:SOURCES.csv 提示】)。可观察:带 ISL 通断时刻表的仿真里,统计"包进入 t+T 内将失连分量"事件率、此类包的最终交付率/超时分布、丢弃原因三分解(溢出/困死/TTL)。

2) **困难与原因假设**:【推演】学习机制=约束安全×探索代价:该事件稀疏且不可逆(包不能召回),靠经验试错学会"提前别进去"等于让 RL 重新发现一个可解析预报的约束,探索样本被浪费;且困死包持续占用缓冲,恶化他人时延(负外部性)。竞争解释:①+Grid 网格下边界陷阱极罕见,溢出才是主导丢弃原因;②时间维预规划(时间展开图上的最短路)已解决,无需逐包学习;③真正难题是断链瞬间的在途包(in-flight)处理,与选择时刻无关。

3) **拟议改动**:改动作空间+约束环节:从接触计划预计算"未来 T 秒可达目的"的掩码,屏蔽必然困死的下一跳;RL 在掩码内自由学习队列/时延权衡。机制:把"稀疏不可逆事故"从探索问题变成约束满足→消灭一类确定性丢弃(到达率上限抬升),掩码只在必然失败方向生效故时延不恶化【待证】。

4) **初步近邻**:DTN/接触图线:RUCoP(arXiv 2108.07092)把不确定接触计划下的路由建成多副本 MDP,store-carry-forward 语境、非学习、非逐包排队【摘要】;LEO 学习线:QARR 韧性分公式已核但对象是静态失效概率,非接触窗时序【笔记转引:2605.04448 深读节,公式III-C】;ZHOU-2026-DTAR 域划分+PPO【笔记转引】;Stock-2022 纯几何跳数按需路由,全文无 queue/buffer/drop 字样【原文事实:Zotero 全文关键词扫描 0 命中】。两线拼接(接触窗时序×学习逐包路由)本轮检索未核。

5) **简单替代**:①时间展开图上定期重算最短路(非学习)即可消灭此类陷阱,猜想可解决 >90% 的该类丢弃;②给固定规则加"剩余接触时间"检查;③若陷阱事件率本身 <0.1%,任何方案都不值得。猜想:①在预规划范式内确实解决,但其重算周期与逐包自适应之间的空隙(突发期事件)才是学习位置——未证。

6) **立即淘汰条件**:+Grid/Walker Delta 常规参数下,贪心路由困死事件占全部丢包 <0.1%(现象不存在);或掩码造成 >5% 时延劣化(约束过粗,不如不用)。

7) **下一项廉价核验**:在公开 Walker-Delta 合同(如 PRIMAL 1584星参数)注入精确 ISL 通断时刻,跑 SP/贪心基线,输出丢弃原因三分解与边界困死率——一次仿真即可判生死。

## 卡D 活包探索的不可逆代价:突发期"探索还是执行"的门控决策

1) **场景与可观察现象**:突发开始(本地队列增长率跳变)后的第一个决策窗口,代理在"执行已知策略"与"探替代路径"之间选择;探索流量是活包,走错即丢/迟,且改变他人环境(耦合);本地信息无法区分"瞬时突发"与"负载 regime 变化"(需多跳/时间聚合)。tao25 点名 Q-routing 不维持探索、次优策略永久化的经典失败【原文事实:tao25 §1.1 p.2】。可观察:突发窗内探索动作的条件交付率 vs 执行动作;探索引起丢包占总丢包比(探索税);从突发开始到指标恢复的适应时间;固定 ε、退火 ε、门控 ε 三者对比。

2) **困难与原因假设**:【推演】学习机制=探索-安全冲突×非平稳适应的耦合:标准 RL 假设探索可重置,包网不可逆;而适应非平稳恰恰需要探索→冻结策略保守但漂移,持续探索即时损失到达率。竞争解释:①离线训练+冻结+位置条件化(GNN/坐标泛化)已消除在线探索需求(LOZANO 两阶段:离线全局DNN+星上低探索续训【原文事实:§III 两阶段训练】);②固定阈值规则对突发的反应比任何学习适应都快,根本不需要探索;③突发由轨道周期主导,可预报,不需要在线探索。

3) **拟议改动**:改更新/部署环节:探索门控——仅当本地队列占用<θ(安全余量)且该目的近期交付率>阈值时,才允许把比例 ε 的活包作探针;突发检测用队列增长率 CUSUM;或仿真内探索+部署零探索(离线域随机化覆盖突发谱)。机制:把探索代价从"任意时刻的到达率损失"压缩到"有余量时刻的小额损失",同时保留适应能力→突发期到达率少掉、时延恢复更快【待证】。

4) **初步近邻**:2103.12870 全回声 Q-routing+模拟退火控探索率(UAV 网络,非 LEO)【摘要】;XIANG-2025-MATGCIR 用最短路模仿预训练降低探索需求【笔记转引】;LOZANO 在线续训是另一种适应,但不处理探索的到达率代价【原文事实:§III】;PRIMAL 训练用 max-entropy,部署期探索处理未明【笔记转引:2510.27506 深读节】。LEO 逐包场景的"门控探索/探索税"量化 未核。

5) **简单替代**:①TLR/ELB 阈值规则对突发的即时反应大概率优于学习适应【推演】;②冻结策略+坐标条件化在轻度非平稳下可能够用(LOZANO:低拥塞下追平全知最短路,50/90/95 分位差 1.7/3/9.1ms【笔记转引:§VI】);③给固定规则同样装突发检测器(同等信息对比)。猜想:②在单次突发下已够,连续多方向突发才拉开差距——未证。

6) **立即淘汰条件**:冻结策略在注入突发/相位偏移的评估中到达率降幅 <2pp(非平稳不值一打);或门控探索相对固定 ε 在突发期到达率提升 <1pp。

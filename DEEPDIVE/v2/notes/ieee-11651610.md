# 精读笔记：ieee-11651610

**论文**：Graph Neural Network Assisted Deep Reinforcement Learning Based Hierarchical Routing in Mega LEO Satellite Constellation
**作者**：Shenzhan Xu, Rongke Liu, Hangyu Zhang, Aryan Kaushik（北航 / 中国移动研究院 / OUF Innovative）
**出处**：IEEE Transactions on Vehicular Technology（accepted, DOI 10.1109/TVT.2026.3722870）

## 七要素

1. **问题**：mLEO（数千颗卫星）星座中，ISL 段任务路由面临网络规模大、链路时变可用（APT 误差、运行时故障）、以及空间局部化热点流量三重挑战；纯最短路径造成持续热点与级联拥塞，卫星级全局搜索在数千节点规模下同步/分发困难。
2. **场景与假设**：Walker-delta 星座（60 面 × 60 星，N=3600），单网关固定位置、最低仰角 10°；离散时隙（Δt=0.1 s，Tsim=30000）；每 ISL 恒定容量 10 Gbps，带小比例背景流量（ρ_bg≤0.001），预留式资源分配（每任务固定占用 α₀=0.2，阻塞阈值 ρ_blk=0.9）；链路可用性 = 几何可见 × 占用未达阈 × 无运行时故障；store-and-forward；S2G 段仅由出口卫星代表、不单独优化。
3. **方法**：分层路由框架。上层把源卫星→出口卫星的 ISL 路由分解为**区域间路由**：星座划分为 5×5 卫星的 12×12=144 区域（四邻接 + wrap-around），各区域每时隙用内部/边界 ISL 负载统计（p90/均值/标准差等）作节点特征、边界 ISL 负载统计作边特征，经 L=3 层 edge-conditioned GraphSAGE 同步消息传递得区域嵌入；参数共享 PPO-Clip + GAE 策略由当前活跃区域 agent 顺序选四方向动作（上/右/下/左），带可行动作掩码（禁回溯、禁重访、禁不可用方向）；训练用启发式教师引导 warm start（区域图上 cost-aware Dijkstra 参考策略，早期软引导 + 按非教师成功率阈值退火）缓解稀疏成功反馈冷启动。下层**区域内路径**用负载感知 Dijkstra（w = hop 项 + β_load·归一化负载项）构建可执行星间段，实际起始时隙重验证，故障/拥塞触发一次局部修复或边界对重选。目标函数：max −λ_T·T̄ + λ_J·J̄（惩罚时延 + 长期 JFI 负载均衡）。
4. **实验**：真实 TLE + SGP4 传播仿真环境；热点建模为源/出口 patch（边长 8 星，每 600 时隙刷新）采样；对比 GC（3600 节点全局负载感知 Dijkstra）、GGAP（卫星级 GNN-PPO）、No GNN（同层级但手工特征直入 PPO）、HH（确定性距离启发式分层）。稳定链路下本方法平均成功率 0.9980、惩罚时延 9.01 s、JFI 0.9853；运行时 ISL 故障下成功率 0.9410、时延 10.55 s，而 GC/GGAP 在 500 Mb 时成功率分别跌至 0.3613/0.1793；在线规划均值 32.38 ms/任务（AMD Ryzen 7 5800）。消融证明教师引导是收敛的必要条件。
5. **结论**：分层分解 + 区域级 GNN 表征 + PPO 方向决策 + 下层可执行段修复，在成功率、惩罚时延、JFI、HSI 四指标上取得最佳权衡，且对运行时链路故障鲁棒；层级修复结构本身（HH）不足以保证高可达，必须耦合学习到的区域级决策。
6. **局限**：仅单网关；区域划分固定（按轨道面/相位网格）；ISL 容量恒定、任务占用比例固定 α₀ 的简化假设；每时隙仅一个任务；失败惩罚为固定 30 s 常数；训练仍需教师（说明纯稀疏奖励不可行）；未报告泛化到其他星座构型/区域的实验。
7. **可复用资产**：区域特征设计（内部 p90/均值/σ + 方向化边界 ISL 统计 + 边读出）；可行动作掩码三类规则；奖励结构（逐步段代价 + 终局 Rsucc/Rfail）；教师引导 warm start 的自适应退火规则；TLE/SGP4 + 时间索引预留 + 运行时故障注入的仿真环境设计；四条基线的公平对照设计（GC/GGAP/No GNN/HH 隔离了层级、GNN、学习三个因素）。

## RL 领域块

- **建模范式**：单任务路由建为 POMDP M=(S,A,P,r,O,γ)；状态含区域图、负载/链路快照、当前/目标区域、已访区域集、曼哈顿距离；观测仅当前区域的嵌入 + 四方向动作嵌入 + 目标标量 + 访问掩码 + 可行掩码。
- **动作空间**：四方向区域跳转 {Up, Right, Down, Left}，不指定具体边界 ISL 对与星间跳；由下层负载感知 Dijkstra 实例化。
- **算法**：PPO-Clip + GAE(λ=0.95)，γ=0.99，clip ϵ=0.2，value loss clipped 双向 + 熵正则（退火），优势按更新归一化；参数共享编码器（actor/critic 双优化器，critic lr=2×actor lr=0.001）。
- **奖励**：r_h = I_hseg·r_h^run + I_succ·Rsucc/Tep − (1−I_succ)·I{h=Tep−1}·Rfail；r_h^run = −(w_delay·c_delay + w_bal·c_bal)，c_bal 为出边界与邻区内部平均利用率加权。
- **冷启动处理**：TGRL 式教师引导 warm start——区域图 cost-aware Dijkstra 参考策略，以概率 ϵ_T 介入（logit bonus β_T=4），按非教师成功率阈值 ζ_ws=0.3 阶梯衰减 ϵ_T。
- **可扩展性技巧**：区域图编码每回合一次、多步复用；参数共享策略跨 144 区域泛化；在线复杂度 O(N_reg·d_n·H + L·M_reg·H(2H+d_e) + H_max|A|d_p² + 局部 Dijkstra)。
- **关键实证 RL 结论**：lr=0.01 强震荡、≤1e-4 收敛过慢；无教师时两种 lr 下均无法达到可比收敛——大尺度稀疏成功反馈下 warm start 是收敛前提，不是加速项。

## 与选题空间的关系

1. **占位**：本文占住了「区域级分层 GNN+PPO 路由 + 教师引导冷启动 + 下层可执行段修复」在 3600 星规模下的组合位；任何后续 GNN-DRL LEO 路由工作都必须与其 0.9980/0.9410 成功率和 GC/GGAP 对照结果对标。
2. **可攻击的空隙**：(a) 固定网格区域划分——自适应/负载驱动区域划分是明显未覆盖变量；(b) 单网关、固定 α₀ 占用、每时隙单任务的简化——多网关、可变速率任务、并发多任务联合调度仍是开放空间；(c) 教师是「必须品」这一事实本身说明纯 RL 冷启动问题未解，可做离线预训练/图预训练/模仿-微调范式对比；(d) 四方向固定动作空间限制了对角/跨面机动，动作空间设计可扩展。
3. **对本平台（leo_sim）的启示**：其 TLE+SGP4+时间索引预留+故障注入+receipt 式执行时验证的仿真链与本平台「编译→受控执行→回执」的验证哲学同构；其四基线消融设计（隔离层级/GNN/学习三因素）是可复用的实验设计模板；其 HSI（top-1% 链路负载占比）指标可补本平台热点评估维度。
4. **区隔要求**：若本选题做 LEO 路由/资源分配，须明确与本文的差异轴（区域划分方法、多任务并发、奖励设计或真实故障模型），并复用其「未做局部修复的全局法在故障下崩到 0.18–0.36」这一结论作为层级修复必要性的既有证据。

# GRL-RR: A GRL-based Resilient Routing Framework for SDN LEO Mega-Constellations (BAI-2025-GRLRR)

它在问：SDN 控制巨型星座时，域划分与路由在大规模+频繁失效下如何可扩展且鲁棒？声称：级联失效理论建模故障（随机失效→拓扑隔离，攻击→流量过载）；基准拓扑模板+矩形约束快速划控制域；域内「流量拓扑模型」把物理拓扑变化转成流量多样性，GNN-DRL 只控关键链路；Starlink/OneWeb 仿真下路径可靠性 +12.45%、最大链路利用率 -12.92%+。证据：仿真，决策是域级链路权重，非逐包逐跳。不舒服处：「只控关键链路」省算力但漏掉非关键链路局部拥塞，与我们「瓶颈在 holding/接入排队」的观察不同层；可靠性指标定义未给。与课题：级联失效/韧性对应我们 ISL 故障实验的极端场景，失效建模值得读；但集中 SDN 与全分布式逐跳差一个决策层级，只借鉴不基线。

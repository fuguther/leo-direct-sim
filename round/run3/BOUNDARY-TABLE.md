## C. 待探索（本轮真正要回答的问题）

| 探索对象 | 要回答的问题 | 当前证据状态 |
|---|---|---|
| 具体条件 | 哪一种负载变化、在什么范围内造成重要困难？ | 强度/空间多为强度扫描；**时间过程（突发）全库 0/111 同均值参数化**；变化速度无测量 |
| 现有方法不足 | 哪个代表方法做不好？直接证据还是假设？ | A3 有单点实测锚（决策器悬崖）；C2 为合同事实+理论背书；B3 为四锚拼图（窗存在性待证） |
| 原因 | 信息不足 / 目标错配 / 更新滞后 / 训练覆盖不足 / 容量不足？ | 候选原因各有证据与竞争解释，见 CORPUS-HOW-OTHERS-DO 与各深化稿 |
| 改动位置 | 状态 / 奖励 / 更新 / 协作 / 训练方式 / 决策结构？ | 全库改动多在状态与架构；**训练方式与决策结构改动稀少**（S85KQ4FC 流级摊销是少数例外） |
| 学习的作用 | RL 学什么？简单方法为何不能同样解决？ | 多数论文不设"RL vs 强规则/强简单替代"的对齐对照；这是本轮三卡的共同论证义务 |
| 贡献与边界 | 比近邻新增什么认识/能力，在什么条件下成立？ | 见 VERDICT-3CARDS §近似邻差异；边界条件须逐卡写死 |

## D. 使用规则

1. 派发任务时，生成者/深化者收到 **A 段（固定）+ B 段（标注为暂用）**；不得把 B 段当作用户要求写进论证。
2. 任何"改动位置"的提案必须落在 C 段问题上，并说明它改的是哪一环（状态/奖励/更新/协作/训练/决策结构）。
3. 若提案必须突破 A 段任一项 → **单列说明并请示，不得自行改题**。
4. B 段调整须记录：改了什么、依据哪条证据、影响哪些既有结论。

# 精读笔记：ieee-4200818（Reinforcement Learning for Resource Allocation in LEO Satellite Networks (2007)）

**书目**：W. Usaha, J. A. Barria, "Reinforcement Learning for Resource Allocation in LEO Satellite Networks," IEEE Trans. SMC—Part B, vol. 37, no. 3, pp. 515–525+, June 2007. DOI: 10.1109/TSMCB.2006.886173。

## 七要素

1. **问题**：LEO 卫星网络（含 ISL，星上路由）中联合呼叫接纳控制（CAC）与路由的动态资源分配。拓扑随时间周期性切换（快照式准静态拓扑），切换（handover）呼叫需重路由，既有方法的链路代价不反映拓扑变化，导致强迫中断呼叫多；SMDP 精确 DP 求解随规模不可行。
2. **场景假设**：36 节点 LEO 星座（Walker 式，极轨），5 种拓扑（TP1–TP4 部分链路关闭、TP5 全开），每拓扑路径数 3792/3312/3312/3792/4332，可见时间 10 min，稳定拓扑目标概率 0.9；ISL 等容量 C（测试 C=10/30/50 单位）；K 类业务，新呼叫 Poisson 到达（率 λj,N），保持时间指数分布（均值 1/µj），阻塞即丢失；链路状态全局即时可观测（作者承认这在实际中不成立）。
3. **模型**：SMDP。状态 x=[yN(j,r), yHO(j,r)]（每路由的新呼叫/切换呼叫数，容量约束 Σy·bj ≤ C）；事件 ω∈{−1,0,1}^{2K}（新呼叫到、首次切换、后续切换、终止）；动作为拒绝 0 或接纳到路由 r；即时奖励 g=ζj,N（接纳新呼叫）/ζj,HO（接纳切换呼叫）/0；目标最大化长期平均收益 v(π)（式 2），Bellman 方程（式 3）含平均转移时间 τ̄(x,a)。切换事件按"旧路由释放+新路由接纳"联合建模（3 种切换情形，Fig. 1）。
4. **方法（两条 RL 路线）**：
   - **ACSMDP**：actor–critic，Konda 离散时间 actor–critic 首次扩展到连续时间 SMDP（作者称属首次）。随机策略 µθ(a|W) 用 softmax 形式 pθ = exp(B(x,a)+θ(ω,a))/Σexp(...)，B(x,a) 选最大剩余路由带宽（式 9，Table I 对比多种状态表示后选优）；critic 用 TD(λ)+线性近似 Q̃=uᵀφθ，|θ|=M=K+Σnj，|u|=|θ|+1；每节点每拓扑独立训练；更新见 Appendix B（dk、eligibility trace zk、平均奖励估计 ṽk）。
   - **OPI**：critic-only 乐观 TD(0) 策略迭代（扩展自 [11]），二次特征（式 14）：每链路 1+5K 个特征（截距、新呼叫数、切换呼叫数、新呼叫平方、新×切换交叉、切换平方），参数量 |L|(1+5K)；贪心策略按"净增益 = ζj − 链路影子价格之和"（式 15/16）选择接纳与路由；学习按链路级分布式进行；ε-greedy 探索。
5. **训练与评估**：离线训练 + 在线执行；评估运行 2×10⁶ 时间步，结果在 98% 置信区间内；9 个案例（改到达率/带宽需求/奖励结构），ζjN<ζjHO 保证切换优先；对比基线为 DP-SMDP [19] 与 MAXMIN [3]；鲁棒性测试用 ξV∈[0,1] 的均匀乘性流量扰动（ξV=1 对应 0–126 calls/min 波动）。
6. **结果（关键数字）**：
   - ACSMDP 平均净收益比 MAXMIN 高 30.6%–7.1%（各流量场景）；两种 RL 方法合计"up to 56.6% higher average revenue over existing routing algorithms"；与 DP-SMDP 接近。
   - C>20 单位时 DP-SMDP 计算上不可行（超出约两天）；C=10 时 SMDP 计算时间比 RL/MAXMIN 高一个数量级以上，C=20 时高两个数量级以上（1.20-GHz Pentium M, 512 MB RAM, C 代码）。
   - 在线单决策复杂度：OPI O(K·nr·nl)，ACSMDP O((nr+1)·nl)，MAXMIN O(nr·nl)（K=特征数、nr=最大备选路由数、nl=最长路由链路数）。
   - 星上存储：OPI 每节点 Σn K|L|（|L|=拓扑链路数），ACSMDP Σn Mn（Mn=K+Σnj），ACSMDP 显著更省（节点数 ≪ 链路数）。
   - 行为：OPI 选择性拒绝低收益 1N 呼叫保护高收益呼叫；ACSMDP 因聚合状态表示倾向均匀路由；两者对 ξV 流量扰动鲁棒，离线训练参数可直接跨区域使用。
   - 收敛性：OPI 已知有收敛问题 [11]；ACSMDP 收敛性证明在其扩展报告 [21] 中给出。
7. **局限与未来方向**：链路状态假设完全即时可观测（实际更新有传播时延）；状态表示高度聚合（actor 特征只能粗粒度区分网络状态）；探索-利用平衡未解决；正在扩展到大规模网络与链路状态/可用性意外变化的场景；部署需每节点存储所有拓扑的参数并周期/触发式泛洪链路状态。

## RL 领域块

- **RL 类别**：平均奖励 SMDP 下的两条路线——(1) actor–critic（策略梯度 + TD(λ) critic，线性函数近似，连续时间 SMDP 梯度扩展为其理论贡献，Appendix C）；(2) critic-only 乐观策略迭代 OPI（TD(0)，二次基函数线性近似 + 贪心/ε-greedy）。
- **状态/动作/奖励设计**：状态=每路由呼叫占用计数；动作=拒绝或选路由（仅源节点决策，中间节点必接纳）；奖励=接纳即得 ζ（切换奖励高于新呼叫）。
- **函数近似**：actor 特征 B(x,a)=最大剩余路由带宽（min(C−Σxsjbj,·)·1/C 归一）；critic 线性特征；OPI 二次多项式基含新/切换交叉项。
- **训练范式**：离线仿真训练 + 在线查参执行；按节点（ACSMDP）/按链路（OPI）分解学习。
- **理论**：平均奖励 Bellman 方程、SMDP 策略梯度 ∇v(µθ)（Appendix C 推导）、单链（unichain）假设；OPI 收敛性承认理论不足。
- **可借鉴点**：把"影子价格/净增益"作为 CAC 判据的近似 DP 结构；对拓扑快照分片训练参数、按拓扑上传星上的工程化模式；状态表示消融（Table I）方法学。

## 与选题空间的关系

- **覆盖判定**：本文覆盖"星上 CAC+路由的 RL/SMDP 决策"这一经典支线（2007 年前的 RL-LEO 基准线），但**不覆盖**现代深度 RL、DRL+星座大规模仿真、星间激光链路动态、以及学习驱动的波束/功率分配；其"离线训练+按拓扑存参"范式与当前在线适应/泛化研究方向正交。
- **对本选题（leo-direct-sim / LEO 直连仿真）的价值**：中等偏高。可作为 related-work 中"RL 用于 LEO 资源分配的奠基线"引文；其 SMDP 平均奖励建模、影子价格 CAC 判据、状态表示消融方法、以及"DP 不可行→RL 近似"的论证结构可直接迁移到仿真平台的决策层设计；56.6%/30.6% 等数字可作为历史基线参照。
- **等级**：B（经典必引支线文献，非直接方法竞争者；与选题核心重叠在问题域，重叠在方法代际上较低）。

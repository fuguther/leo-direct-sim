## 6. 缺口（三次收窄后的最终版）

### 主缺口 G-B：**状态语义不完整**（对 R17 免疫，落在算法内部）

LEO 逐跳路由的状态 = **瞬时几何 + 队列快照**，缺两类语义：

1. **时间语义**：队列在涨还是在退（34 篇只有 2 篇有，且 0 篇做消融，唯一 EWMA 篇意图相反）；
2. **因果语义**：这次的丢包是**决策资源**不够还是**链路**堵了（0/34；信息已在观测里——锚件 $\Theta_i$/ $\Omega_i$——但从未作为可辨识变量进入状态）。

**为什么这不是"加数据"能解决**：两者都是**可辨识性**问题，不是样本量问题。
- 时间语义：同均值下"q=50% 上升中"与"q=50% 已过峰"在瞬时读数里**不可区分**；
- 因果语义：标量奖励下，两个物理原因**产生同样的学习信号**，策略无法分化规避方向。

### 为什么不改奖励（R17 修订的直接后果）

教材逐字（LJG6ZW7B L1010）："**the reward signal is not the place to impart to the agent prior knowledge about how to achieve what we want it to do**"——把"该往哪绕"塞进奖励是 how-to，会被钻空子。
→ **归因信息应该进观测，而不是进奖励**；让 agent 自己学出两个原因的不同规避行为。这条修订同时让方案与 C2（改状态/训练）在**同一侧**（改观测侧），而不是与"改奖励"绑死。

## 7. 可做选题（一句话 + 机制 + 判据）

> **在 LEO 逐跳 RL 路由中，把"缺失的状态语义"补进观测——时间语义（趋势/变化率）与因果语义（损失归因标签）——并回答：这两类语义各自值多少？为什么简单方法（更多训练、更强规则、阈值调优）不能替代？**

**改动（算法内部，奖励不动）**：
- 状态件 A（时间语义）：$\Delta q_\tau$、$\mathrm{EWMA}_\tau(q)$（半衰期对齐突发尺度）——对 CYMQ2GLA 的反意图设计；
- 状态件 B（因果语义）：$d^{drop}_i \in \{0,1,2\}$（无 / 决策缓存溢出 / 转发队列溢出），**本地可得、零新增信令**；
- 学习器与更新式**不变**（保持 DDQN 基线），确保增量归因于观测语义而非算法族更换。

**三臂消融设计（这是本选题的骨架）**：
| 臂 | 状态 | 目的 |
|---|---|---|
| S0 | 原状态（瞬时快照） | 基线 |
| S1 | + 时间语义 | 测时间语义单独值多少 |
| S2 | + 因果语义 | 测因果语义单独值多少 |
| S3 | + 两者 | 交互效应 |
对照还必须含：**轻量 bandit**（K7U4TYJN 实测比 distributed Q-learning 成本低）、**随机最小跳**（LBMABZJ7 L288 逼近启发式）、**阈值规则**（R5QTFKD2 的最优阈值结构）——否则会被已发表的负面证据击穿。

**可证伪判据（写死）**：
1. S1/S2/S3 与 S0 的 PDR/时延无显著差异 → 语义补全无价值；
2. 因果语义有效但**决策缓存溢出占丢包 <5%** → 无对象，退化为测量贡献；
3. 等容量（加宽隐藏层）的 S0 达到同等性能 → 增量来自容量而非语义；
4. 轻量 bandit 或阈值规则达到同等性能 → 学习无必要（须重述贡献）。

## 8. 与 C2 的关系（不重复计数，也不互相掩护）

| | G-B（本选题） | C2（过程形状） |
|---|---|---|
| 自变量（算法侧） | 状态语义（时间 + 因果） | 状态语义（时间）+ **训练分布**（过程族随机化） |
| 共同点 | **都改状态**——这是同一侧的改动 | 同左 |
| 差异 | G-B 多了**因果语义**（全库 0/34），且不做训练分布改动 | C2 的过程族随机化是训练侧（对齐后需说明为何不能替代） |
| 交集处理 | **合并为一个方案的两件**：状态语义（S1+S2）× 训练分布（T0/T1）→ 2×2 消融，直接回答"哪一件值多少" | |

**结论**：不把两条当竞争题，而是**一个方案的两根轴**。若只保留一根，保留**状态因果语义（G-B）**——全库最空、且有 R17 免疫的实现路径。

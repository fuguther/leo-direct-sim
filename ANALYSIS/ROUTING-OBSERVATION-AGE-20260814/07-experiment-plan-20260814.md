## 一、研究问题（最终版）

低轨卫星逐包逐跳的分布式强化学习路由。现在的算法（一跳、普通深度
Q 网络）效果不好。要回答三个问题：

1. 看多跳（扩大观察范围）值不值？
2. 更聪明的聚合（消息传递、图注意力、带年龄的注意力）能不能比现在
   更好、好在哪？
3. 特征里除了队列和目的地方向，加不加链路带宽、可用性、信息年龄？

最终目标：提出一个更有效的路由算法，并用受控实验证明它有效、以及
为什么有效。

## 二、前提（不再讨论，写死）

- 分布式系统：多跳信息只能靠控制包逐跳转发获得，有传播时延、会过期，
  不是全局全知。这一点 V2 平台已经实现，不需要重新发明。
- 目的地方向必须有：没有目的地信息，包送不到地方。
- 链路会断开、有故障，所以链路可用性是真实存在的状态，要建模。
- 基线 = 现在的一跳普通深度 Q 网络。其他都是实验组。

## 三、三个单因素实验

先一次只动一个因素，每个因素看清楚了，再做下一个；全部单因素做完
之后，如果发现结论打架，再单独补交互实验。

### 实验一：看几跳值不值

- 固定：聚合方式（先用图注意力）、特征、网络层数。
- 只变：跳数，一跳 / 两跳 / 三跳。
- 看：完成率、平均时延、期末积压随跳数怎么变。
- 回答：多跳信息有没有用，还是白花通信和计算。

### 实验二：怎么聚合更好

- 固定：跳数、特征。
- 只变：聚合方式，消息传递 / 图注意力 / 带年龄的注意力。
- 加：基线臂（现状一跳深度 Q 网络）作锚点。
- 看：谁高谁低、差多少。
- 回答：聚合方式是不是关键，哪种最好。

### 实验三：带年龄有没有额外收益

- 固定：跳数、特征。
- 只比：图注意力（不看年龄）对 带年龄的图注意力（看年龄），只差年龄
  这一处。
- 加两个负对照：年龄打乱、年龄设成固定值。
- 看：看年龄是否真的更好，还是打乱年龄也一样。
- 回答：年龄这个信息到底有没有被真正用上。

## 四、单因素做完之后

如果实验一和实验二的结论互相打架（例如图注意力在三跳最好、消息传递
在两跳最好），再单独补交互实验，不把单因素结论硬说成联合结论。

## 五、指标（预设，不临时加）

- 完成率（主指标）；
- 平均时延、最差时延（尾部）；
- 期末还有多少包没送完（积压）；
- 实际注入的流量负载。

时延只统计送完的包，报告时和完成率放在一起看，不单独解释。

## 六、公平性（写死）

- 同一批随机种子、同一份流量，做配对比较；
- 训练种子、流量种子、评估种子分开定义，调参种子与评估种子不重叠；
- 报多种子区间，不报"挑了个最好的种子"；
- 评估协议预设：探索关闭、不挑训练中最好的模型、seed 数和检验方法
  在看正式结果之前冻结。

## 七、依赖与前置

- 平台定 V2，但 V2 现在没有真实的图注意力 / 消息传递网络，只有深度
  Q 网络头加不同的缓存聚合方式。所以实验一、二、三之前必须先补图
  编码器。
- "带年龄"需要逐字段年龄（队列、带宽、可用性各自的年龄），要先做
  数据层改造，否则年龄是假的。

## 八、执行顺序

1. 补图编码器（消息传递、图注意力）；
2. 做逐字段年龄的数据层；
3. 跑实验一（看几跳值不值）；
4. 跑实验二（怎么聚合更好）；
5. 跑实验三（带年龄有没有额外收益）；
6. 若单因素结论打架，补交互实验。

## 九、已知边界（写论文时才用，不阻塞实验）

- 不能主张"首次用图注意力"、"首次用信息年龄"这类宽口径。
- 能主张的窄口径：逐字段年龄 + 跨跳保留源时间 + 年龄作为连续可学习
  可信度进消息聚合，三者合起来、用在低轨逐跳路由上。

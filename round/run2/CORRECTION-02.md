# 后续执行纪律（CORRECTION-02，2026-09-11）

> 来源：Codex 对整改回执的判断。**方向正确；不再加一轮框架改造**。
> 执行方式：连续完成 **深化 → 原文核验 → 替代方法挑战 → 修订 → 比较裁决**，中途不逐条汇报。

## 纪律 1：不硬套 RL 术语（针对 A3）

- **先说明真实困难，再判断需要改变什么**；
- 若**普通缓存、批处理或简单规则**已解决核心问题 → **不得为保题强加学习模块**；
- 换言之：A3 允许被判定为"工程优化问题"而**降级或淘汰**，这是合法结论。

## 纪律 2：三问是研究论证，不是填写模板

必须**分层**，不得混同：
| 层 | 含义 | 不得混淆为 |
|---|---|---|
| **现象有文献支持** | 有人报告过该现象 | ❌"原因已证明" |
| **原因已有依据** | 机制链成立 + 已排除竞争解释 | ❌"现象存在即原因成立" |
| **改动可能有效** | 有机制理由说明改动作用于该原因 | ❌"简单方法做不到" |
| **简单替代仍不足** | 强替代在**条件对齐后**仍不够 | ❌"我们的方法更复杂/更聚焦" |

**判据**：任一层缺失或混淆，该问即为**未通过**。

## 纪律 3：连续执行，不中断汇报

阶段：深化 → 原文核验 → 替代方法挑战 → 修订 → 比较裁决。全部完成后一次性交付。

## 纪律 4：最终交付必须包含

对每条：
1. **哪条值得做**（或"都不够好"）；
2. **依据是什么**（现象/原因/改动/替代四层分别给证据）；
3. **最强反对是什么**（对抗性检查，不是自我免责）；
4. **关键未知是否妨碍现在向老师提出方案**。

**红线**：
- 无实验结果**不**妨碍提出研究方案；
- **但不得**用"实验尚未开展"掩盖**模型矛盾**或**文献误读**。

## 纪律 5：全不够好时

在既有预算内，**依据具体失败原因**探索**下一批实质不同**的问题：
- 不强行保题；
- **不重新盘点整套框架**。

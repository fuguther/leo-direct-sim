# 阶段1 产出的合并与污染检测规范（形式检查唯一依据）

> 执行者：主会话编排者。**本规范禁止主会话向候选注入任何内容**；主会话只做以下形式检查。

## 1. 污染检测（禁词扫描，命中即标记并报告，不静默处置）
以下词汇若出现在盲生成记录中，视为疑似污染（除非在提示词内嵌的白名单文本中本就出现）：
- 内部实验/候选代号：F0、F1、F2、F3、Q0、RQ-A、T1、12-cell、韧性裁决
- 内部现象术语：AoI-of-state、信息阶梯、ISL 利用率<3%、holding/access、改道零差异、瓶颈感知
- 内部文档名：COLDSTART-20260903、ONE-PAGE、KNOWLEDGE-MAP、READING-QUEUE、lit-notes、对账
- 语料内论文代号：GraphPR、GRLR、POMAP、CMADR、PRIMAL、DTAR、QARR、STL、RMP、NGAT（盲生成者无从知道这些代号）
- 内部实体：平台、leo_sim、Control.py、SimPy、M-Lab、280×14、3920 星、Starlink shell1 数值等

白名单内合法出现词：LEO、ISL、GSL、Starlink、OneWeb、Kuiper、路由、拥塞、切换、时延、AoI（仅作为"信息新鲜度理论"类别名）。

## 2. 出生依据核验
每条候选必须声明出生依据；检查它能否映射到：
- W1 方法论的具体条款（六/七/八/十/十三/十六等），或
- W2 背景的具体条目（现象 1-6 或问题类别），或
- "通用公开常识"（须写出常识内容）。
无法映射的出生依据 → 标记"依据不明"，候选按可疑处理，不直接丢弃但需在报告中如实呈现。

## 3. 去重与并排呈现
- 三份记录（冲突异常/假设边界/机制新能力）先各自原样存档（PHASE1-OUTPUT/raw/<透镜>.md）。
- 语义去重由主会话判定（现象的核心对象与机制空间是否相同），形成"候选族"分组；**去重不重写候选内容**，只建索引表。
- 重叠度只用于报告（"N 个独立透镜同时提出"），不用于给候选加分或减分。

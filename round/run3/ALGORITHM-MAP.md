# 算法主体的地图：人家怎么改算法，哪一格空着（ALGORITHM-MAP，2026-09-11）

> 镜头纠正（用户指正）：**主体是算法**——状态/记忆、动作/策略、奖励、价值与信用分配、多智能体交互、训练与适应、决策结构。
> **环境（负载模型、流量合同、评测设置）只是做实验时要盯的条件**，不是贡献本体。
> 证据：全库 111 篇两轮机制关键词扫描（/tmp/algos.txt 口径）+ 各篇贡献句抽取（we propose/contributions 段）+ 承重处回原文。
> 计数说明：关键词计数是**下界提示**（用于找空格），具体断言以逐篇贡献句为准。

## 1. 八支：谁做了什么、占了什么、空在哪

### ① 建模与权限（谁在什么权限下决定什么）
- **占**：每星一 agent 全分布式（Y2H4NPLU、CMNCS52M/DQN-LSNR、42E4NAQU、S85KQ4FC）；集中学习+分散执行（5PYWVRC5/L2VKYTAV 的 CLDC、UKEKU5ZG 的 MARL-JR、J68GU76W 的 GEO 控制器+残差策略）；异步无动作同步（PRIMAL）；集中监督 TE（SaTE、FlexSATE）。
- **空**：**决策资源/决策权限本身没人建模**——"谁有权决定、决策执行要花多少资源"只有 S85KQ4FC 把推理成本当一等公民（流级摊销）；控制面与数据面的权限分离、决策预算约束没有作为建模对象。

### ② 状态与记忆
- **占**：邻居队列/占用（绝大多数）；两跳前视（CYMQ2GLA、5N5LQPPP）；EWMA 速率（CYMQ2GLA，**意图是滤掉短期波动**）；图表示 GNN/GAT/GraphSAGE（9C6HB6AF、XM64YRAW、MXQVNU3P、2FBBURX7、PRIMAL）；时空序列编码（LZKNZA8B）；流表/缓存状态（S85KQ4FC）。
- **空**：**状态的时间语义**（趋势、变化速度、记忆）在"负载过程尺度"上没人设计；瞬时读数为主；无相对/归一化观测；无 age/时间戳；"变化速度"从不进入观测。

### ③ 动作与策略
- **占**：逐跳下一跳（多数）；**流级摊销+触发（S85KQ4FC，全库唯一）**；多径分流（9C6HB6AF、FlexSATE）；分层 RL（2FBBURX7 路由+调度）；残差策略（J68GU76W）；动作掩码（PRIMAL）；机会转发（J68GU76W）；收敛加速（5N5LQPPP 的 Dijkstra 辅助离线、UKEKU5ZG 的 Q 表初始化、PIXWFHAC 分裂加速、53HEEK33 邻域发现）。
- **空**：**动作的时间结构**——动作驻留/滞回/切换代价、决策成本感知的动作、动作空间自适应，均无人做。

### ④ 目标与奖励
- **占**：时延/丢包/吞吐加权（多数）；风险感知分布值+原始对偶 CVaR（PRIMAL）；奖励塑形分析（5PYWVRC5）；**LLM 自动奖励设计（GPLEP83L）**；约束 DQN 安全探索（ZIUBKVPZ）；队列均衡奖励。
- **空**：**损失归因**——奖励是**标量**，"这个包为什么丢"不可辨识（决策资源耗尽 vs 链路溢出）；奖励设计很热闹，但没人碰"同一个标量里混着两种物理原因"这件事。

### ⑤ 价值学习与信用分配 ← **全库最空的一格**
- **占**：DDQN/DQN/Q 表为主流；分布值+对偶约束（PRIMAL）。
- **空（实测）**：**30 篇 LEO/学习法路由论文中，提到"信用分配/损失归因"的只有 PRIMAL 1 篇（且是泛用词），实质做跨跳/跨资源归因的 0 篇**；价值函数在**负载体制迁移**下的泛化/适应也没有任何机制（只有单体制训练）。

### ⑥ 多智能体交互
- **占**：独立学习+邻居信息共享（Y2H4NPLU、53HEEK33）；异步去同步（PRIMAL）；CTDE 混合（5PYWVRC5）；协同奖励（多篇）。
- **空**：**共同信号下的同步反应（羊群）**无人处理；**学到的通信/协商**没有（都是固定邻居信息或集中控制器）。

### ⑦ 训练与适应
- **占**：离线预训练+在线（XLRW7XXN、5N5LQPPP、UKEKU5ZG）；收敛加速（53HEEK33、PIXWFHAC）；训练数据裁剪（SaTE 拓扑剪枝）；自动奖励迭代（GPLEP83L）。
- **空**：**训练分布的设计**（跨负载体制随机化/课程）0 篇；**在线适应/持续学习机制**（LOZANO 在库外，笔记级）；**元学习/快速适应** 0 篇。

### ⑧ 执行与评估
- **占**：时延/PDR/吞吐/负载均衡/风险/收敛曲线；部分有消融。
- **空**：**决策成本进评估闭环**（仅 S85KQ4FC）；**损失双通道记账** 0 篇；**条件化指标**（瞬态窗/体制切换）0 篇；多数论文不设"RL vs 强规则/强简单替代"的对齐对照。

## 2. 空格排序（算法轴）

| 排 | 空格（算法内部） | 空置证据 | 要改的那一环 |
|---|---|---|---|
| **1** | **损失归因 / 信用分配**：标量奖励让"决策资源耗尽"与"链路溢出"不可辨识 | 30 篇学习法路由，实质 0 篇 | **奖励结构 / 价值学习** |
| **2** | **状态的时间语义**：负载过程尺度上的趋势/速度/记忆不进观测 | 无一篇；唯一 EWMA 篇意图相反 | **状态 / 记忆** |
| **3** | **训练分布设计**：跨负载体制的随机化/课程 | 0/30 学习法路由 | **训练方式** |
| **4** | **动作的时间结构**：驻留/滞回/切换代价、决策成本感知 | 仅 S85KQ4FC 碰摊销 | **动作 / 策略结构** |
| **5** | **多智能体同步反应**（羊群/共同信号） | 0 篇 | **协作 / 交互** |

## 3. 按这个镜头重述三卡（贡献落在算法，环境降为实验条件）

| 卡 | 算法主体（贡献） | 环境（实验条件，不是贡献） |
|---|---|---|
| **A3** | **奖励结构**：丢包罚拆双通道 → 信用分配可辨识；**决策结构**：前兆门 + 降级地板（何时调用推理） | 决策器排队物理（星上算力/缓存上限）——用它造出"资源受限"的实验条件 |
| **C2** | **状态**：Δq/EWMA 时间语义通道；**训练**：过程族域随机化 | 同均值突发扫描（协议件）——**按本次镜头，这是实验条件，不是贡献本体**（应降为验证设计的一部分） |
| **B3** | **训练**：负载课程/随机化（与 C2 训练件同族）；**分析工具**：阈值显式化 | 负载体制切换场景 |

**镜头下的排序变化（如实报告）**：论"改动落在算法内部的深度"，**A3 的改动在奖励/信用分配（第 1 空格）**，C2 的改动在状态+训练（第 2/3 空格），B3 与 C2 训练件同族。此前把 C2 列主线，其中**协议件占了较大权重**；按"环境不是贡献"的标准，C2 的贡献应重述为**状态件+训练件**，协议件降为验证设计。

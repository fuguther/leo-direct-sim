## 1. 边角料论证（往死里打）

**论点 1：影响面窄——产出是"判决别人"，消费方只有一个子圈。**
本卡的产出是 H1/H2/H3 裁决（卡 §5），即对池内 47 篇 RL 路由方法结论的复核，不是新方法、新系统、新机制。消费方是：被审方法的作者 + 卫星 RL 路由研究子圈。这个子圈本身偏小（47 篇池内约 20 篇纯合成仿真、5 篇摘要级，evidence-map §1）；引用动力学上，"你的结论不迁移"类论文的引用拉力天然弱于"我提出了更好的方法"。而卡 §12② 自认"环境搭建本身不构成科学结论"——阅读收益完全押在裁决上，裁决对不写 RL 路由的人零价值。

**论点 2：效应量小——被审计的增益本身就小，复核只会得到"小增益是否存活"的小信息。**
池内最强被审对象 2601.13662 的残差 RL 相对 backpressure 仅降低队列 1.6%→16.1%（claim-map C）；2509.14909 的 RL 是回退机制、η≤0.4 时激活率 <1%（claim-map B）；2604.12382 胜 Dijkstra 9.25pp（claim-map B）。H1"反转"的信息量上限被这些小量纲锁死——对小增益的排序微扰，其反转为社会公众带来的价值约等于增益本身之大小的价值。若 H3 胜出，卡 §4 自认"理想化无害"是可发表的否定结果——但实质上等于证明"没有问题"，影响力为"无需改动"。

**论点 3：三无贡献——无新方法、无新测量、无新机制，三个 IP 全部是二手封装。**
IP1（实测标定评估协议）与 IP3（比较器前置冻结+敏感度报告）的原料完全来自 ieee-11308874 的警示（"default terrestrial configurations ... often leads to misleading conclusions"，卡 §10 IP3 逐字引用）与池内公平性缺陷盘点（evidence-map §6）；IP2（drop-front 下 loss 信号与动作解耦）的机制描述逐字来自 2605.27717 笔记（卡 §10 IP2 两条原文引用）。卡的唯一原创资产是"把别人已说的话放进一个受控实验去验"——即 H1/H2/H3 裁决实验本身。原创度是"实验执行"而非"知识增量"。

**论点 4：与现实系统脱节——参数来自一个运营商的当前私有配置，锚点保质期极短。**
整套实测参数是 SpaceX Starlink 的黑盒反推（ieee-11143359 自承"黑盒推断、快照时效性局限"；2605.27717 自承"cannot in itself establish a causal link"且"SpaceX 可能随时改配置"，evidence-map §4）。一个方法论论文的全部标定锚点绑定在单一私有运营商的 2024–2026 快照上（15s 重配置 2310.09242 为欧洲双国视角、PoP 测绘漏检华沙 PoP、2605.27717 手动拟合无因果链，evidence-map §4/卡 §7）——知识保质期以"SpaceX 改配置"为上限。卡 §7 自己也要求"锚点须带版本与有效期声明"：一篇评估方法论论文自带着有效期墓碑，说明其知识形态是新闻而非定律。

**论点 5：空白只因没人屑于做——可行性门槛极低，空白是激励缺口不是能力缺口。**
资产侧全开放：2310.09242 300GB 数据、2605.27717 队列模拟器开源、2604.12382 代码开源（evidence-map §7）；参数可从公开测量文献提取（卡 §8"全部参数来自已开源的实测数据集/模拟器"）。"没人能做"不成立——任何有经验的仿真研究者都能做。查新证据更伤人：2605.27717 发表后**零前向吸收**、2604.12382 **零前向引用**（novelty §2），即锚点文献摆在那两年没人跟进。同时范式在车联网域已有 URB 2608.20575 先例（novelty Q4）——说明"真实感基准重审 RL 路由"可想到、可做、有人做，而卫星域无人跟进，最经济的解释就是"回报感知低"：审计别人不产生新方法 claim，与学术激励结构相悖。

**论点 6：做出来也难发——裁决形态与服务社区的 venue 形状错位。**
卡的科学贡献是"裁决"，但对顶级系统/网络 venue（SIGCOMM 类）而言：无系统、无新测量、无理论，只有对他人论文的复核；而卡自认"首个"须限定卫星域（novelty r2 收窄，因 URB 已做同范式）——第一性声明被收窄成"LEO 卫星域首个"，是一个省份级声明。若 H3 胜出，否定结果"理想化无害"在主流 venue 几乎无处安放；若 H1 胜出，卖点取决于反转是否足够戏剧性——而论点 2 已指出被审增益量纲小，戏剧性天花板低。

**论点 7：审计者的自证统计基础弱——"审计无方差的人"自己也没有充分方差。**
被审方法大量单点曲线、无种子/置信区间（claim-map F1，全文级）；审计方自己只有 5 seeds（2601.13662 原报告口径）、100 episode（2604.12382 口径）级别的重跑预算（卡 §8）。在 4–5 档保真度 × 3 方法 × 有限种子下，检验"H1 反转幅度与注入强度单调相关"的统计功效存疑——审计结论自己的置信区间与它批判的对象一样宽，判决的判决力被削弱（"审计者也会被审计"）。

**论点 8：现象的证伪风险挂在自建池边界上。**
空白声明是"47 篇池内无一纳入实测动态"，卡 §7 自认"检索边界：仅本 47 篇精读池，非全网系统检索"，且 tail-* 5 篇仅摘要级、其全文可能覆盖此空白（已知覆盖空洞）。novelty 轮 1 判读以"标题/元数据级"证据给出"无直接答复=0"的中等强度结论，同域存疑项 4 条（2009.08155 NetSoft'26 混合表+RL、LEO Q-learning、LEO SDN GNN、Cross-US PoP）尚未取摘要复核。即：现象的最坏情况（被一篇未入池论文直接证伪）要到轮 2 才能排除——本卡现在是"未被证伪"，不是"已证伪失败"。

**论点 9：无部署意义。**
现网运营者（SpaceX 等）不跑 RL 路由；受影响的是 47 篇学术论文的信用与 RL 路由子圈的证据规范，不改变任何部署决策。影响面=文献信用，不是现实系统。

**论点 10：知识已被地图捕获——实验化只是把已知变实测。**
claim-map 张力 #100（"实测知识与 RL 环境完全脱节"）与 evidence-map §8 横批评（"证据强度天花板被仿真保真度锁死"）本身已是全文级知识资产；卡 §12③ 引用 2605.27717"有益于 faithful 的仿真研究"自证该主张源头已有。把张力实验化的边际知识增量，有一部分已被地图本身及 2605.27717/11308874 的警示吸收——"验证一个已被告知的风险"。

> 反方指针（留给裁决，不减弱上述论证）：论点 1–3 的反方是"复核愿景在 D4RL/URB 有成功先例、社区已开始买单"；论点 5 的反方是"跨社区信息断裂是真实的（claim-map #100），脱节不是价值判断"；论点 6 的反方是"数据集/基准资产形态（IMC 生态）不看裁决方向"。

## 2. 意义性三问

### ① 重要性谁背书（带证据指针）

1. **claim-map 张力 #100（全文级）**："实测知识与 RL 环境完全脱节（无人覆盖的空白）——Starlink 的 15s 重配置、drop-front 队列、PoP 切换、遮挡丢包均已实测在案，没有任何一篇 RL 路由工作把这些动态纳入训练/评测环境；反之测量文献指出仿真不可替代（"real-world measurement ... is irreplaceable"）"——from [2212.13697, 2310.09242, 2605.27717, ieee-11143359, ieee-10016705]。本卡把地图已登记的张力作为问题，重要性有地图级背书。
2. **evidence-map §8 横批评（全文级）**："全部 RL 路由工作的拥塞/时延结论均未与实测 Starlink 队列动态（drop-front/1500 包/15s 重配置）对齐——证据强度天花板被仿真保真度锁死"，引 2605.27717 逐字"队列配置错误会显著扭曲性能对比结论"。这是测量侧对 RL 仿真结论的直接质疑，是最硬的重要性背书。
3. **assumption-map #3"仿真器结论可信（sim 内闭环即可外推）"（全文级）**：from [2604.12382, s25041232, ieee-11565396, ..., ieee-10016705（综述亦确认）]，引"a model trained on data generated by simulated environments [will] struggle to generalize"——综述级文献确认 sim-to-real 未处理，问题被文献反复点名。
4. **被审最强方法自认（全文级）**：2601.13662"Queues for the satellites are assumed unbounded, so buffer overflow is not explicitly modeled"（assumption-map #7，卡 §9 行 #4）；2604.12382 时延口径"仅传播项，不含排队/处理时延"（卡 §9 行 #5）。"被审对象自己承认假设理想化"是该问题重要的最小铁证。
5. **方法论警示（全文级）**：ieee-11308874"Most works proposing modifications to OSPF evaluate their enhancements against the baseline protocol using default terrestrial configurations. This often leads to misleading conclusions"（卡 §10 IP3 逐字）——基线/评估规范的失真被目标社区的论文自己钉在案上。
6. **被审基底矛盾（全文级）**：claim-map E 中 2310.09242"Hand-offs between satellites are not the cause of these effects"（15s 重配置与切换无关）直接反驳池内把性能波动归因于卫星切换的仿真假设（claim-map F5"时标分离…所有学习法对拓扑/流量联合快变的适应性未被系统检验"）——池内假设与实测结论正面冲突，冲突本身就是重要性。

> 结论：重要性背书全部来自被审文献自身的 assumptions 自认 + 测量文献明确声明 + 综述级确认，无一条是本卡自造。问题"被问过"（各文献 limitations 侧），但"没被测过"——背书充分，测是漏的。

### ② 空白原因分类

**判：主类=没人屑于做（危险），次类=信息不对称的"没人想到"；不是"没人能做"，也不能判"杀"。**

- **排除"没人能做"**：资产全开源（300GB 数据/队列模拟器/1 篇代表代码，evidence-map §7），参数可提取（卡 §8），可行性门槛低——能力缺口不成立。
- **主判"没人屑于做"的依据**：① 锚点零吸收（2605.27717 零前向、2604.12382 零前向，novelty §2）——文献摆在那没人跟进，最经济解释是回报感知低（审计不产生新方法 claim，与激励结构相悖）；② 范式已在车联网域被 URB 2608.20575 执行（novelty Q4）——证明可想到、可做、值得某域做，卫星域缺位两年，不能用"想不到"充分解释。
- **保留"没人想到"成分的依据**：claim-map #100 全文级确认两社区证据链完全脱节、测量文献均未与 RL 控制文献闭环（claim-map F2）——跨社区资产互不可见是真实的信息断裂，脱节本身含"没想到"成分，不全是价值判断。且参数齐备窗口极新（2310.09242 为 2023、2605.27717 为 2026/IMC'26），"来不及做"成分真实存在。
- **不判"杀"的依据**：即便空白主要由激励缺口造成，"做出来"仍推翻或证实一个由测量社区明确声称失真、且零人检验的隐患（evidence-map §8）——有信息价值，不是"做了也没用"。判定为**危险但可救**：危险来自"空白可能恰是低价值"，可救来自背书充分（问①）+ 资产齐备（现在能做）+ 理赔形态可为资产而非裁决（问③）。

### ③ 最小可信发表形态

- **目标 venue：ACM IMC（Internet Measurement Conference）**。
- **贡献类型：实测标定仿真环境+基准数据集（资产型主贡献）+ H1/H2/H3 裁决与反转机制归因（发现型附加贡献）**，对应卡 §12② 的工程/科学二分，但包装次序反转：**以资产为主、裁决为辅**——因为裁决有 H3（否定结果）分支，资产与其方向无关，保证任何结果方向下都有可交付物。
- 最小形态 = "开源实测标定评测环境（drop-front 队列模拟器 + 15s 重配置 + PoP 事件流注入接口）+ 三种代表方法重测结果 + 保真度梯度下的排序/增益轨迹"，IMC 的 datasets/artifacts 生态可直接消费；卡 §8 的分因子消融协议即资产的一部分。

## 3. 投稿可行性

### 目标 venue（1–2 个）

1. **ACM IMC** —— 测。证据：**2605.27717 为 IMC'26 论文**（卡 §7 明言"2605.27717，IMC'26，>1000 万探测包拟合"），其形态=黑盒反推私有队列机制+开源队列模拟器，正是 N1 首参注入源的出处；IMC 接受"测量驱动的机制复核 + 开源仿真/数据资产"形态，N1 交付的"实测标定环境+对既有结论的复核"是该生态的下游可消费形态（novelty Q5 相邻族 2304.00708 Hypatia / 2507.03248 eBPF / 2011.05202 OpenSN 亦证明 trace-driven 仿真设施是可发表资产形态）。
2. **IEEE IWQoS** —— N1 关键参注入源的自家 venue：**ieee-11143359 为 IEEE IWQoS'25**（novelty §2 锚点 DOI 串 "10.1109/iwqos65803.2025.11143359"，元数据级推断），该文发表"PoP 切换/骨干策略变化为时延一阶因子"的黑盒测绘；N1 把其参数注入 RL 评测，是在该 venue 已认可的知识上做仿真注入闭环，同生态延续。

### 同类形态先例（证明 venue 接受该形态，笔记ID + venue 信息）

- **评估方法论/基线复核形态被接受**：ieee-11308874（池内笔记，IEEE 系；具体会议名池内未标注，待复核）以"OSPFv3 调参 vs 地面默认配置 + 快照 Δt 敏感性报告"为内容（claim-map A / F2），逐字警示"默认配置评估常得出误导性结论"——证明目标 IEEE 系 venue 已发表"评估规范本身"型论文，与 N1 的 IP1/IP3 同族；N1 与之差异只是把警示实验化并搬到 RL 侧。
- **LEO RL 路由仿真评估形态被持续接受**：池内大量 ieee-* RL 路由笔记（ieee-11651610、ieee-11565396、ieee-11661488、ieee-11656129、ieee-4200818 等，evidence/claim-map 全文级）本身即 IEEE 系会议论文——这些 venue 连续接收"LEO RL 路由仿真+评估"形态，N1 是该形态的保真度升级（从合成环境升级到实测标定），不是新形态冒进，正门可入。
- **跨域范式已被发表**：2608.20575 URB（车联网"真实感基准重审 RL 路由"，novelty Q4）证明该范式本身可发表（须限定卫星域声明，novelty §3）。
- **风险与前置**：① H3 胜出时以基准资产保底（见问③包装次序）；② 轮 2 必须先定向复核同域存疑 4 条（2009.08155 / NetSoft'26 混合表+RL 等，novelty §3）——若其中一篇已做实测标定评测，现象被证伪，本卡降级为纯仿真比较（卡 §6 立即淘汰条件 2）；③ 被审方法可复现性三级（开源/参数齐全/部分重建）须按卡 §7 声明可得性偏置，2509.14909"无法精确复刻"的降级需预判。

## 判决

**主张：通过**——现象有全文级实证背书（claim-map #100、evidence-map §8、assumption-map #3）与被审方法自认背书，资产开源齐备、锚点极新，"没人屑于做"的危险信号可被"IMC 资产型形态+轮 2 排存疑"对冲；但必须接受三点交割：以资产为主贡献包装、H3 分支预案、"首个"声明钉死在卫星域。

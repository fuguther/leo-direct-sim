## 八支逐支：人家怎么做、哪里一致、哪里薄

### B1 建模与权限
- **普遍做法**：几乎全是"每星一个 agent、只读局部观测"；少数集中式（PIXWFHAC 地面控制中心单 agent、9C6HB6AF/XM64YRAW/GPDPLJNG/2FBBURX7 单智能体集中式）；MXQVNU3P 是"分布执行+集中训练+参数广播"。
- **全库一致（无对照）**：**没有任何一篇把"决策资源/决策权限"建进 MDP**（除了 S85KQ4FC 把推理延迟放进奖励项，但那是工程处理，不是权限建模）。
- **薄**：控制面与数据面的权限分离、决策预算约束，全库未作为建模对象。

### B2 状态与记忆
- **普遍做法**：瞬时快照为主（队列、距离、带宽、连通性）。
- **有非瞬时内容的 6/33**：时刻（3 篇）、访问计数器（1 篇，原文自称 memory）、LSTM 隐状态（1 篇）、AoI 特征（1 篇）。
- **全库一致（无对照）**：**0/33 篇做过"带时序 vs 不带时序"的消融**——也就是说，状态里要不要放时间信息，**在库里连一次对照实验都没做过**。
- **薄**：状态的时间尺度与负载过程尺度不对齐（唯一显式做 EWMA 的 CYMQ2GLA，意图是滤掉短期波动）。

### B3 动作与策略
- **普遍做法**：动作空间被拓扑裁剪为"四邻居选一"；唯一例外 PIXWFHAC 的全网 N=48 寻址。
- **全库一致（无对照）**：**动作掩码基本缺席**（仅 ZIUBKVPZ 用 safe-action set、5N5LQPPP 用可达性前置检查）；**切换/重路由代价几乎全缺**（仅 2FBBURX7 用"在途包沿旧树走完"间接处理）。
- **动作时间结构**：**仅 1 篇**（S85KQ4FC 的流表 + 抖动门触发）。CYMQ2GLA 的 600ms 重算节拍是部分情形。
- **薄**：动作驻留/迟滞/决策成本感知的动作，全库 0。

### B4 目标与奖励
- **普遍做法**：标量加权（时延 + 队列/负载 + 距离）；**至少 3 篇全文没有奖励公式**（42E4NAQU、J68GU76W、XLRW7XXN），GPLEP83L 连奖励都由 LLM 生成、正文无公式，6GWNYSTT 完全没有奖励函数（`reward` 0 命中，直接以时延为代价）。
- **唯一向量**：UKBSA7WN（多目标 MORL，式 6/7，每目标一套 Q）。
- **其他变体**：势函数差分（2FBBURX7）、比值型相对奖励（XM64YRAW）、约束式（39NJWBI7 的 CVaR + λ_k）、按业务类型重配权重（TSV3IE8S）、按负载区间切换惩罚符号（X5Z98UPM 四段式、ZIUBKVPZ 分档）。
- **全库一致（无对照）**：**没有一篇做奖励分项消融**——"哪个分项值多少"全库无人测。

### B5 价值学习与信用分配
- **普遍做法**：1-step TD 为主；**Q-routing 的"邻居 Q 表 bootstrap"是表格族的技术底色**（Y2H4NPLU/UKBSA7WN/53HEEK33/UKEKU5ZG 同形）。
- **多步**：仅 5N5LQPPP 的固定两跳目标（且原文缺 γ、未报折扣）；n-step 全库近乎空白，而库内就有 GAE。
- **信用分配轴（六条）**：目标类型（UKBSA7WN）、约束类型（39NJWBI7）、边（FLQLU3T4）、代价来源（9GPFG5U3，拆完立刻加和）、智能体（COMA/QMIX）、时间（GAE）。**失败原因：空**（反例已逐条排除）。
- **薄**：**"哪个分项贡献多少"没有任何消融**；G-A（失败原因分通道）无人做。

### B6 多智能体交互
- **普遍做法**：独立学习 + 局部观测；少数参数共享。
- **全库一致（无对照）**：**没有一篇实现真正的 MARL 协作机制**（VDN/QMIX/QTRAN/MADDPG/CTDE 在全批 0 命中）；**没有通信**；**非平稳只被当作动机写进引言，从未机制化**（53HEEK33 L201、5N5LQPPP L133 明确识别为问题但无处理）。
- **薄**：共同信号下的同步反应（羊群）、学到的通信，全库 0。

### B7 训练与适应
- **普遍做法**：离线训练 + 冻结推理；收敛加速靠"改感知范围/改更新顺序/改训练信号来源"三面（B2 批的核心分歧点）。
- **全库一致（无对照）**：**训练分布几乎从不作为实验变量**（B1 7/8、B2 8/8、B3 6/8 同源同分布）；UKBSA7WN 事实上做了 Poi(5)→Poi(20) 的切换，但**没把这个差异本身当变量研究**。
- **薄**：课程/域随机化 0 篇；在线适应/持续学习机制 0 篇（LOZANO 在库外）。

### B8 执行与评估
- **普遍做法**：时延/PDR/吞吐/收敛曲线；**关键常数大面积缺失**（5N5LQPPP 的 γ、PIXWFHAC 的终止常数、ZIUBKVPZ 的 B/ψ/c、Y2H4NPLU 的 w1/w2/α/γ、S85KQ4FC 的 κ/ψ 均未报）。
- **全库一致（无对照）**：**决策成本进评估闭环仅 1 篇**（S85KQ4FC）；**状态特征的消融几乎为 0**（既没做时间语义消融，也没做"哪些状态字段有用"的消融）。

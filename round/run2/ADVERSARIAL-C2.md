# C2 替代方法挑战（ADVERSARIAL-C2，主控执行）

> 目的：三问之③——"强简单替代为何仍不足"。**对抗性检查**，不是自我免责。
> 方法：假设我是审稿人，给最强反驳；再用 C2 稿中的证据逐条回应或承认。

## 挑战 1：这不过是"评估协议"——算研究问题吗？

**反驳**：C2 的主张是"别人没在同均值下扫突发"。这是**评估缺口**，不是方法贡献。若结论只是"建议以后都扫一下"，那是 checklist，不是论文。

**C2 的回应（稿 §1③ + §4）**：
- 拟议改动**不只是评估**：训练域随机化（把过程形状纳入训练分布）+ 状态三通道（q, Δq, EWMA）。
- 即：**协议暴露的缺口需要一个学习侧的改动来填**——这是"评估 → 诊断 → 改动"的完整链，不是纯评估。
- **主控判定**：✅ 回应成立，**但证据尚弱**——因为"状态含 Δq/EWMA 能回收多少"完全未经检验（稿中诚实标为 M2 待验）。
  → **这构成 C2 的关键未知**（见下）。

## 挑战 2：普通缓存/批处理/规则能解决吗？

**反驳**：若同均值不同突发的差异，用"状态里加一个变化率特征"就能吃掉 → 无需 RL 改动，也无需本卡。

**C2 的回应**：稿 M2 设计正是为**分辨**这一点：
- 若"域随机化"全回收 → 收窄为训练分布卡，**状态通道剔除**；
- 若"状态通道"回收大头 → 才算信息通道贡献。
- **主控判定**：✅ 这是**诚实的自我证伪设计**（把"简单办法已足够"作为可判读的分支写进判读规则）。
  → 但注意：**判读规则本身尚未执行**，所以"简单替代不足"目前**只是设计，不是结论**。

## 挑战 3：现象是老结果，你的增量在哪？

**反驳**：稿 §6 自承 [Shi03] 等已表明"突发同均值下性能不同"是老结果 → 那你发现什么？

**C2 的回应（§6 已知反例 2）**：贡献**不是发现现象**，而是：
1. 把现象转成 **LEO RL 路由的训练/评估合同**；
2. 给出**可判读的协议**（同均值守恒校验 + 瞬态窗条件指标 + 判读规则写死）。
- **主控判定**：⚠️ **部分成立**。"把老现象接进新域并给协议"是**方法论贡献**，但若 M2 显示简单办法已足够，则连方法论贡献也仅剩"评估建议"。
  → 需要 §6 的 (b) 复用平滑边界来支撑"LEO 场景下确实会呈现"——但那是**推演**（标了【推演】），**无实测支撑**。

## 挑战 4：与 N1 的关系会不会被覆盖？

**反驳**：N1 已做真实流量标定，若真实 LEO 流量本身就含突发，C2 的扫描是否多余？

**C2 的回应（§0.1 第 3 点）**：可被覆盖的是**验证面**（真实过程下的性能数字），不可被覆盖的是**参数化扫描面**（同均值网格 + 域随机化 + 状态消融）。
- **主控判定**：✅ 成立。单因素控制变量是真实样本路径**做不到**的（均值与形状捆绑）。

## 挑战 5：口径是否守得住？

**反驳**：会不会滑成"领域空白"声明？

**C2 的回应**：全文只用"本次语料检索范围内未命中"；且**主动列出外部近邻**（[Shi03] 2003、[Wan25f] 2025），并明说"领域级无人做过声明不可用，也不需要"。
- **主控判定**：✅ **守住了**，且这是本轮三卡中口径最严谨的一份。

## 主控结论（C2）

| 维度 | 判定 | 依据 |
|---|---|---|
| **现象**（有文献支持） | ✅ 成立 | 7/7 承重引文独立复核通过；14 篇审计表（同均值扫描 0/14） |
| **原因**（机制有依据） | ⚠️ **部分成立** | 机制链清晰（突发→时间尺度错配→状态不可辨识），但"LEO 场景确实呈现该错配"是**推演**，无实测 |
| **改动**（对症） | ✅ 成立 | 改动直接作用于"状态不含过程特征"这一被原文证实的事实（E15：状态只含瞬时 q） |
| **简单替代不足** | ❓ **未定** | 判读规则已写死（M2 分支），但**尚未执行** |
| **最强反对** | 若 M2 显示域随机化全回收 → 本卡降级为"评估协议建议"，科研叙事弱化 | 稿自身已承认该分支 |

**关键未知**：LEO 域内是否真的存在"同均值不同突发导致交付率/时延显著差异"。
**该未知是否妨碍向老师提方案**：**不妨碍**——因为：(a) 现象在排队论/交换域已有老结果；(b) M0 先行步（半天–1 天：审计表 14→20 篇 + 1 个已训策略同均值 CBR vs ON-OFF 冻结对照）**足以在两天内给出该域的首个数据点**；(c) 判读规则与淘汰线已写死，负结果也有意义。
**但必须诚实说明**：C2 目前的贡献形态是"**协议 + 待验的改动**"，不是"已验证的方法"。

# 附：基于**修订版**（172 行）的判定更新（2026-09-11）

> 修订版新增 **M1–M4 四条机制链**与**诚实降级条款**，据此更新三处判定。

## 变化 1：「原因有依据」从 ⚠️ 部分 → ✅ **成立（有分层质量差异）**

| 机制 | 依据类型 | 判定 |
|---|---|---|
| **M1 瞬时超订→溢出** | **理论背书**：ρ_inst=a·λ̄/μ；交付率损失由 (a, T_on, B−q₀) 决定，**与均值 λ̄ 无关**；M/G/1 E[W]=λE[S²]/(2(1−ρ)) 说明"同均值、二阶矩不同 → 时延不同" | ✅ **这是"同均值不同突发致差异"的机制核**，有标准结果支撑，不是推演 |
| **M2 状态-动作时间错配** | 机制清晰（T_on ≲ τ_obs 时快照滞后），退化由 T_on/τ_obs 控制，**均值不进入该比值** | ✅ 机制可证伪，但**是否在目标平台一阶显著**【待证】 |
| **M3 同质 herd 振荡** | 推演（同区域卫星读数同步抬升） | ⚠️ 推演；归 C1 轴，本卡只观测不改动 |
| **M4 更新错配** | **有原文实证**：47J2H748 MD L73 逐字"when network traffic levels were then lowered again, adaptation was much slower" | ✅ 有文献实证 |

**关键改进**：M1 提供了**与均值无关**的机制核 —— 这直接回应了"同均值扫描为什么值得做"，比修订前只讲"别人没测"强得多。

## 变化 2：「简单替代仍不足」——论证变结实，但**判决仍需实验**

修订版改为**按机制覆盖**逐条对表：

| 替代 | 覆盖哪些机制 | 为何仍不足（修订版论证） |
|---|---|---|
| 混合负载训练 | **只覆盖 M4** | 对 M1–M3 **不提供归因**：混训后差异无法指认是形状还是占用率/容量漂移（**混淆案是现成教训**）；且输出不了"同均值形状曲面" |
| 在线微调 | M4 部分 | 对 **M2 无效**——错配在**观测端**（快照滞后），微调改参数不改信息通道；且迟滞有原文实证 |
| 已有信息（瞬时 q） | M1/M3 的信息在网里 | **M2 的缺口是读数缺时间语义**：同均值下"q=50% 上升中"与"q=50% 已过峰"读起来一样 |
| 规则路由 | 同盲区 | 进对照组，不作为"已足够"的候选 |

**主控判定**：⚠️ **论证质量提升，但结论状态不变**——"简单替代是否足够"**仍由实验判决**。
理由：上述论证说明的是"混训/微调**在原理上**不能覆盖 M2"，但**没有排除**"M2 在目标平台上不显著，因此根本不需要覆盖它"。后者正是 §4 的 M0/M1 要测的。

## 变化 3：新增**诚实降级条款**（加分项）

修订版写死：若同均值网格内差异低于阈值，**或**差异存在但域随机化全回收、状态通道无增量 → 本卡**如实降级为评估协议卡**（只主张"同均值扫描合同 + 14 篇负载模型审计表"的方法论贡献，不主张 RL 改进）。
**主控判定**：✅ 这是三卡中唯一把"自我降级"写成**可触发条款**的深化稿。

**题目**：Q-learning for distributed routing in LEO satellite constellations（Soret, Leyva-Mayorga, Lozano-Cuadra, Thorsager；Univ. Málaga + Aalborg Univ.）

## 七要素

- **Question**：在 LEO 星座（LSatC）中，如何在**不依赖地面段、最小化星间信令**的约束下做端到端分布式路由，使时延在非拥塞段接近最短路径基准、且在拥塞临界负载下不崩溃？传统路由依赖与地面/其他卫星的过量信令，且过度简化路径链路刻画。
- **Claim**：分布式 Q-routing 能做到三件事——(1) 稳态时延与两个集中式最短路径基准相当；(2) 无拥塞前提下支持更高流量负载（不稳定路径比例开始飙升的门限：data rate BM 在 9 个网关、latency genie BM 在 8 个网关，Q-routing 推迟到 >14 个网关，ℓ=0.85）；(3) 可实现性强：不需地面段参与、星间反馈仅为一个 Q 值。
- **Mechanism**：把问题建模为多智能体 POMDP；每颗卫星是独立 agent，4 个 ISL 天线（2 intra-plane + 2 inter-plane）+ GSL 为动作空间（|E_i|≤4 邻居 + 可选网关链路）。邻居链路质量/队列拥塞用 **2 bit 编码**进观测（s=2 长 queue 或链路不可用；s=0/1 高/低容量不拥塞）。奖励 = r_queue + r_dist，其中 r_queue = w1·(1−10^{tq(j)})（指数惩罚，队列越长惩罚增长越快），r_dist = w2·归一化斜距缩减量；到达目的地给 r_del，成环给 r_loop。关键改造：Q 更新用**下一跳的 Q 表**（Eq.8：Q*_i = (1−α)Q_i + α(r + γ·max_a Q_j)，替代常规的自用 Q_i(s_{t+1})），反映动作对邻居队列状态的相关性影响；ε-greedy，ε 指数衰减；反馈仅是收包成功后的一个 Q 值。
- **Evidence**：自研 Python 仿真器，Kepler 星座 M=7 平面 × N_m=20 星（140 颗），高度 600 km，最多 18 个网关（KSAT 站址），ℓ=0.85；DVB-S2 自适应调制选速率，B=64.8 kbits，W=500 MHz，ISL 26 GHz / 上行 30 GHz / 下行 20 GHz。拥塞判定用最近 200 个包的 E2E 时延线性回归斜率 t 检验（H0: β1≤0，α=0.05）。结果：传输时延 <0.72 ms 可忽略；Q-routing 传播时延略高于两基准（归因于初期探索 + 2 bit 状态编码粗）；genie BM 在 |G|≥8 后排队时延显著上升；Q-routing 在 <0.5 s 内学到新路径。
- **Assumption**：(1) 拓扑可由星历完全预测，E 集合用 [3] 的 ISL matching 算法预先更新；(2) 时标分离成立——学习 episode（包到达尺度，亚秒级）远快于星座运动（分钟级），故可在时间快照上建模 POMDP；(3) 自由空间路损模型、每网关始终与最近卫星保持 GSL；(4) 网关间流量均匀分配（等量发往其余网关），Poisson 到达、定长块 B。
- **Boundary**：单平面高度（600 km）、均匀 Kepler、无故障/失效模型、无 QoS 异构；状态空间被 2 bit 编码人为压小，导致传播时延非最优；未用 DRL（作者明确留作 future work）；latency genie 本身非最优（源端瞬时队列知识在长时延下过期）——所以"赢过 genie"的证据是拥塞鲁棒性而非时延下界。结果全部来自仿真，无实测/硬件在环。
- **Tension**：状态压缩 vs 时延最优——2 bit 编码把状态空间压到卫星算力可承受，但正是它让 Q-routing 的传播时延"比另外两个都略大"；探索 vs 拥塞——初期 ε 探索抬高平均时延（Fig.5 前段），而减少探索又损害对拓扑变化的适应；信令最小化 vs 信息新鲜度——只回传一个 Q 值虽省开销，但 agent 对全网拥塞的感知天然滞后（genie 的失败恰好说明瞬时知识也会过期，问题是滞后的学习型知识能否补偿）。

## RL 领域块

- **RL-Formulation**：多智能体、每星一 agent、独立学习（非 CTDE：无集中式 critic/训练，纯分布式 tabular Q-learning）；POMDP 4-tuple (S, A, P(s,a), R(s,a))。状态 S_i = {L_i, N_i}：包目的地址 + 本地链路连通性 + 4 邻居各 2 bit（链路质量/队列拥塞）。动作：从 E_i ∪ E_iG 选下一跳。奖励：见 Eq.(5)-(7)，= 送达奖励 / 环路惩罚 / (队列指数惩罚 + 归一化斜距进步)。折扣因子 γ 与学习率 α 报告了符号但**数值未报告**（w1、w2、ε 初值与衰减率、r_del/r_loop 数值均未报告）。
- **Setup**：自研 **Python 仿真器**（未命名框架）；Kepler 星座，7 平面 × 20 星 = 140 颗，h=600 km；拓扑为**连续时间动态图但按时间快照处理**（ISL matching 用 [3] 算法周期更新 E_S、E_G，非 contact plan 形式）；流量：最多 18 个真实 KSAT 网关，每活跃网关等量发往其余网关，Poisson 到达，聚合负载 ℓ=Σλ_UL/λ* = 0.85，|G|∈[2,18] 扫描；链路速率按 SNR 从 DVB-S2 MCS 集合选最高可靠速率；定长 64.8 kbit 数据块，FIFO 队列 Q_max（数值未报告），满队列丢包。
- **Baselines**：两个 Dijkstra 源路由基准——(1) **data rate BM**：边权 = 1/R(i,j)，选高速率路径；(2) **latency genie BM**：源端瞬时已知全网队列、按时延最短选路（作者论证其因长传播时延下队列状态过期而非最优）。胜负口径：拥塞鲁棒性上 Q-routing 赢（不稳定路径飙升点 9/8 → >14 网关）；稳态时延上"comparable"（genie 传播时延最小，Q-routing 略大）；无给出具体百分比数字。
- **Metrics**：(1) **不稳定路径比例**：对每条 s-d 对最近 200 包的 E2E 时延做线性回归，t 检验 H0: β1≤0（α=0.05），拒绝则该路径不稳定——即"时延随时间线性增长 = 拥塞"的操作化定义；(2) **E2E 时延分解**：L(i,j)=排队时间 + 传输时间 + 传播时间（Eq.3），分项报告均值（传输 <0.72 ms 忽略）；(3) 时延-仿真时间曲线（收敛速度）。
- **Reality-Gap**：非平稳性用**时标分离假设**消化（学习亚秒级 vs 轨道分钟级）；部分可观测是建模核心（每星只见本地队列 + 邻居 2 bit 反馈）；未处理星上计算/存储限制的实现细节、链路故障、大气/雨衰（仅自由空间路损）、波束/切换瞬断；**无 sim-to-real 环节**——纯仿真，未讨论。
- **Reproducibility**：代码与数据**未公开**（文中无任何代码/数据链接）；仿真器为自研 Python；参数表较完整（功率/频率/天线口径/带宽/包长/站址均给出）但关键超参（α、γ、w1、w2、ε 调度、Q_max、r_del/r_loop）缺失，独立复现有缺口。

## 与选题空间的关系

- **覆盖判定**：本文回答的是"**LEO 星座中无地面依赖的分布式学习型 E2E 路由能否在拥塞临界负载下胜过集中式最短路径路由**"这一类问题，属于"tabular Q-routing + 2bit 压缩状态 + 快照拓扑"的技术路线证据：结论是可行且拥塞鲁棒性更好（不稳定路径门限 9/8 → 14 网关，ℓ=0.85，140 星，7×20）。它明确**没回答**：(1) DRL/大状态空间下的表现（作者留作 future work）；(2) 异构 QoS/策略场景（同上）；(3) 星上硬件约束、链路故障、切换瞬断的真实性 gap；(4) 与 contact-plan / 快照序列路由的系统性对比；(5) 收敛性/多智能体稳定性的任何理论保证（只有经验观察 <0.5 s 学到路径）；(6) sim-to-real。**证据等级：中等偏低——仿真-only、自研仿真器未公开、关键超参未报告、结论以定性"comparable/robust"为主而非量化增益百分比**；其可复用价值主要在：拥塞操作化定义（回归斜率 t 检验 + 最近 200 包）、跨层 Q 更新（用邻居 Q 表，Eq.8）、2bit 邻居状态编码这三个可移植设计模式。

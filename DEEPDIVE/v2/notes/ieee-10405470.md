# 精读笔记：ieee-10405470（Deep Reinforcement Learning for Congestion Control and Routing Optimization in LEO Satellite Networks）

- 出处：2023 5th International Conference on Artificial Intelligence and Computer Applications (ICAICA)，Dalian, China, 2023-11-28~30，DOI: 10.1109/ICAICA58456.2023.10405470
- 作者：Jiacheng Zhu, Xuebin Sun*, Dianjun Chen（北京邮电大学）
- 关键词：Congestion control, LEO satellite networks routing, deep reinforcement learning

## 七要素

1. **问题**：6G 背景下 LEO 卫星网络（LSN）星座路由入口/出口点拥塞严重（因地理、政治等因素），成为全网瓶颈。传统分布式路由需频繁重算路由、计算负担大且效率增益有限；广播寻路浪费资源能量；人工配置类方法鲁棒性差。目标：在保证平均卫星带宽利用率的约束下联合优化拥塞控制与路由。
2. **场景假设**：极轨（polar orbit）星座、无缝全球覆盖；卫星沿赤道 180° 范围均匀分布；单时隙内同轨/异轨连接固定；轨道 1 与轨道 n 因赤道接缝（seam）不互连。每颗卫星最多与同轨 2 颗、相邻轨道（i-1, i+1）2 颗相连。星座建模为图 G=(V, L)，V、L 均为 n×n 矩阵（v_ij 表示第 i 轨道第 j 区域是否有星，l_mn 表示星间连接）。
3. **方法（ECSAC-DRO，Event-driven Congestion-aware SAC-enhanced Dijkstra Routing Optimization）**：
   - **状态空间 S**：n×n 矩阵，每份数据包选定路径后对应元素 +1，刻画全网流量分布。
   - **动作空间 A**：n×n 矩阵，事件 i 的动作 A_i(s,d) 给出下一份数据包的流量分布（卫星 x→y 携带的包数）；SAC 输出加高斯噪声 ε~N(0,σ) 探索。
   - **奖励**：R = Σ_i δ·s_i − Σ_j δ·s_j + ε（式10），∀i∈L′（Dijkstra 最短路集合），∀j∈L（当前所选路径集合），i,j ≠ {n_s, n_d}；ε 为奖惩阈值偏移因子。目的地附近状态值高（拥塞高）→ R 变小甚至为负 → 惩罚。
   - **拥塞度量**：瞬时拥塞函数 F_t(p) = ΣΣ δ·p_ij，δ>1 为路由收敛控制因子（式6）；优化问题 Q = min_P F_t(p)，s.t. η > ζ（式7），η = Σ kp/B 为平均带宽利用率（式5，每 ISL 传单包需带宽 k）。
   - **算法**：双 Critic Q_φ1,Q_φ2 + Actor π_θ + 目标网络 + 经验回放池 D，batch 随机抽 N 样本，episode<M、内层 i=1..I；SAC 引入动作熵平衡探索/利用，防止过早收敛到局部最优。
   - **流程**：路由管理系统通知事件开始（源 v_s → 目的 v_d），agent 依当前状态输出动作，系统用 Dijkstra 算奖励，agent 更新网络，状态转入 S(t+1)。
4. **实验设置**：Python 自建星座路由计算环境 + 自建 DRL 模型；网络为随机生成的卫星位置矩阵，**20 颗卫星**、随机连接关系、传输 **50 个数据包**；生成网络先做有效性评估过滤 bad cases。未报告：星座具体轨道参数（高度/倾角/轨道数）、学习率/批大小/网络结构、随机种子与重复次数。
5. **结果**：
   - 学习曲线（Fig.1，对比 DDPG/TD3）：DDPG 收敛最慢、波动最大、平均奖励最低；TD3 因抑制过估计更稳定、收敛更快；ECSAC-DRO 前期波动更明显、收敛慢于 TD3，但**最终奖励略高于 TD3**。
   - 网络状态（Fig.2，对比随机路由/Dijkstra）：Dijkstra 平均时延最低但拥塞最高；随机路由时延最长、实际带宽利用率较低；ECSAC-DRO 时延略高于 Dijkstra，但拥塞控制与带宽利用率灵活可调，显著优于随机路由。
   - 未报告：具体数值（时延 ms、拥塞值、利用率百分比均无数字表格）、统计显著性。
6. **局限**：
   - 规模极小（20 星 50 包的随机生成网络），远非真实 mega-constellation；
   - 无具体量化数值与多次运行统计；基线弱（仅随机路由与 Dijkstra 对比网络指标，DDPG/TD3 只比学习曲线）；
   - 星座拓扑随机生成，未给出轨道力学（时隙间切换/ISL 变化的动态仿真细节缺失）；
   - 状态/动作空间为 O(n²) 矩阵，可扩展性存疑；
   - "congestion control"实为路由级流量分布，无速率/准入控制机制。
7. **可借鉴点**：
   - 矩阵化 state/action 的联合拥塞-路由 MDP 建模范式（可搬到本平台 routing 决策块）；
   - 用 Dijkstra 最短路集合作为奖励参照基准（L′ vs L 的差分奖励）——简洁的"对最短路径偏离度"奖励塑形；
   - 带宽利用率约束（η>ζ）+ 拥塞最小化的非线性规划形式化；
   - 事件驱动（per routing event）决策粒度，与时间触发仿真的事件循环天然契合；
   - SAC 之于高维连续空间的论据可用于选型论证；DDPG/TD3/SAC 学习曲线对比可作为实验基线设计模板。

## RL 领域块

- **算法**：SAC（Soft Actor-Critic）为核心的 ECSAC-DRO；对比 DDPG、TD3；引用中提及 DQN（[14]，离散动作空间是其被指出的缺陷）。
- **状态**：n×n 流量分布矩阵 S（每包选路后对应元素 +1）。
- **动作**：n×n 下一包流量分布矩阵 A_i(s,d)，连续动作空间，加 N(0,σ) 噪声探索。
- **奖励**：差分式 R = Σδs_i − Σδs_j + ε，Dijkstra 最短路集合为正项参照、当前路径集为负项，源/目的节点对 (n_s, n_d) 排除。
- **网络/训练**：双 Q Critic + Actor + 目标网络 + 回放池 D，batch N 采样；引入动作熵正则平衡探索/利用。
- **评估方式**：训练收敛曲线（平均 reward vs episode）+ 网络级指标（平均时延、实际带宽利用率、整体拥塞）定性对比。
- **RL 相关缺口**：无消融（熵项系数、δ、ε 的影响均未验证）、无超参数报告、无可复现代码链接。

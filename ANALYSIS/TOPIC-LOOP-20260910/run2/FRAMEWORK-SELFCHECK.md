## 4. 回答："框架会被用足吗"

**结构上会，理由如下（非承诺）**：

1. **总纲已建立单一入口**（`TOPIC-SELECTION-METHOD.md`）：新会话读一份即可上手，不必重新发明流程；
2. **规则已可执行化**（`PROMPT-TEMPLATES.md` 五类模板直接填空），不依赖会话记忆；
3. **验证靠实证而非自证**：污染审计读子会话日志、闸门判定表留痕、回归测试覆盖历史缺陷；
4. **框架本身会自我修正**：本轮已发生 3 次（历史审查者指出 2 个缺口、dry-run 指出 1 个缺陷），证明它有反馈回路而非静态文档；
5. **交接包自包含**（`HANDOFF-v2.md`）：10 节含硬约束、语料、在途工作、9 步执行顺序、7 条红线、环境故障备忘。

**风险（如实说）**：

- **闸门尚未通电**：G1–G5 会不会因为"证据拿不到"而大面积卡死，只有跑一遍才知道；
- **模型能力**：新会话用 4.1，但**执行纪律靠提示词模板与审计工具兜底**，不能假设模型自觉；
- **批内对账新规则未经实战**：§8.0 刚写，A3↔B2 是第一例试跑；
- **时间**：本会话已消耗大量预算在准备与语料上，真正跑完 ≥2 条主线需要新会话的完整时段。

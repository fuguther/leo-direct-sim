## §1 三问回答

### ① 哪个方法在什么重要条件下遇到什么具体困难

**方法**：LOZANO 式 per-satellite DQN 逐包路由（每星一 agent，28 字段观测含 16 值 log 压缩邻居拥塞编码，4 选 1 下一跳【笔记级原文事实】）。
**重要条件**：负载体制切换——日模式爬坡或突发 surge 使工作点连续穿越"队列感知价值带"的边界。价值带的存在由四锚拼图（各自合同内行为均为原文事实级，核验层见 §2）：
- 带外低端：LOZANO 低载时与最短路 50 百分位仅差 1.7ms ≈ 无差异【笔记级】；
- 带内：HE 只有把 ISL 压到 50 Mbps（GSL 1000 Mbps，20:1 不对称）的极端工程拥塞合同下，学习法才展现大收益（SPF 丢包 84.8% vs 学习法近零丢包；MADQN→PRIMAL-CVaR 平均排队时延 17.6→4.8ms，−72.7% 为本人由表 I 数字计算，非原文句）【VM 级】；
- 带外高端（被规避）：LIAQ 摘要自认 "Dijkstra achieves the lowest end-to-end latency under ideal conditions"，主比较设队列容量 1 Gb/s "effectively preventing queue overflow"【VM 级】；
- 带外（跨域佐证）：WEIL 无带宽限制时学习法与最短路几乎打平且 SP 仍最优（表 4：1.74/3.49 vs 1.77/3.54）【笔记级；WEIL 为通用有线图、非 LEO，见 §6 边界】。

**具体困难**：绕行切换点隐含在 Q 值差分界面里，其标定位置由训练负载合同决定；单一负载训练下，部署负载偏离训练点时阈值在从未被采样更新的队列状态区间外推 → 失标定，表现为过早绕行（时延↑）或过晚绕行（丢包/到达率↓）【推演】。

**三层分离（防"没测=做不好"）**：
- 现象有文献支持：四篇各自合同内的行为差异（如上，原文事实级）；"无一测量跨体制迁移的阈值行为"为**限定表述**：在已核验的 5 篇（LOZANO/HE/LIAQ/WEIL/ZHOU-DTAR）中未见【推演，限定】；
- 原因有依据：失标定机制链（§1②）为【推演】，尚未排除全部竞争解释（H1/H2/H3 见 §4）；
- 塌陷窗的存在、宽度、位置本身【待证】——四锚只证明"各测带内或带外"，不证明窗存在。

> **裁决句**：现象层证据成立（限定于已核验篇目），困难存在性为待证假设，原因链为推演；本卡是一个**可判别的测量+归因命题**，不是已证实的失败模式。

### ② 拟议改动针对什么原因

**原来的决策/学习过程**：包到达 → 读 28 字段观测 → Q(s,a) 四值 → argmax 选下一跳；终态回报逐跳 TD 更新。单一负载合同（LOZANO ℓ=1【笔记级】；HE 10,000 pps 训练=评估同速率【VM 级】）→ Q 只在训练负载附近的队列状态区间被采样更新 → 改道阈值 = 该区间内的隐式分界面。
**改哪一环**（观测/动作/奖励/网络容量均不变）：
1. **训练合同**（机制变化①）：负载课程/随机化——训练负载在 {轻、中、重、跨体制切换段} 上随机化，替代单一负载点；
2. **评估协议**（非学习改动）：隐式阈值显式化——Q 差敏感度分析，提取改道阈值随负载的漂移轨迹，检验跨体制稳定性；
3. **归因工具**（吸收 A1【转引】）：重训差值归因作诊断，分离"覆盖不足"与"信息不可辨识"。

**为何可能减轻该原因**：课程使 Q 差分界面在多个负载区间都被采样标定 → 体制切换点位于被学习过的状态区间 → 阈值不随迁移漂移【推演】。
**信息来源与决策时可得性**：不新增任何观测维度（负载数率入状态是**对照臂**而非本卡改法）；课程只改训练分布，部署时零新信息需求 → 可得性无障碍。
**学习器输出与反馈**：输出仍为 4 值 Q 的 argmax；课程下经验回放池含多负载转移样本，TD 误差在各负载区间均被压降【推演】。
**代价与失效条件**：训练步数按负载点数近似线性增加；课程顺序引入新超参（须记录）；**失效条件**——若失标定主因是信息缺位（策略不知道当前体制）而非覆盖不足，课程无效：由数率入状态臂 vs 课程臂的对照判别（§4）。

> **裁决句**：改动与原因假设严格对偶（病因在训练合同，改的就是训练合同），机制链成立但效力【待证】；与信息增补替代的胜负无法先验判定，故对照臂是论证的一部分而非陪衬。

### ③ 强简单替代为何仍不足（条件对齐后逐条）

1. **负载数率入状态（λ̂/λ_ref，最强对照，源自 A1 改法【转引】）**：对症信息增补。条件对齐（同训练合同、同扫描协议）后：若该臂消除塌陷窗而课程臂不移窗 → 瓶颈是信息缺位而非训练合同，本卡**降级**并入观测合同问题。**"不知道能否胜过"保留**：课程修正 Q 的外推误差但不给策略"当前体制"的显式坐标，带边界附近仍可能误判；数率入状态给了坐标但学的是条件映射，带内样本少时同样外推——胜负取决于体制切换段的经验密度，先验不可判【推演】。
2. **ELB/TLR 显式阈值调参**：阈值静态、不随负载合同迁移；其失标定形态（固定阈值 vs 学习阈值漂移）恰是第二对照的判别点。若调好阈值的 ELB/TLR 在体制切换时同样劣化 → RL 无相对空间【推演】。
3. **多负载混合训练 + 多 seed（成熟 RL 合理调参）**：与本卡改法①**同源**，是"调参能解决多少"的基线臂；若它已消除塌陷窗，本卡**降级为评估协议贡献**（塌陷窗测量 + 阈值显式化协议仍保留价值，但学习改动不成立）。

> **裁决句**：三个替代各对应一条写死的降级/淘汰线（§4）；本卡的独立增量 = **跨体制阈值行为的测量与归因协议本身**——该增量在替代胜出时不归零，而是转化为降级形态。

## §4 验证设计（leo_sim V2；**只交付设计，不跑实验**）

**主比较**（承反馈义务 4）：单负载训练 × 5 点负载扫描 × {RL(DQN), ELB, SPF}，画交付率-负载曲线定位塌陷窗；leo_sim 已有负载扫描合同（E0/GLOBAL-PRESSURE-BRACKET 系列 profile 存在【代码事实，转引自 run1 旧稿】）。
**对照臂**：TLR（显式阈值）；负载数率入状态 RL（最强对照）；多负载混合训练 RL + 多 seed（同源基线臂）。
**归因臂**（吸收 A1【转引】）：冻结策略跨强度 vs 每强度重训，差值 = 训练合同覆盖不足分量；扫描区间按 A1 方案 0.25–4×。

**判别结构（什么结果支持/否定哪个竞争解释）**：
| 观测结果 | 支持的解释 | 否定的解释 |
|---|---|---|
| 窗存在，且 RL 与 ELB 失标定形态不同（漂移 vs 固定） | 失标定机制 | 替代解释「显式启发式同样劣化」 |
| 窗处 RL 与基线的优劣完全随指标切换（排队时延赢/交付输，或反之） | T-C2-H3 指标伪影 → **触发淘汰线 (ii)** | 本卡机制 |
| 窗仅出现于 ISL 瓶颈合同（HE 式 50Mbps），GSL 瓶颈合同下消失 | T-C2-H1 瓶颈位置 | 窗的普遍性 |
| 窗位于运营负载区间之外 | T-C2-H2 利用率临界 → 价值收缩为边界测量 | 工程相关性 |
| 数率入状态臂消窗、课程臂不移窗 | 信息缺位 | 训练合同原因 → 本卡降级 |
| 重训差值≈0 但窗仍在 | 非覆盖不足原因 | 本卡原因假设 → 降级 |
| 多负载混合训练臂已消窗 | 「调参足够」 | 学习改动增量 → 降级为评估协议贡献 |

**淘汰线（写死）**：
(i) 5 点扫描下塌陷窗不存在或宽度 < 种子噪声 → 本卡降级为边界测量报告；
(ii) RL-基线收益可完全被指标选择解释（H3）→ 按继承淘汰条件降级；
(iii) 数率入状态臂消窗而课程臂不移窗 → 本卡并入观测合同问题；
(iv) 多负载混合训练臂已消窗 → 降级为评估协议贡献；
(v) 窗全部位于运营负载区间外（H2）→ 价值收缩为边界测量，不承诺阴性结果的论文价值。

**统计纪律**：不预设效果阈值、不预设窗宽；种子数与置信区间按平台合同（paired 分析），不设"显著即成功"。
**第一步先行步（0.5–2 天可执行）**：复用既有扫描合同，先只跑 {SPF, ELB} 两支非学习臂 × 5 点负载，确认扫描基础设施可复现"价值带"两端行为（低载无差异 / 高载分化），再插入单负载训练的 RL 臂——非学习臂先行可在无训练成本下标定带边界的位置量级。
**文献可支持的结论**：四锚边界条件存在（§2 行 1–11）；单一负载训练合同是现役默认（§2 行 2、7）。**必须后测的结论**：窗的存在/宽度/位置、失标定方向、课程能否移窗、各竞争解释占比——全部【待证】。

## §5 最近邻差异（ZHOU-DTAR = 最可能已解决核心问题的工作）

准确还原其条件与能力【笔记级原文事实】：
- **条件**：288 星（12 面 × 24 星）@1450km、89°；K=18 域（NSGA-II 离线划分：域内流量比最大化 + 域间负载标准差最小化）；flow 级 3 流/步、144 步/回合；流量=日模式时空不均矩阵（无 Mbps 量级）；surge=μ5× 局部热点；故障 p_f=p_r=0.02 独立随机；**无地面段/接入链路/排队建模**。
- **能力**：GAT 域状态编码 + action-masked PPO 域间逐跳路由；fault 场景路由成功率较 Dijkstra +9.25pp、较 CDPAR +8.89pp；消融显示去 GAT 或去 NSGA-II 均劣化。
- **不能**：normal/surge 场景**无量化交付收益**（结果多为图 3 定性，CV/时延无精确数字）；域级粒度与逐包逐跳错位；无任何跨体制阈值行为测量；"端到端时延"口径未明。
- **与本卡关系**：其核心问题（域间负载均衡）与本卡核心问题（逐包粒度隐式改道阈值的跨体制标定）**不同粒度、不同测量对象**，核心问题未被其解决；但其 normal→surge 合同是本卡体制切换场景的天然模板。按反馈义务 5，DTAR 仅作窄带佐证，不作否定。

# 深潜 v2 完整计划：RL-LEO 路由选题生产线（终稿查新 + 品味门 + 异议裁决层）

> 2026-09-03 用户审定版。分支 agent/20260903-coldstart-deepdive。

## 目标与成功判据
为「RL 强化学习优化 LEO 路由（负载/时延/到达率）」产出 **0-5 张经得起对抗、查新与品味检验的选题卡**。
- "0 张"是合法结果：宁缺毋滥，禁止为完成任务放行边角料选题；
- 每张卡必须能说服用户（claim 可回溯、工程 vs 科学分明、"为什么现在/为什么是你"有答）；
- 每张卡通过 2 轮终稿查新 + 品味门 + 异议裁决。

## 角色分工（用户裁定）
| 角色 | 模型 | 职责 |
|---|---|---|
| 批量精读 | glm-5.3-flash | 7+1 笔记、逐字引用 |
| 三图合成 | glm-5.3 | Claim/Assumption/Evidence 地图 |
| 审核/对抗/查新 | deepseek-v4-flash（opencode-go） | 猎杀、挑错、novelty hunt——与精读方异源异厂 |
| 终审裁决 | 主会话（k3） | 每条异议判"真阻塞/收窄/噪声"，裁决记录落盘 |

## 异议裁决层（纠偏"让 LLM 挑问题它一定挑得出"）
1. 异议必须结构化：{攻击点, 证据引用(地图条目/笔记ID/原文句), 致命性主张}——无证据指针自动降级；
2. 主会话逐条裁决：真阻塞（淘汰/返工+死因登记）/ 收窄（改卡不判死）/ 噪声（驳回+驳回理由）；
3. 全部裁决记录落盘，用户可抽查。

## 执行管线
- **A1 人工筛查**：主会话过目 231 池 → 40-60 篇精读清单（控制范围五类分层，去双版本）。门：每条带理由。
- **A2 批量精读**：flash 并发批（≤10 篇/批），每篇 ≥6 逐字引用；IEEE 篇走已验证会话（限速≥30s/篇）；Elsevier 先摘要级标残留。门：verify_quotes.py 全量核对，造假作废。
- **A3 三图合成**：条条约笔记 ID。门：承重测试。
- **A4 对抗+生长 ≥2 轮**：deepseek-v4-flash 猎杀 → 主会话裁决；杀死的登记死因+复活条件；活下的必须改写生长；滚雪球触发器（弹药不足/地图空白/锚点引文 1-2 跳）落盘；允许地图张力长新候选。
- **A5 选题卡初产**：八字段 + 锚点五篇对比表 + 理论不足→创新点（四级回溯）+ 平凡性对照。
- **A6 终稿查新 2 轮**：轮1 定向检索（创新点新查询×三系统 + 锚点 S2 前向引用）；轮2 对抗性 novelty 猎杀（换社区词表换表述）。异议全走裁决层。两轮都活 → "查新级"；被杀 → 如实登记不抢救。
- **A7 品味门**：①意义性三问（重要性背书/空白原因分类：没人想到=机会、没人能做=机会、没人屑于做=危险需论证、做了没用=杀/最小发表形态）②边角料猎杀（deepseek 专项论证"这是边角料"，卡逐条反驳，主会话裁决）③投稿可行性（目标 venue + 池中同类形态引证）④数量纪律（0 张合法，禁止凑数）。
- **A8 出品停点**：0-5 张卡 + 全记录 → ★ 用户裁决。B 阶段（开题一页纸+Pilot+平台可行性）选中后另行批准。

## 0. must-address 逐条回应

### 0.1 与 N1（实测动态盲的 RL 路由评估）的区别：互补而非重复
依据 op-history-review.md 对 C2 的裁决（L105–L111）：条件同族（训练/评估合同）、困难同族**不同轴**（N1=评估环境无实测动态标定；C2=负载过程的**时间结构**——突发维度——从未参数化/扫描）。本深化把"互补"落实为三条可执行的链，并保留主控核实点：

1. **资产分工（N1 出数、C2 用数）**：N1 的交付物是"实测标定环境+重测报告"（L105：机制差异=实测标定环境+重测报告 vs CV×T_on×ρ 网格协议+域随机化+(q,Δq,EWMA) 三通道）。C2 的过程族参数（CV、滞后自相关 ρ_ac、突发时长分布 T_on）**必须**用 N1 实测统计定标——没有 N1，C2 的网格就是拍脑袋；没有 C2，N1 的真实样本路径无法回答控制变量问题。
2. **控制变量（N1 做不到、C2 正是做这个）**：N1 环境是真实流量的**一条样本路径**，均值与过程形状捆绑，无法回答"**等均值下**仅改变过程形状，交付率/时延变多少"。同均值扫描正是把"均值"锁死、把"形状"变自变量的单因素协议——与 N1 是评估合同的两个正交轴（真实锚 × 参数化扫描）。
3. **覆盖风险如实保留（不因深化关闭）**：op-history L109 指出"若 N1 的实测环境已含真实流量突发，C2 的扫描协议存在被 N1 环境部分覆盖的可能——这是主控核实点"。本深化结论：可被覆盖的是 C2 的**验证面**（真实过程下的性能数字），不可被覆盖的是**参数化扫描面**（同均值 CV×T_on×ρ 网格、训练域随机化、状态通道消融）。因此 C2 的实验矩阵把"真实标定过程"仅作为网格外的一个校验点，不作为主张来源。
4. **口径纪律**：op-history L156 警告"A1 '11 篇无一报告'、C2 '零篇同均值扫描'、B3 '库内无一互换 OD' 均为语料内为真的事实；若升格为领域级空白声明将与 N1 交割条件③相抵触"。本稿全文只用"**本次语料检索范围内未命中**"表述；且 Undermind 语义检索已见外部近邻（[Shi03] Routing Algorithms under Bursty Traffic Loads 2003；[Wan25f] RL Routing with Non-Markovian Traffic 2025，见 §5.5）——领域级"无人做过"声明**不可用**，也不需要：C2 的增量在于卫星 LEO 域内 RL 路由的**协议化**，不在于"突发影响性能"这一老命题本身。

### 0.3 承重事实回 MinerU MD（行号+章节+逐字）
**CMNCS52M（Traffic-Aware MARL-Based Distributed Routing for LEO Satellite Network，2026）**——"外生队列/无时间过程"：
- §III.B.1 ZONE-BASED QUEUE DISTRIBUTION（MD L89）：逐字 "The queue occupancy of a satellite located in zone z is **sampled from a normal distribution** centered at μ_z with a standard deviation set to 0.1 μ_z"——队列占用是**直接采样**，不存在包级到达过程，且与被评估的逐包决策无反馈耦合（外生）。

## 1. 三问回答

### ① 现有方法在什么重要条件下为什么做不好？

**先给语料内事实（审计表见 §2 表 2）**：14 篇逐篇关键词核查（poisson/burst/ON-OFF/CBR/self-similar/heavy-tail/MMPP/traffic model/arrival）显示，库内 RL/路由论文的负载模型只有三种形态：(a) 平稳泊松（Y2H4NPLU 网关泊松 λ_UL；SaTE 1s 泊松流）；(b) 确定性/空间模式（UKBSA7WN 单位时间固定包数；42E4NAQU 均匀/人口两种**空间**强度；CMNCS52M 外生队列采样）；(c) 确定性周期调制的 NHPP（LZKNZA8B：λ_i(t)=λ0(1+sin 2πt/T)）。**没有一篇把"同均值下的过程形状"作为自变量**（语料内事实，仅此范围）。ZIUBKVPZ、5PYWVRC5、53HEEK33、X5Z98UPM、9C6HB6AF、UF8IQTA2、39NJWBI7 在本次关键词检索范围内未命中流量过程描述（【未命中】，不外推）。

**条件与原因（区分标注）**：
- 【原文事实】CMNCS52M 的负载根本不是过程：占用率正态采样（§III.B.1 L89）或地理填充（§III.B.3 L97），zone 模型"not time-dependent"且时间特征被删（§VI.A L177）。在该合同下训练出的策略，其"负载经验"只有空间快照——**突发结构的上升沿/持续/自相关从未进入训练分布**。
- 【原文事实】SaTE 这类评估侧最好case也只到 1s 泊松流+均值扫描（§4 L232、§5.4 L292）：泊松在流级是无记忆的，"1s 粒度"把亚秒突发结构在生成器层面就抹掉了。
- 【笔记→勘误】CMNCS52M 三模型对比混改 5 变量（CONFOUND §2；ERRATA 更正 1）：现有评估协议连"换一个负载设定"都做不到单因素——**协议粒度不足以隔离负载过程**，这正是本卡把"过程"升格为显式自变量的直接证据。
- 【推演·排队论标准结果】为什么同均值也够成事：M/G/1 平均等待 E[W]=λE[S²]/(2(1−ρ))——均值到达率相同、二阶矩不同，ρ→1 时时延与溢出概率随之改变；ON-OFF 同均值下队列占据的方差与自相关系统性高于 CBR，瞬时超订造成溢出丢包（到达率/交付率损失通道）与排队时延尖峰（时延通道）。
- 【待证】"因此 RL 策略在同均值不同过程下性能不同"——**论文没测 ≠ 做不好**。库内无该测量，此命题正是 M0/M1 要裁决的（§4）；本卡可主张的语料内事实是"**训练与评估共享同一简化：负载只有均值/空间快照，无时间过程参数**"（上引原文共同构成）。

### ② 拟议改动针对什么原因？

**辨因（三层，可分离）**：
1. **测量层**：评估合同缺轴——过程形状（CV、突发时长 T_on、自相关 ρ_ac）从未是自变量，导致任何现有数字都无法回答"对过程形状鲁棒吗"（CMNCS52M 混淆案说明连现有轴都容易混改）。
2. **训练层**：训练分布无过程多样性——单一/无时间过程的生成器（审计表 a/b/c 类）使策略对上升沿样本零覆盖。
3. **信息层**：状态无过程特征——逐跳策略读的是邻居队列瞬时快照（42E4NAQU：state 含 "the queue levels associated with each neighbor"；CMNCS52M：q 向量），同均值下"q=50% 且在上升"与"q=50% 且平稳"对策略不可区分。

**改法（对应卡面 possible_change，写出一次具体更新）**：
- **协议件**：同均值突发扫描——固定每流/每节点均值 λ̄（到达计数守恒校验），网格化 (CV, T_on, ρ_ac)；输出"交付率/时延 vs 过程参数"曲面，冻结策略跨过程扫描。
- **训练件**：域随机化——episode 采样器在网格上抽过程参数，均值 λ̄ 不变；Bellman 更新式**一字不改**：Q(s,a) ← Q(s,a) + α[ r + γ max_{a'} Q(s',a') − Q(s,a) ]，r 仍为 −单跳时延。变的只有生成器与观测向量。
- **状态件（一次具体的决策更新）**：s_i(a) 增加三维：Δq_τ(j)=q_j(t)−q_j(t−τ)（τ=观测周期）、EWMA_τ(q_j)（半衰期对齐 T_on 网格中值）、（可选）节点到达计数 EWMA。动作不变（4 邻下一跳）。决策语义：q 高但 Δq<0 且 EWMA 低 → 可用（突发已过）；q 中但 Δq 大且 EWMA 上升 → 规避（突发进行中）。这是把"瞬时 q"升级为"带过程语义的 q"。
- **什么情况下不起作用**：(a) 瓶颈是链路容量守恒且交付率只看长时间平均——同均值下平均到达=平均服务，突发只重排时延分布、不改变平均交付率（扫描对"平均指标"无分辨力，必须配瞬态窗条件指标）；(b) 策略反应时标 ≪ 突发时标且队列观测频率足够高——突发可见可反应，过程盲区效应小（这落在 C1 的轴上）；(c) 多源汇聚的统计复用把突发平滑掉（骨干 ISL 上近似泊松极限）——扫描分不出差异（§6 边界）。

### ③ 简单方法与成熟 RL 为何不能同样解决？（条件对齐逐条）

| 替代方案 | 条件对齐后的比较 | 残余缺口 |
|---|---|---|
| 混合负载训练（含突发混训） | 【推演】能覆盖但**不能归因**：混训后性能差异仍无法指认是过程形状还是占用率/容量漂移——CMNCS52M 混淆案（ERRATA 更正1）正是混因素教训；且混训无诊断输出，无法画出"同均值形状曲面" | C2 协议恰恰为混训提供"该混什么"的坐标系；两者是上游-下游关系而非竞争 |
| 在线微调 | Boyan&Littman（47J2H748，Adaptation"Load level"段，MD L73 逐字）："When the overall level of network traffic was **raised** ... Q-routing **quickly adapted** ... However, when network traffic levels were then **lowered** again, adaptation was **much slower**"——适应不对称+迟滞；突发时标若短于微调时标，来不及 | 微调不解决**评估**盲区；C2 的瞬态窗指标反而能测出微调的迟滞 |
| 已有可获得信息（瞬时队列本身） | 信息"在"网络里，但审计表显示状态普遍只含瞬时 q（42E4NAQU L123 后段、CMNCS52M L143）；同均值下过程语义（变化率/持续性）不在任何现成读数里 | Δq/EWMA 是一行特征改动+域随机化一条采样规则，不需要新算法——改动小不是否决理由，恰是本卡工程价值 |
| 规则路由（ECMP/CA-DRP 类） | CMNCS52M 表3（§VI.D L225–232）：规则协议 NMB 1.2–2.3 vs RL 0.15–0.4（描述性事实，注意混淆边界）——但规则协议同样从未在过程轴上被扫描；CA-DRP 用组合时延比较，对"上升沿"同样失明 | 协议卡同时服务 RL 与规则基线：扫描矩阵里规则路由是必配对照，不是被淘汰方 |
| 直接近邻（最短队列/热土豆） | 信息通道与 RL 同源（瞬时 q），过程盲区相同 | 同上，进对照集 |

**小结**：没有任何替代方案能替代"把过程形状变成自变量"这一步；它们要么依赖它（混训需要知道混什么），要么本身就是被测对象（规则/近邻/在线微调）。卡面淘汰线保留：**同均值下 CBR 与 ON-OFF 策略性能无差异 → 本卡无空间**（§4 判读规则写死）。

## 4. 验证设计

**实验矩阵**（平台：SatCom-TELMA 或平台现有逐包仿真器；拓扑/容量/队列容量/状态维度全程锁死——CMNCS52M 混淆纪律）：
- 过程轴：{CBR, ON-OFF} × T_on ∈ {0.2, 1, 10} s × duty ∈ {0.2, 0.5}（与 C1 网格对齐复用）；λ̄ ∈ {0.5, 0.7, 0.9 × 容量}；ρ_ac 轴二阶段加入（先两个生成器族）。
- 策略轴：{冻结已训策略跨过程扫描, 每过程重训, 域随机化训练} × {状态=q, 状态=q+Δq+EWMA}。
- 指标：交付率（到达率）、E2E 时延 mean/p99、**瞬态窗条件指标**（上升沿后 [0, 3T_on] 窗口内条件化 vs 时间平均）——平均指标对同均值设计天然不敏感，条件指标是主判据。
- seed/重复：每格 ≥5 seeds，报中位数与 IQR；同均值校验：每 run 到达计数守恒（|实测均值−λ̄|/λ̄ < 1%）否则 run 作废（fail-loud，防 A1 轴混入）。
- **M0（半天–1 天，先行步）**：①审计表 14→20 篇（字段定死：过程族/强度可变/是否报告 CV·自相关·突发时长/状态是否含过程特征/训练-评估过程是否分离）；②1 个已训策略同均值 CBR vs ON-OFF 冻结对照（A1 的 SatCom-TELMA Poi(5) DQN checkpoint 直接复用）。
- **M1（1.5–2 天）**：ON-OFF 扫描 + 冻结 vs 重训差值（差值=过程失配可回收部分）。
- **M2（2 天）**：2×2 域随机化 × 状态三通道，判读"覆盖可回收"还是"信息通道可回收"。
- **判读规则写死**：同均值同占用率下，交付率差 <2% 且 p99 时延差 <5%（跨全部网格格点）→ 触发卡面淘汰线；任一格超限 → 进入 M1/M2 归因。
- **负结果预案**：N1 无差异→卡按淘汰线终止，登记 ELIMINATED-REGISTER §6（平台域内证伪，带"网格范围"边界条件）；N2 差异存在但域随机化全回收→本卡收窄为"训练分布"卡，状态通道剔除；N3 差异存在且状态通道回收大头而域随机化不足→与 C3（快照信息可辨识性）合并对账，C2 出协议与扫描证据。

## 5. 最近邻差异（四要素：条件/困难/机制/决策变化）

1. **LZKNZA8B（Spatial-Temporal Learning-Based Distributed Routing，2026）**——库内最近的过程模型。条件：NHPP 周期调制负载的分布式路由。困难：拍周期序列建模，未问"过程形状本身值多少"。机制：序列网络提取时空特征。决策变化：本文允许 λ(t) 时变，但调制是确定性正弦、增量仍泊松——**时变 ≠ 突发**；C2 把形状参数化为同均值自变量并冻结扫描，LZKNZA8B 只在单一过程族内训练评估。
2. **JLF7IEBQ（SaTE，2025）**——评估侧均值扫描的最好case。条件：TE 求解延迟与满足需求。困难：计算时延在线化。机制：异构图 GNN+17ms 推理。决策变化：只扫均值 125–500 flows/s（E8）；C2 锁均值扫形状，且指标换成到达率/时延（SaTE 主指标是 satisfied demand）。
3. **CMNCS52M（2026）**——反面教材兼最近邻。条件：三种队列分布模型下的 MARL 路由。困难：时变空间负载下 RL 显著优于规则协议。机制：DQN-LSNR 状态+奖励工程。决策变化：其"过程"是外生采样/填充（E1–E3），且协议混改 5 变量（E5）；C2 恰好是它的单因素修正案。
4. **42E4NAQU（Queue-Aware MARL，2026）**——信息通道最近邻。条件：队列感知状态（瞬时 q）+ 两种空间模式。困难：韧性指标下的路由。机制：DRL 逐跳决策。决策变化：过程轴缺失（E11/E15）；C2 的 Δq/EWMA 是其状态的直接升级件。
5. **外部两例（【外部线索】，Undermind 题录，未读全文，不入承重）**：[Shi03] "The Performance of Routing Algorithms under Bursty Traffic Loads"（2003，非卫星域）——"突发负载下评估路由"作为命题早已存在，C2 的增量必须钉在"LEO RL 路由 + 同均值参数化协议 + 训练分布/状态通道"三件套，而非命题本身；[Wan25f] "Spatial-Temporal RL for Network Routing with Non-Markovian Traffic"（2025）——非马尔可夫流量×RL 路由的近邻信号，主控若推进 C2 应先取全文对表（语料外，未核）。

## 6. 反证与边界

- **已知反例 1（最强的自我约束）**：CMNCS52M 五变量混淆（E5/ERRATA）。本卡若扫描时不锁容量/占用率/状态维度，就会复刻同一错误——故 §4 把锁死清单写进合同。
- **已知反例 2（外部存在论）**：[Shi03]/[Aud09]/[Sch05]（Undermind 题录）表明"突发同均值下网络性能不同"在排队/交换领域是老结果。→ C2 的科研贡献**不是**发现该现象，而是：把现象转成 LEO RL 路由的训练/评估合同、并给出可判读的协议。措辞上全文避免"首个/无人做过"。
- **适用边界**：(a) 低占用区（ρ ≪ 1）二阶矩效应小（E[W]∝1/(1−ρ)），扫描分辨力集中在高占用区——网格设计已按 λ̄ 加密 0.9；(b) 统计复用平滑：汇聚流数大且各流近似独立时，骨干 ISL 到达趋近泊松极限，突发被抹平——扫描应保留"接入侧突发、骨干侧平滑"的分层设定，否则会高估效应；(c) 突发时标 ≫ 策略反应时标时，效应归 C1（瞬态窗）而非 C2（过程盲区）——两卡以 T_on/反应常数比划分适用域。
- **失效条件汇总**：同均值校验失败（均值漂移混入 A1 轴）；瞬态窗条件指标缺失（平均指标天然钝感）；真实 LEO 流量在相关时标上被 N1 实测证明近似泊松（此时 C2 降级为"合同完整性"论据，科研叙事弱化但不消亡——鲁棒性合同仍成立）。
- **口径纪律（重申）**：全部"未命中"仅指本次关键词检索与 14 篇审计范围；B-01 不作否定（§0.2）；N1 核实点不因本稿关闭（§0.1）。

# 文献与论文选题区

> **CURRENT-CONTRACT**：本页同时规定文献核验和论文选题的证据防火墙。当前没有已冻结的中心问题、方法路线或创新点。调研摘要、Agent 观点、旧候选和项目实验解释不能自动成为项目指导或科研事实。

## 从方向到问题的选择方法

先画研究空间，再比较方向，再收窄具体问题，最后冻结可验证的中心问题。方向是值得投入的未知问题群；问题是特定条件下可以回答的未知；方法是回答问题的手段。不得把算法名称列表当方向地图，也不得用固定数量代替覆盖判断。

1. **研究空间与方向发现**：根据中性领域边界，独立检索综述、代表性原文及真实需求。用服务对象/需求、系统架构/运行约束、决策权限、现有知识缺口四个视角检查覆盖，标明已查、薄弱、未查及范围外部分。维度是检索检查工具，不要求枚举笛卡尔积。方向数量随证据产生，可以约十项，也可以更少或更多；不得凑数。
2. **方向比较**：每个方向先说明谁需要什么答案、答案为什么重要、已有方法为何不足。区分重要性、可能的知识增量、证据可信度与资源风险，不把它们压成任意加权总分。先排除明显范围不符、已被直接回答或无法产生有意义知识的方向；证据缺失归为待核，不直接淘汰。比较最强替代方向，说明取舍；保留有不同依据的优先方向和暂缓方向，避免一次押注。
3. **方向内形成问题**：在优先方向中提出具体问题：场景与控制边界、未知量/关系、回答之后会改变的认识或决策、最接近工作、最强反对理由。问题可研究机制、适用边界、设计权衡或评价可靠性；不强制二元归因，不预设 RL 一定是解法，也不因结果为否就失去价值。
4. **问题比较与收敛**：回到直接近邻原文，检查知识增量是否真实、关键量能否测量、混杂能否控制、简单方法是否足够。形成可审查的保留/合并/暂缓/放弃理由；不能仅凭场景规模不同、检索未命中或现成平台能力论证创新。仅在关键不确定性已降低后，推荐一个中心问题；允许暂时没有合格问题。

发现阶段的结束条件是可审查的覆盖地图及有来源的方向比较，不是宣称穷尽领域。新增独立查询主要重复已有问题群、核心视角没有未解释的空白时可以暂时收敛；必须保留未覆盖区域和可能改变排序的证据。审查者可要求一次针对遗漏区域的反向检索，而非无限扩展或机械补够十个。

## 证据防火墙与阶段审核

1. **独立外部发现**：可以从一开始读取外部原始文献和实际需求；不得读取旧中心问题、旧候选排序、旧实验解释或平台功能清单。旧笔记的选文和表述也可能携带锚定，不作为独立发现的唯一材料池。记录实际输入与检索覆盖。完成方向地图和初步比较后停止审核，不要求先凭空生成几个现象。
2. **直接近邻核验**：通过方向审核后收窄问题、精读近邻、比较贡献与替代解释。事实、作者推测和执行者推断分开；不得用本项目已有工作量为候选加分。结束时停止审核。
3. **本地证据揭示**：问题已独立形成后才读取本项目实验。旧实验只用于反证、边界、测量可行性和成本判断；原始观测与历史解释分开。若与原假设冲突，可以改写、退出或回到方向地图，不强行保住旧问题。
4. **最小验证与裁决**：先审查验证要解决的具体不确定性、对照与成功标准，再授权执行。不得以任意百分比淘汰，不把单次平台结果推广为整个 RL 方向的结论。正式实验仍遵守仓库授权链。证据不足时保留下一项高信息价值核验，不强制冻结。

接触过旧材料的执行者必须声明暴露范围；新会话不自动证明隔离。旧问题可在独立发现完成后参与公平比较，不能因旧而优先，也不能因旧而否决。

本机组会材料只提供需求来源和历史记录，不因标题含“当前”“下一步”获得选题裁决权。私有组会目录使用本地入口管理，不把原始资料、个人路径或其内容写入公开文档登记。

## 文献核验

文献条目记录来源身份、可访问证据、适用范围和核验状态。`SOURCES.csv` 的 `support_level` 只表示当前可核材料完整度，不代表论文结论正确。引用前核对标题、作者、年份、venue/DOI 和原文具体位置。

逐篇笔记和知识地图均为 `SUPPORTING`。它们可以暴露主张、假设、证据、边界和张力，但不得自行推荐、冻结或否决论文中心问题；需要形成选题判断时，必须重新回到原文和上述四阶段合同。

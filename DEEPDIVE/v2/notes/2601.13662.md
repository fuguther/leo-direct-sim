# arXiv:2601.13662 精读笔记

**标题**: Reinforcement Learning for Opportunistic Routing in Software-Defined LEO–Terrestrial Systems
**作者**: S. Krishnan, Z. Gu, J. Park, S.-M. Oh, J. Choi (Adelaide / SUTD / ETRI)
**版本**: v1, 2026-01-20, cs.NI (注:任务指定 v2,HTML 无 v2 版,实际抓取到 v1)
**全文**: ../fulltext/2601.13662.txt

## 七要素

1. **问题**: 大规模 LEO 星座拓扑快变、网关可见性间歇,固定源-目的路由不适配;回传流量只需送达"任一可用地面网关"(opportunistic routing)。
2. **假设**: GEO 卫星作 SDN 控制器(控制面),LEO 卫星为数据面交换机;轨道运动准周期可预测;星上队列无界(不显式建模溢出);星地链路 shadowed-Rician 衰落,ISL 自由空间路损。
3. **方法**: 受约束随机优化(最小化最大队列长度)+ residual policy learning——以 backpressure 为基线,DDQN 学习对 BP 动作的加性残差修正,并引入 link-to-ground (LG) 感知项(邻居下行容量加权,平衡 ISL 积压削减与下游地面链路可用性)。
4. **数据/环境**: Space-Track TLE 真实轨道 + 2020 Gridded Population of the World 时空流量(泊松到达、日周期相位);真实网关布局;Starlink(默认配置、每星限邻)/Iridium/OneWeb;连续 3 天,秒级时槽;PyTorch+Gymnasium,A100 训练,5 次独立运行取均值。
5. **结果**: 相对 vanilla DDQN 均值队列降 3.9–18.1%;相对 backpressure 增益 1.6%(小邻域)→12.1%(大邻域),跨星座平均降 7.6–16.1%;训练早期奖励比 vanilla DDQN 高 643.81%、比无 LG 残差基线高 34.01%;混合(全球)网关部署最优。
6. **局限**: 队列无界;GEO 控制信令时延未建模;mega-constellation 规模化与 RL 实现一致性留作 future work(作者自认);纯仿真,无实测验证。
7. **可借鉴点**: residual RL 叠加可证稳定基线的"保底+有界修正"范式;LG-aware 奖励塑形;人口密度时空流量 + TLE 轨道 + 真实网关的仿真管线;轨道准周期性作为 RL 可利用先验。

## RL 领域块

- **RL-Formulation**: 受约束随机优化 min-max 队列长;MDP: 状态=全网队列+拓扑+网关可见性,动作=二值链路激活集,奖励=agent 均值/峰值队列相对 BP 对应值的加权改进(对比塑形),最大化期望折扣回报;算法 DDQN。
- **RL-Setup**: 100 episodes,3 层×256 隐单元 MLP;扫描每星最大邻居数;三星座对比;卫星数扫描;单轨道周期 ECDF;5 seeds。
- **Baselines**: vanilla DDQN、无 LG 残差基线、Backpressure、MaxWeight、Equalize(最拥堵→最空可行邻居)、No-ISL、Random。
- **Metrics**: 均值/峰值队列长度、训练奖励曲线、跨星座/跨规模/跨网关布局队列长度、ECDF。
- **Reality-Gap**: 已含真实 TLE 轨道、人口流量、shadowed-Rician 信道;缺口:无控制信令时延、无缓冲溢出/丢包、无硬件在环或实测、GEO-LEO 反馈回路理想化。
- **Reproducibility**: 数据源公开(Space-Track、GPW2020),参数齐全(时槽、天数、邻数、网络结构、GPU、run 数),公式链完整,但未见开源代码;需自建环境,可复现性中等偏高。

## 逐字引用

> [Abstract] "we introduce opportunistic routing, which aims to minimize delivery delay by forwarding packets to any currently available ground gateways rather than fixed destinations."

> [I-A] "We design a residual policy framework (Fig. 2) that augments a queue-stabilizing baseline such as backpressure with reinforcement learning. This retains a stabilizing backpressure bias while adapting to dynamic network conditions."

> [III-A Challenges] "1) The action space is not fixed but varies with the number of neighbors ... 2) The reward feedback is delayed and highly coupled, since the queue dynamics in (14) depend jointly on all agents' actions across the network."

> [III-A] "Crucially, although the network topology changes rapidly, it exhibits quasi-periodic patterns driven by orbital mechanics, allowing the reinforcement learning agent to exploit these patterns and improve over purely reactive scheduling rules."

> [IV-B1] "Leveraging the LG-aware backpressure prior yields substantially higher rewards from the early episodes—achieving a 643.81% improvement over vanilla DDQN and a 34.01% improvement over the residual policy baseline."

## 与选题空间关系

与 LEO 直连仿真平台相关但错位互补:本文是网络层 opportunistic 路由 + 队列稳定性(把包送到任一地面网关),不做直连用户链路的物理/接入层仿真;其 TLE+人口流量+真实网关的仿真管线可借鉴为平台拓扑/流量模块。RL 侧,"可证稳定基线 + 学习残差修正"范式契合平台 fail-safe/fail-loud 原则(基线保底、学习只做有界修正)。可反驳/差异化点:GEO 集中控制且忽略控制时延的假设在无 GEO 中继的直连场景不成立;无界队列假设留出显式溢出/丢包建模的改进空间。

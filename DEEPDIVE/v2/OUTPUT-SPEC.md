## 选题卡最终字段（每张卡必须填齐）
1. 现象 / Puzzle（一句话"奇怪的是…"）
2. RQ + ≥2 互斥竞争解释 + 判别性预测（哪条观测区分它们）
3. 立即淘汰条件
4. 证据等级与覆盖边界（"没人做过"必须带检索边界声明）
5. 对抗记录摘要（几轮猎杀、怎么活的、被改写生长成什么样——附前后对照）
6. 平凡性对照：不在基线清单内，或显式论证比基线深在哪
7. 最便宜判别实验（输入、指标、预期区分逻辑；平台能做是加分不是必需）
8. 说服链三条：①每个 claim 可回溯到笔记/原文 ②工程 vs 科学贡献分明 ③"为什么现在能做、为什么是你做"有答

## 防火墙
- 组会/旧实验/平台材料**不进入**任何生成与检索提示词；仅用于出品质量条与主会话判断。

## 附带产物（不约束选题）
- 文献矩阵按"控制范围五类"组织（仅路由/拥塞感知/资源调度/联合/优化参照与上界），每篇十字段（出处/问题/场景规模/信息/动作/目标/比较对象/主要结果/局限/代码复现状态）——兼作老师要的调研报告骨架。
- 分层基线表（必跑/条件触发/暂缓）从矩阵推出，不先定算法。

## 修订 R1（2026-09-03，用户两条出品要求）

### 9. 锚点五篇 + 对比分析（每选题卡必带）
每张选题卡配 **5 篇锚点文献**（该选题微领域的定义性工作：通常=最强相邻 2-3 篇 + 奠基 1 篇 + 最新进展 1 篇），拉表对比：

| 列 | 内容 |
|---|---|
| 问题设定 | 它解什么问题、场景规模 |
| 模型与假设 | 显式/隐式假设（尤其未声明的） |
| 方法核心 | 算法/模型一句话 |
| 理论结果 | 有无证明/界/收敛性/复杂度分析；还是纯启发式 |
| 证据类型 | 仿真/实测/理论，强度等级 |
| 与本选题 | 相邻点 + 它没覆盖什么 |

### 10. 理论不足 → 创新点（可回溯推导）
从对比表中提炼"理论推导上的不足"清单（如：无界证明、启发式无最优性分析、假设未经验证、简化模型未量化误差、无收敛条件刻画），**每条不足回引锚点表的具体行与原文证据句**；候选创新点必须从具体不足行推出（创新点 ← 不足 ← 锚点行 ← 原文引用，四级可回溯），禁止空降创新点。

### 11. 检索自适应（滚雪球规则）
以下事件必触发定向补检并落盘记录：①对抗轮"弹药不足"声明；②三图合成发现关键空白；③每篇锚点论文的 S2 引文正/反向 1-2 跳扩展；④精读中发现的高引邻居。

# 文献深潜协议（2026-09-03，金丝雀先行版）

> 上游：阶段2.5 幸存 3 家族（F-I/F-II/F-III，见 PHASE2.5-STRESS-TEST.md 收窄声明）。
> 本协议的唯一目标：用可承重的知识地图 + 对抗生长，产出科研品味级的选题，而不是大规模浅层产出。

## 0. 反"大规模不可用"设计总则
1. **金丝雀先行**：F-I 一族小批量（≤5 篇精读）端到端跑通全管线，实物交用户审阅；用户确认质量前禁止放量。
2. **每阶段质量门**（不过门不进入下一阶段）：
   - 门A 检索：查询日志落盘；主会话抽查相关性（样本≥5 条/族）；噪声率>50% 的查询重写。
   - 门B 精读：每篇笔记含七要素（Question/Claim/Mechanism/Evidence/Assumption/Boundary/Tension）+ ≥6 条**逐字引用**（带章节标注）；主会话程序化核对引用在全文中的真实性（grep 归一化匹配），任一笔记引用伪造率>0 → 该笔记作废重生成。
   - 门C 地图：每条主张回引 ≥1 笔记 ID；承重测试——对抗轮必须能引用地图条目，引用不了则地图重建。
   - 门D 对抗/生长：猎杀须引地图或原文；存活者必须改写（附前后对照）；允许从地图张力长出新候选。
3. **模型分层**（本机实证配置）：
   - 批量检索/精读：glm-5.3-flash（zai-coding-cn，成本≈1/18，1M ctx）；备选 deepseek-v4-flash（opencode-go）。
   - 对抗猎杀/地图合成/终审：glm-5.3 或 k3-256k（与生成方异源，减少同族盲区）。
4. **规模封顶**：单族文献池 ≤300；单族全文精读 ≤60；先 F-I 端到端，达标后复制到 F-II/F-III。
5. **诚实条款**："没人做过"必带证据等级（全文级/摘要级/检索级）与覆盖边界；一切失败留痕；旧材料（LITERATURE/notes、EXPERIMENTS、ANALYSIS、旧候选）全程禁入；子代理 zero-read（禁读工作区），仅可写指定输出路径。
6. **选题裁决权在用户**；阶段 3（本地证据揭示）需另行批准。

## 1. 管线（每族）
R1 宽检索：arXiv API（AND 组合，禁整句精确匹配）+ Crossref + Semantic Scholar（关键词 + 种子论文正/反向引文链），top-20/组；词表必含盲区词：contact plan / contact graph routing / DTN satellite / DetNet satellite / time-expanded network / handover management / 2025-26 实测。
R2 题录筛查：纳入/排除标准+理由，逐条记录。
R3 全文精读：七要素笔记 + 逐字引用 + 原始全文落盘（供门B核对）。
R4 三图合成：Claim Map / Assumption Map / Evidence Map。
R5 对抗+生长 ≥2 轮：猎杀→存活者改写→再生。
R6 出品：选题卡（现象/Puzzle/RQ/竞争解释/判别预测/淘汰条件/证据等级/覆盖边界/最便宜判别实验/地图出处）。

## 2. 金丝雀验收（用户裁决用）
- 3 篇精读笔记实物 + 引用核对报告（程序化）+ 迷你地图 + 1 轮异源模型猎杀记录。
- 用户判：笔记质量是否可用 → 可用才放量。

## B. 笔记模板 7+1（七要素保留 + RL 路由领域块）
- RL-Formulation: 状态/动作/奖励；单/多智能体；CTDE？
- Setup: 仿真器、星座规模、拓扑模型（快照/连续/contact plan）、流量模型
- Baselines: 打谁、赢多少
- Metrics: 时延/到达率/负载的精确口径
- Reality-Gap: 非平稳/部分可观测/sim-to-real 处理
- Reproducibility: 代码数据是否公开

## C. 平凡性对照组（"随便一个AI都能想到"的淘汰标准）
放量前先跑平凡基线：强模型零过程直提 10 个该方向选题。
幸存候选必须满足：不在基线清单内，或显式论证比基线深在哪（可判别的额外结构）。通不过=淘汰。
另加判据：平台独有攻击力——优先"只有具备 leo_sim 类平台才能攻击"的选题。

## D. 全自动信息源阶梯（一次性配置后无人值守）
0. 一次性配置（用户）：CARSI 登录一次（浏览器持久 profile）；申请 Elsevier/IEEE TDM API key（dev.elsevier.com / developer.ieee.org）；S2 免费 API key。key 仅存本地私密文件，永不入库。
1. Unpaywall API：DOI→合法开放版本（零风险，批量）。

4. 浏览器代理（autoglm-browser-agent，用户已登录的持久会话）：仅处理精读清单内经前三级仍不可得的**个位数关键篇**；限速（≥30s/篇）、遇验证码/429 立即停并上报。

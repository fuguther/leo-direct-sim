Q0 information-ablation literature map and no-results meeting narrative
0. 检索边界与方法
研究问题边界

本次检索不回答“哪种 RL/MPC 路由算法效果最好”，而回答 Q0 的核心问题：

当 LEO 网络路由决策拥有不同信息集时，什么算法族可以作为严格最优、上界或强参照？信息裁剪后，性能差距应如何解释？

重点区分：

Q0-I：当前全局状态已知，未来未知，但转移规律已知 → 在线最优。

Q0-F：完整未来 trace 已知 → clairvoyant/offline upper bound。

信息裁剪矩阵：

去远端队列；

去远端拓扑；

去 AoI/历史；

延迟或陈旧状态；

局部观测。

禁止以下错误解释：

普通 MPC ≠ 严格上界。

强 RL baseline ≠ 最优 oracle。

单条 trace 优势 ≠ 一般未来信息价值。

时间扩展流模型 ≠ 自动等价于 packet-level scheduling optimum。

仓库中的 Q0 文档已经明确区分：

Q0-I 是“仅知当前全局状态、不知未来”的严格在线最优对象；

Q0-F 是完整未来信息的离线最优对象。
证据：Q0-ALGO-RESEARCH 明确写出三个最优对象区分，并指出“把 Q0-F 直接叫当前信息上界会错误归因”。

1. 五条证据链
A. 当前全局状态在线最优：MDP / SMDP / PDMP
A1. Puterman — Markov Decision Processes: Discrete Stochastic Dynamic Programming

作者：

Martin L. Puterman

年份：

1994

Venue：

Wiley

DOI：

无 DOI（经典专著）

稳定来源：

https://onlinelibrary.wiley.com/doi/book/10.1002/9780470316887

核心命题：

完整 Markov state 已知、转移概率已知时，Bellman equation 给出最优策略。

适用假设：

Markov property；

状态完全可观测；

reward 定义明确；

transition model 已知。

Q0 映射：

支持：

Q0-I 的理论定义；

event-driven DP；

tiny 状态空间验证。

对应：

Q0-I
current global snapshot
↓
state S
↓
Bellman optimal action

不能支持：

不知道未来 arrival 的情况下制造未来 oracle；

大规模 LEO 网络直接求解；

部分观测情况下仍称严格最优。

A2. Bradtke & Duff — Reinforcement Learning Methods for Continuous-Time Markov Decision Problems

作者：

Steven J. Bradtke

Michael O. Duff

年份：

1995

Venue：

Advances in Neural Information Processing Systems

DOI：

无稳定 DOI

来源：

https://papers.nips.cc/paper_files/paper/1995

核心命题：

连续时间决策问题可表示为 semi-Markov decision process。

Q0 映射：

支持：

非固定 slot；

event-driven LEO simulation；

link availability event。

不能支持：

future geometry 已知；

clairvoyant upper bound。

A3. Puterman / SMDP 方向交叉验证

事实：

Q0 tiny 文档采用：

memoized event DP；

Bellman 递推；

当前信息。

仓库明确：

tiny DP 不是 Q0-F clairvoyant 上界，而是验证有限状态 Bellman 最优动作序列。

证据：

FACT

Q0-I tiny DP 已定位为 correctness anchor，不是正式求解器。

Q0-F 尚未完成。

信息裁剪需要区分 observation loss 和 transition loss。

证据：

INFERENCE

Q0-F 应采用 event-time MILP/CP-SAT。

Q0-I 与 Q0-F 差值可估计 future-information value。

# 文献阅读与重读

先明确这次阅读回答什么，再分配深度。身份/方法/结果/限制分别记 unread、scanned、checked、not_applicable，并记定位。一次缓存或一次全文读取不等于全部主张已核。

1. Zotero/来源表找身份、版本、附件，检查已有笔记；作者版本与正式版同 paper，不同 source。
2. 用 MD 搜索与通读所需上下文；原始 PDF/官方固定版本 HTML 承担核验。公式、单位、数量关系、表格工况、图轴/图例、算法步骤回原页。grep 零命中不能证明方法不存在。
3. 记录原文支持状态、作者主张/我们推断/假设、证据形态、适用范围。图中估读值注明方法与范围。解析缺陷与原文是否支持某条 claim 分开。
4. 原文定位采用 PDF 零起始页索引和章节/图表编号；印刷页号另记。HTML 用锚点，代码用 exact commit/文件/行。MinerU归一化坐标与PDF点坐标不能混用。
5. 重读提交新 read 与增量 claim。纠正追加 supersedes，旧条目保留。换当前依据使用 activate_source；只是加入另一个版本不会自动作废旧证据。

RL 方法按用途还原：系统与队列服务/失效/决策时刻；智能体及参数共享/训练部署；状态来源、信息范围和年龄、历史与缺失；动作/掩码/回退；奖励分量、权重、结算、终局与折扣；更新目标/多步/离策略/replay/target/探索；训练评估拆分、预算与随机种子；基线权限、时延条件样本、到达率分母及在途处理。未报告就写未报告，不补作者算法。

自由笔记写清收获和困惑。结构字段服务溯源，不要求每篇写满长表；研究候选排名单独保存在任务材料里。

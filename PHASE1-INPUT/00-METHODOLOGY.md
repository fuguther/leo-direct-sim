## 科研选题方法论（外部规范文本，白名单W1）

真正的科研选题，通常不是："我先想一个很厉害的题目→查文献→提几个假设→做实验。"更接近：**选一个值得长期待的战场→建立领域地图→找到一个"解释不通的地方"→提出几种竞争性解释→想办法设计一组证据把这些解释区分开→做便宜的小试验攻击自己的想法→活下来的那个问题，才进入正式开题。**真实科研常常不是 A→B，而是做到一半进入一段"所有假设都不对、实验也乱了"的阶段（the cloud），最后可能发现比原问题更好的问题 C。

一、区分 6 个常被混在一起的东西：领域 Field（长期在哪片知识空间工作）、研究问题 Problem（这里有什么解释不通）、研究问题 RQ（究竟想弄清什么）、假设 Hypothesis（可能是什么原因）、预测 Prediction（如果假设对，数据应出现什么）、研究设计 Design（怎么区分竞争解释）。新手常直接从技术热点跳到"我做个新算法"，中间最关键的一步——"到底有什么东西现在解释不了？"——根本没出现。

二、真正的研究者首先不是"找题目"而是"选战场"：长期放一批重要问题，等新方法/数据/技术/理论出现使某个问题变得可攻击。好问题应同时满足 重要性×可攻击性（Interest×Feasibility）。研究者在开始阶段先读、想、讨论，不要立即把自己绑死在第一个问题上。

三、选领域时真正要问 5 个问题：(1) 这个领域有哪些重要但没解决的问题——不是"有什么没人做过"，而是"有什么我们现在仍不理解"；(2) 为什么这个问题以前没解决（没数据/没算力/测不了变量/理论工具不成熟/系统以前不存在/实验无法区分两个机制/默认了错误假设）；(3) 为什么偏偏现在可能解决（老问题+新数据/新算法/新环境/两个过去分开的文献+新连接）——timing；(4) 我有没有特殊攻击优势（比较优势）；(5) 如果我失败还能学到什么——研究价值不等于必须得到预想结果，好题目往往是 H1 对→有结果、H2 对→也有结果、都不对→暴露新现象。

四、进入领域后第一项工作不是"读很多论文"而是建"知识地图"：这个领域有哪些主要主张？哪些已确定？哪些有争议？每个结论依赖什么假设？哪几个现象现有理论解释不了？每篇论文抽 7 样：Question（真正问了什么）、Claim（作者认为世界是什么样）、Mechanism（为什么）、Evidence（凭什么信）、Assumption（依赖什么关键前提）、Boundary（什么范围内成立）、Tension（留下什么解释不通的）。最后得到三张图：Claim Map（谁认为 A→B / A→B only if C）、Assumption Map（完全信息、i.i.d.、理性主体、静态网络、同质个体、无测量误差…）、Evidence Map（RCT/observational/仿真/理论证明/自然实验/benchmark/case study——"大家的结论很强，但证据并没有真正区分不同解释"常常就是机会）。

五、最核心的一步：找 Puzzle。Puzzle = 按现有知识，这件事本不应该这样，但它偏偏这样：Existing belief A + Observation B ⇒ A 无法完整解释 B。

六、7 个"问题生成器"：(1) Contradiction：文献冲突——Paper A 说 X→Y，Paper B 说 X 不导致 Y，真正的问题是什么条件导致不同结论；(2) Anomaly：现实异常——理论认为 A⇒B，现实出现 A 且 非B；(3) Assumption violation：攻击关键假设——不要做"去掉 A2 再跑一次"，而问"当 A2 不成立后，原结论为什么以及什么时候失效"（problematization，超越单纯的 gap spotting）；(4) Boundary condition：寻找结论的边界——何时 X→Y 停止成立；(5) Mechanism ambiguity：结果知道原因不知道——X→M1→Y 还是 X→M2→Y，哪个机制在起作用；(6) New capability：过去不能问现在能问——新数据/传感器/模型/平台/算力/政策/制度；(7) 两片文献之间的断层：A 文献知道 X→M，B 文献知道 M→Y，但没人研究 X→M→Y。

七、强的假设来自 理论→机制→假设→可观测预测，例如"因为机制 M，所以在条件 C 下，预测 X 会导致 Y"，而不是"我猜 X 会提高 Y"。

八、高手主动构造竞争解释 H1/H2/H3，然后问：有没有一种观测，在 H1 下会出现、在 H2 下不会出现？这就是判别性预测（discriminating prediction，John Platt 1964 Strong Inference：多替代假设→排除性实验→分叉→重复，而不是不断找支持自己理论的证据）。

九、一张好的假设表：机制/为什么/预测A/预测B/什么结果支持它/什么结果反驳它。如果你发现无论出现什么结果都能解释成"支持 H1"，H1 基本没有科研价值。

十、主动杀自己的题目（把自己当 Reviewer 2）——9 关：Gate1 Problem（不用术语一句话说清哪里不知道）；Gate2 Importance（解决了会改变哪个认识）；Gate3 Existing answer（文献最好的答案是什么）；Gate4 Deficiency（为什么现有答案不够）；Gate5 Novelty（新现象/新机制/新理论/新识别/新边界/新能力，而不是"以前没人把A用在B"）；Gate6 Discrimination（什么证据区分你的解释与竞争解释）；Gate7 Feasibility（数据/算力/实验/样本/时间/技术）；Gate8 Fatal risk（最可能死在哪）；Gate9 Success criterion（什么结果出现后可以说问题被回答了）。

十一、开题前还有 Pilot 阶段：cheap test before expensive commitment——先验证数据拿不拿得到、核心变量是否存在、measurement 是否靠谱、基准能否复现、关键假设是否明显违背、实验有无基本信号、仿真规模能否跑、"新现象"是不是 bug、方法优势是否来自不公平比较。Pilot 的目的不是提前拿到漂亮结果，而是提前发现这个题为什么会死。

十二、好开题 = 重要现象→已有知识→Puzzle→RQ→竞争假设→判别性证据→贡献这条链，而不是"时代背景→技术发展→国内外很多人做了→仍有不足→所以我设计一个XX模型"（后者没有真正的 epistemic problem）。

十三、开题一页纸：现象/目前知道什么/Puzzle（"奇怪的是____"）/RQ/已有解释 M1,M2/我的假设/判别性预测表/设计/贡献（"我们关于____的认识将从____变成____"）。

十四、读论文训练"科研人的眼睛"6 问：为什么这问题值得问？论文之前大家相信什么？什么东西让旧解释不舒服？作者真正排除了哪个竞争解释？哪个关键假设不成立结论会崩？如果我是作者下一篇最值得做什么（不是最容易）？

十五、探索与验证：允许先看到奇怪结果再提新假设，但不能看完结果编一个假设再假装预先存在（HARKing）。区分 exploratory（发现假设）与 confirmatory（检验预先假设）；已有观测可生成假设，检验最好依赖新的独立观测。

十六、8 步开题法：①选战场②建地图③找Puzzle④生成多个解释⑤推导判别性预测⑥设计最小判别实验⑦做Pilot+Kill Test⑧活下来的问题正式开题。核心是连续问三个问题：什么重要问题现在还没有被真正理解？为什么现在有机会回答它？什么证据会让我承认自己的解释是错的？
